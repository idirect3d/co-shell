# FEATURE-422 Web UI 模型配置界面

## 背景

Web UI 目前没有模型配置界面，用户需在录入框发 `:model add` 等命令，体验不佳。希望为 Web UI 设计一套专门的模型设置 UI，复用 REPL 向导状态机，包含：状态条模型选择器、模型管理弹窗、专用向导 UI。

## 方案

1. **状态条模型选择器**：hover 状态条主模型/视觉模型图标展开可选择模型列表（当前模型高亮），直接切换当前模式使用的模型，含"默认"选项（清空当前模式模型绑定，恢复全局默认）和"+"新增入口。
2. **模型管理弹窗**：模型列表 + 操作（切换/启用/禁用/编辑/删除/优先级）。
3. **专用向导 UI**：大弹窗，左侧步骤导航 + 右侧字段设置，上一步/下一步/取消。

后端复用 `ModelHandler` 向导，通过 WebIO 驱动（Print→ui_text、ReadLine/ReadKey→ask、Ask→interaction）。新增 `__CANCEL__` 哨兵值实现任意步骤退出兜底（readLine 错误时返回 `__CANCEL__`，所有 wizardPrompt* 识别并传播，AddModelWizard/editModelWizard 主循环识别退出）；给能力选择、启用等步骤增加 Q 退出；`model_wizard_cancel` 消息调用 `wio.failAll()` 让向导退出。

## 验收标准

1. 状态条 hover 主模型/视觉模型图标可展开模型选择列表，当前模型高亮，可切换，含"默认"选项和"+"新增入口。
2. 模型管理弹窗可列出模型，支持切换/启用/禁用/编辑/删除/优先级操作。
3. 新增/编辑模型进入专用向导 UI，左侧步骤导航 + 右侧字段设置，上一步/下一步/取消。
4. REPL 向导从任意步骤均可通过 Q 退出（含能力选择、启用等原无退出步骤）。
5. Web 向导取消（关闭弹窗/点取消）后，后端向导退出，不再卡死，可继续响应其他指令。
6. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 REPL 向导能力选择步骤 Q 退出
- 前置：REPL 环境，执行 `.model add` 进入向导
- 步骤：向导进行到能力选择步骤时输入 `Q`
- 期望：向导退出，不卡死，返回 REPL 提示符

### UC-002 REPL 向导启用步骤 Q 退出
- 前置：REPL 环境，执行 `.model add` 进入向导
- 步骤：向导进行到启用步骤时输入 `Q`
- 期望：向导退出，不卡死

### UC-003 REPL 向导 ReadLine 错误退出（模拟 Web 取消）
- 前置：单元测试环境（`model_wizard_cancel_test.go`）
- 步骤：`wizardTestIO{failRead: true}` 使 ReadLine 返回错误
- 期望：`wizardPromptBool`/`wizardPromptStringWithDefault`/`wizardPromptSecret`/`wizardSelectCapabilities` 均返回 `wizardCancel`，向导退出

### UC-004 状态条模型选择器展开
- 前置：Web UI 已启动，状态条显示主模型/视觉模型
- 步骤：鼠标 hover 状态条主模型图标
- 期望：展开模型选择列表，当前模型高亮，含"默认"选项和"+"新增入口

### UC-005 状态条切换模型
- 前置：Web UI 已启动，状态条模型选择器已展开
- 步骤：点击列表中的某个模型
- 期望：发送 `model_switch` 消息，后端切换模型，状态条刷新显示新模型

### UC-006 状态条"默认"选项
- 前置：Web UI 已启动，当前模式已绑定模型
- 步骤：点击模型选择列表中的"默认"选项
- 期望：清空当前模式模型绑定，恢复全局默认模型

### UC-007 状态条"+"新增入口
- 前置：Web UI 已启动，状态条模型选择器已展开
- 步骤：点击"+"新增入口
- 期望：打开模型配置向导弹窗，进入新增模型流程

### UC-008 模型管理弹窗打开
- 前置：Web UI 已启动
- 步骤：点击菜单栏"模型管理"入口
- 期望：打开模型管理弹窗，显示模型列表（含 ID/Provider/Model/状态/优先级）和"＋ 新增模型"按钮

### UC-009 模型管理弹窗操作
- 前置：Web UI 已启动，模型管理弹窗已打开，存在至少一个模型
- 步骤：点击模型的"切换/启用/禁用/编辑/删除"按钮
- 期望：发送对应消息，后端执行操作，模型列表刷新

### UC-010 新增模型向导
- 前置：Web UI 已启动，模型管理弹窗已打开
- 步骤：点击"＋ 新增模型"，进入向导，逐步填写字段
- 期望：向导 UI 显示左侧步骤导航 + 右侧字段设置，每步一个字段，上一步/下一步可用，完成后模型列表刷新

### UC-011 向导取消兜底
- 前置：Web UI 已启动，新增模型向导进行中
- 步骤：点击向导弹窗的取消按钮（✕）
- 期望：发送 `model_wizard_cancel` 消息，后端 `wio.failAll()` 让向导退出，向导弹窗关闭，后端可继续响应其他指令（不卡死）

### UC-012 编译通过
- 前置：代码修改完成
- 步骤：执行 `go build ./... && go vet ./... && go build -o work/co-shell .`
- 期望：编译、vet 全部通过，可执行码生成成功

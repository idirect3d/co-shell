# FIX-562 测试用例 —— hub「Agent 设置」表单 Agent描述 区块间距过小

> 分支：**FIX-561**（本会话分支，FIX-562 归入同一分支）｜版本：**v0.76.4** (BUILD-1134)｜产物：`work/co-shell-0.76.4.darwin.arm64`、`work/co-shell-hub-0.76.4.darwin.arm64`

## 问题与根因

**现象**：hub 左抽屉 → 点某个 agent →「Agent 设置」（修改 agent 参数）界面，最下方的「Agent描述（最近一次注册上报）」区块（标签 + 只读文本 + 说明）与它上面的内容「贴在一起」，没有间距，观感差。

**复现与量化（修复前，已实测）**：独立 hub 实例 + 浏览器打开 detail 视图，用 DOM `getBoundingClientRect()` 量测 `#viewDetail .config-body` 内各节点：

| 节点 | top | bottom | 与上一节点的间距 |
|------|-----|--------|------------------|
| `#f-extra`（补充运行参数） | 406 | 462 | 14px |
| `#d-state`（状态提示行） | 476 | 491 | 14px |
| 「Agent描述」字段 | 491 | 582 | **0px** ← 问题所在 |

普通字段之间统一为 14px（`.field { margin-bottom:14px }`），只有 Agent描述 区块是 0px。

**根因**：`.field` 只有 `margin-bottom`，而 Agent描述 区块的**上一个兄弟节点是 `.hint`**（`#d-state` 状态提示行）。`.hint` 只有 `margin-top:4px`、没有 `margin-bottom`，两个相邻 margin 折叠后该处为 0 —— 即「字段靠上一个字段的 margin-bottom 拉开间距」这一约定，在「上一个兄弟是 hint」时失效。

## 修复内容

`hub/gateway/webui_static.go`（嵌入式静态页）：

1. 新增 CSS 规则 `.field-sep { margin-top:16px; }`（含英文注释说明原因）；
2. detail 视图末尾的 Agent描述 字段加上该类：`<div class="field field-sep">`。

只调间距，不改任何字段内容、只读语义与保存行为（不涉及 `use-case/FEATURE-559`、`FIX-560` 已发布的行为）。

# FEATURE-500 Web UI 会话标题锁定优化

## 背景

Web UI 会话标题当前在任务完成时会被 LLM 自动生成的标题覆盖，用户手动修改的标题无法保留。需要引入标题锁定机制：用户手动修改标题后自动加 `$` 前缀表示锁定，任务完成时不再覆盖；清空标题则恢复默认占位标题并解除锁定。

## 方案

1. **手动改标题加锁**：用户修改标题（非空、有变化）生效时，后端保存为 `$` + 标题（锁定）。
2. **清空标题解锁**：用户清空标题生效时，后端恢复默认占位标题（如"新会话N"，与新建会话逻辑相同）并解除锁定，下次任务完成时 LLM 自动生成新标题。
3. **锁定标题不被覆盖**：会话标题以 `$` 开头时，任务完成（attempt_completion）只更新 keywords，保留原标题。

## 验收标准

1. 用户手动修改会话标题（非空、有变化）后，标题自动加 `$` 前缀，任务完成时不被 LLM 自动生成的标题覆盖。
2. 用户清空会话标题后，标题恢复为默认占位标题（如"新会话N"），任务完成时 LLM 自动生成新标题。
3. 标题以 `$` 开头的会话，任务完成时只更新 keywords，标题保持不变。
4. 编译通过：`go build ./... && go vet ./...`。

## 测试用例

### UC-001 手动修改标题加锁
- 前置：Web UI 已加载，当前会话标题为"新会话1"
- 步骤：点击标题输入框，修改为"我的项目"，按 Enter 生效
- 期望：标题变为"$我的项目"，会话列表同步显示"$我的项目"

### UC-002 锁定标题不被任务完成覆盖
- 前置：当前会话标题为"$我的项目"（已锁定）
- 步骤：执行一个任务并完成（attempt_completion 返回新标题"新任务标题"）
- 期望：会话标题仍为"$我的项目"，不被覆盖；keywords 正常更新

### UC-003 清空标题恢复默认并解锁
- 前置：当前会话标题为"$我的项目"（已锁定）
- 步骤：清空标题输入框，按 Enter 生效
- 期望：标题恢复为默认占位标题（如"新会话N"），无 `$` 前缀

### UC-004 解锁后任务完成自动生成标题
- 前置：当前会话标题为"新会话1"（已解锁）
- 步骤：执行一个任务并完成（attempt_completion 返回新标题"新任务标题"）
- 期望：会话标题更新为"新任务标题"

### UC-005 标题无变化不重复加锁
- 前置：当前会话标题为"$我的项目"（已锁定）
- 步骤：点击标题输入框，输入相同内容"$我的项目"，按 Enter 生效
- 期望：标题不变，不重复加 `$` 前缀

### UC-006 前端清空标题发送空值
- 前置：Web UI 已加载，当前会话标题为"$我的项目"
- 步骤：清空标题输入框，按 Enter 生效
- 期望：前端发送 `session_rename` 空值消息，后端恢复默认占位标题

### UC-007 编译验证
- 前置：无
- 步骤：运行 `go build ./... && go vet ./...`
- 期望：全部通过，无编译错误、无 vet 告警

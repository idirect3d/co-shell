# FEATURE-476 亮色主题色调调整（样本蓝灰配色）测试用例

## 背景

对 co-shell Web UI 的亮色主题（`[data-theme="light"]`）按样本界面的蓝灰配色方案做色调调整。色调版本不变（仍是亮色），仅调整各区域背景/文字颜色。

## 改动范围（已确认）

1. **仅左侧工作区面板**：
   - 工作区标题栏（`#sidebar .panel-head`）背景 → 深蓝（约 #1F4E79），文字白色
   - 分支（`#wsBranch`）→ 独立浅蓝半透明小块（约 #E8F0FE 半透明）
   - 文件列表（`#tree`）→ 浅灰背景（约 #F2F2F2）
2. **co-shell 主标题栏（`#topbar`）**：底边用深蓝，画比现在粗一点的边框

## 测试用例

### UC-001 亮色主题下工作区标题栏为深蓝背景
- **前置**：Web UI 处于亮色主题（`data-theme="light"`）
- **步骤**：查看左侧工作区面板标题栏（含"工作区"文字）
- **预期**：标题栏背景为深蓝色（约 #1F4E79），"工作区"文字为白色，刷新按钮可见

### UC-002 亮色主题下分支为独立浅蓝半透明小块
- **前置**：亮色主题，工作区为 git 仓库（有分支名）
- **步骤**：查看标题栏右侧的分支名（#wsBranch）
- **预期**：分支名显示在浅蓝半透明（约 #E8F0FE）的独立小块内，与深蓝标题栏背景区分明显

### UC-003 亮色主题下文件列表为浅灰背景
- **前置**：亮色主题，工作区有文件
- **步骤**：查看左侧文件列表（#tree）区域
- **预期**：文件列表背景为浅灰色（约 #F2F2F2），文件文字清晰可读

### UC-004 亮色主题下主标题栏底边为深蓝加粗边框
- **前置**：亮色主题
- **步骤**：查看顶部主标题栏（#topbar）底边
- **预期**：主标题栏底边为深蓝色边框，比当前（1px 浅灰）更粗（约 2px 深蓝）

### UC-005 暗色主题不受影响
- **前置**：Web UI 处于暗色主题（`data-theme="dark"`）
- **步骤**：查看左侧工作区面板、主标题栏
- **预期**：暗色主题下各区域配色与改动前一致，未受亮色主题改动影响

### UC-006 亮色主题整体协调
- **前置**：亮色主题
- **步骤**：整体查看界面
- **预期**：深蓝标题栏、浅蓝分支小块、浅灰文件列表分层清晰，整体协调不突兀

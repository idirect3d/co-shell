# FIX-529 测试用例：hub 徽标三角图标尺寸与 co-shell 品牌三角对齐

## 背景

hub UI 标题栏左上角浮着一个「co-shell-hub」徽标（`#hubBadge`），它盖在 iframe 内 co-shell 标题栏的品牌区之上。徽标文字前的三角箭头（`#i-hub-mark`）与 iframe 内 co-shell 品牌三角（`#i-tri`）在同一视觉位置上，但两者尺寸不一致。

**根因（代码定位，非推测）**：

| 侧 | 元素 | 尺寸来源 | 渲染尺寸 |
|---|---|---|---|
| iframe 内 co-shell | `.brand-mark .ico`（`web/static/style.css:201`） | 显式 `width:7px; height:7px` | **7×7 px** |
| hub 徽标 | `.ico.mark`（`hub/gateway/webui_static.go:248`） | 通用 `.ico { width:14px; height:14px }` 又被其后的 `#hubBadge .mark { width:12px; height:12px }` 覆盖（同特异性、后出现者生效） | **12×12 px** |

两个图形路径同形同比例（`#i-tri`：24 视箱内 11×13；`#i-hub-mark`：24 视箱内 11.4×14.4），因此视觉差异就是纯尺寸的 2 倍。

## 需求（用户确认）

1. 调整 hub UI 标题栏 logo 文字前的三角箭头图标，使其大小与 co-shell Web UI 同一位置上的图标一致（**7×7 px**）。
2. 版本 `0.62.1`（FIX，patch+1）；任务号 `FIX-529`；分支 `FIX-529`。

## 实现契约（需确认）

| 项 | 约定 |
|---|---|
| 改动位置 | `hub/gateway/webui_static.go` 内嵌 CSS 图标尺寸块内已存在的 `#hubBadge .mark { width:12px; height:12px }` |
| 改动内容 | 改为 `width:7px; height:7px`（同特异性下该规则位于通用 `.ico` 之后，是实际生效的尺寸） |
| 不变项 | SVG 路径（`#i-hub-mark`）、JS（`badgeFullW` / `setConn` / `opened` 逻辑）、徽标高度 44px、gap 8px、`align-items:center` 居中 |
| 非目标 | 不改 co-shell 侧 `.brand-mark .ico`；不动 `.head .mark` / `.pane-head .mark`（当前 HTML 中未被使用）；不动其它图标尺寸（`.pin` 18px、`.btn .ico` 15px 等） |

## UC-0001 徽标三角计算尺寸 = 7×7 px（核心用例）

**步骤（浏览器 console）**：

```js
var m = document.querySelector('#hubBadge .mark');
var r = m.getBoundingClientRect();
JSON.stringify({ w: r.width, h: r.height,
  cw: getComputedStyle(m).width, ch: getComputedStyle(m).height });
```

**期望**：`w = 7`、`h = 7`、`cw = "7px"`、`ch = "7px"`。

**修复前基线**：`w = 12`、`h = 12`、`cw = "12px"`（本用例修复前应 FAIL）。

## UC-0002 与 iframe 内 co-shell 品牌三角尺寸完全一致（核心用例）

**步骤**：

```js
var hub = document.querySelector('#hubBadge .mark').getBoundingClientRect();
var fr = document.querySelector('.frame.active').contentDocument;
var brand = fr.querySelector('.brand-mark .ico').getBoundingClientRect();
JSON.stringify({ hub: [hub.width, hub.height], brand: [brand.width, brand.height],
  equal: hub.width === brand.width && hub.height === brand.height });
```

**期望**：`equal === true`（两组均为 7×7）。

**修复前基线**：hub 12×12 vs brand 7×7，`equal === false`。

## UC-0003 视觉一致性（截图比对）

**步骤**：对徽标区域与标题栏品牌区各截一张图（同一缩放），目视/多模态比对两个三角的可视大小。

**期望**：两个三角可视高度一致，无「hub 三角明显更大」的观感；三角外接框均为 7×7，可视主体约 3.3×4.2 px。

## UC-0004 徽标布局无错位

**步骤**：

```js
var b = document.querySelector('#hubBadge');
var bb = b.getBoundingClientRect();
var m = b.querySelector('.mark').getBoundingClientRect();
var name = b.querySelector('.name').getBoundingClientRect();
JSON.stringify({ badgeH: bb.height, markTop: m.top - bb.top, nameLeft: name.left - m.right });
```

**期望**：`badgeH === 44`；三角在 44px 内垂直居中（`markTop ≈ (44-7)/2 = 18.5`，允许 ±0.5 亚像素误差）；文本紧邻三角右侧无重叠（`nameLeft > 0`）。

## UC-0005 三角颜色与断连灰显行为不回归

**步骤 1（连接态）**：`getComputedStyle(document.querySelector('#hubBadge .mark')).color` 期望为强调色 `rgb(63, 214, 239)`。
**步骤 2（断连态）**：在 hub 控制台/接口停掉与 hub 的连接（或断网/停止 hub 的 WebSocket 客户端）后，`#hubBadge .mark` 应带上 `off` 类，`color` 变为 `--fg-faint` = `rgb(91, 99, 115)`。
**期望**：颜色行为与修复前一致（仅尺寸变化，颜色/状态逻辑不受影响）。

## UC-0007 徽标宽度自适应正常（窄化后不溢出/不换行）

**步骤**：

```js
var b = document.querySelector('#hubBadge');
JSON.stringify({ w: b.getBoundingClientRect().width, h: b.getBoundingClientRect().height,
  wrap: getComputedStyle(b).whiteSpace, overflowX: b.scrollWidth > b.clientWidth });
```

**期望**：徽标高度仍为 44px（单行不换行）、`whiteSpace = "nowrap"`、无内容溢出；徽标总宽度相比修复前**约窄 5px**（12px → 7px），但 `logo + 版本号` 仍完整可见（窄屏隐藏版本号的既有逻辑不误触发）。

# FEATURE-434 重新设计 --help 示例

## 背景

`--help` 下示例过多（12 个），信息冗余，重点不突出，用户难以快速找到常用用法。需要精简为 3 个重点示例，突出最常用的三种使用场景。

## 方案

将 `--help` 的示例部分从 12 个精简为 3 个，突出重点：

1. **直接执行指令**：`co-shell "列出当前目录的文件"`（自然语言指令直接执行）
2. **启动配置绑定 IP 和网络白名单的对其他主机提供 web ui 的服务模式**：`co-shell --serve --bind 0.0.0.0 --whitelist 192.168.1.100,192.168.1.0/24`（局域网内其他主机访问 Web UI）
3. **同时指定工作空间、会话 ID、指令**：`co-shell -w /path/to/workspace -s my-task-001 "生成周报"`（用于其他程序调用 co-shell 的纯 agent 应用）

## 验收标准

1. `--help` 输出示例部分只显示 3 个示例，不再显示原来的 12 个。
2. 示例 1 展示直接执行自然语言指令。
3. 示例 2 展示 `--serve --bind --whitelist` 组合，用于对其他主机提供 Web UI 服务。
4. 示例 3 展示 `-w -s` + 指令组合，用于其他程序调用 co-shell 的纯 agent 应用。
5. 中英文（zh/en）文案均正确更新。
6. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

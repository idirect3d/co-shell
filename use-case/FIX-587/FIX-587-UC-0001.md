# FIX-587 UC-0001：已加载技能清单抬头——代码层用例

> 分支：**FIX-587**　版本：**v0.91.3**　需求：用户 2026-10-02「去掉 3.8 KB 与 sha256、只留位置信息右对齐、提示行并入描述」
> 判定口径：`skill_load` 结果抬头 = `<名称>` + 位置标签（工作区/全局）右对齐到 **显示列第 60 列**；抬头与结果文本内**不得**再出现文件路径、字节数、token 估算、sha256 前缀；提示行在有描述时以「（描述：xxx）」结尾。

## 目的

锁定抬头与提示行的文本契约（同时供 LLM、REPL、日志三处阅读），防止后续改动把宽度还给元数据、或把位置标签挤到换行。

# FIX-587 UC-0002：已加载技能清单——运行时用例（Web UI / REPL / LLM）

> 分支：**FIX-587**　版本：**v0.91.3**　产物：`work/co-shell-0.91.3.darwin.arm64`
> 观测对象：① Web UI 右侧「已加载技能」面板；② `skill_load` 工具结果文本（LLM/REPL/日志共用）。

## 目的

证明三处出口都按新契约显示：**只有名称 + 位置标签（右对齐）**，不再出现大小与 sha256；悬停行显示的是该 skill 的**卡片描述**（而不是原来的完整 sha）。

## 前置条件

```bash
cd /Users/direct3d/github/co-shell
ls -l work/co-shell-0.91.3.darwin.arm64
grep -rn "sk-size\|sk-sha" web/static/app.js web/static/style.css   # 期望无输出（已移除）
```

## 用例 A：Web UI 面板（`--serve` 必须，避免占用调试浏览器）

```bash
./work/co-shell-0.91.3.darwin.arm64 --serve --port 8123
# 浏览器打开 http://127.0.0.1:8123
```

1. 在对话框输入 `:skill load image-generate`（或让 Agent 调用 `skill_load`）。
2. 观察右侧/侧边「已加载技能」面板。

**期望**：
- 每行只有 **技能名**（左，占据剩余宽度，过长省略号）与 **位置标签**（右对齐：`工作区` / `全局`）；
- **不再出现** `3.8 KB` 之类的大小与 `7a611b09` 之类的 sha 前缀；
- 鼠标悬停该行 → 提示为该 skill 卡片描述（如「本地 AI 文生图（画图）能力…」），**不再是**完整 sha256。

## 用例 B：工具结果文本（LLM/REPL 同一份）

在 REPL 或 Web 对话框执行 `:skill load image-generate`，查看 `skill_load` 的返回文本：

**期望**（示例）：

```
SKILL LOADED: image-generate                          工作区
以下全文已固定（pinned）在本次对话中，…无需再重复 read_file。（描述：本地 AI 文生图（画图）能力…）
附带资源: README.md, scripts/generate_image.py
```

- 抬头位置标签末列 ≈ 第 60 列；
- 抬头中无路径 / 字节数 / token 估算 / sha256；
- 提示行以「（描述：xxx）」结尾，且**无** `%!(EXTRA …)` 伪影。

## 用例 C：会话恢复后描述仍在

1. 重启用例 A 的会话（切回同一 session）。
2. 观察面板与 `:skill list`。

**期望**：面板仍显示名称 + 位置标签；悬停描述对**新加载**的 skill 有效（`description` 随 `LoadedSkill` 持久化；对升级前就已加载的旧会话记录，描述字段可能为空 → 该行无悬停提示，属预期降级）。

## 通过判据

- A：面板无大小/sha、位置右对齐、悬停显示描述；
- B：工具结果抬头与提示行符合上例，无 fmt 伪影；
- C：刷新/恢复会话后行为一致（旧记录允许无描述）。

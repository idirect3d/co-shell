# FEATURE-493 测试用例

## 用例 1：状态栏 % 单位亮色显示（深色主题）
- **前置**：Web UI 深色主题（默认），状态栏可见
- **操作**：打开页面，观察状态栏模型上下文使用率（如 `🧠模型(89% of 1M)`）
- **预期**：`%` 字符显示为纯白色（`var(--fg)` = #d5dbe7），与数字同色，比单位外的说明文字（`of 1M`）更亮

## 用例 2：状态栏 % 单位亮色显示（亮色主题）
- **前置**：Web UI 亮色主题（light / light-tp）
- **操作**：切换主题后观察状态栏模型上下文使用率
- **预期**：`%` 字符显示为纯黑色（`var(--fg)` = #1d2433）

## 用例 3：状态栏 t/s 单位亮色显示
- **前置**：深色主题，状态栏可见
- **操作**：执行一轮任务产生 token 统计后，观察状态栏"最后一轮"段（如 `↑4500（2250t/s, 2s)`）
- **预期**：`t/s` 字符显示为纯白色（`var(--fg)`）

## 用例 4：状态栏 s 单位亮色显示
- **前置**：深色主题，状态栏可见
- **操作**：执行一轮任务产生 token 统计后，观察状态栏"最后一轮"段的耗时（如 `2s`、`25s`）
- **预期**：`s` 字符显示为纯白色（`var(--fg)`）

## 用例 5：消息流 token 行单位不受影响
- **前置**：深色主题
- **操作**：执行一轮任务，观察消息流中每轮迭代的 token 统计行（如 `↑34,670 ↓154 Σ34,824/1,048,576 1.8s 75`）
- **预期**：消息流 token 行的 `t/s`、`s` 单位保持原样（不包 span、不变色），仅底部状态栏单位变色

## 用例 6：会话标题栏去加粗（宽屏可编辑输入框）
- **前置**：宽屏，会话标题栏显示可编辑输入框 `#streamTitle`
- **操作**：检查会话标题文字样式
- **预期**：`font-weight` 为 400（非加粗），不再是 600

## 用例 7：会话标题栏去加粗（窄屏循环标题）
- **前置**：窄屏，会话标题栏显示循环标题控件 `.stc-face`
- **操作**：检查循环标题文字样式
- **预期**：`font-weight` 为 400（非加粗），不再是 600

## 用例 8：回归——状态栏其他文字不受影响
- **前置**：深色主题
- **操作**：观察状态栏整体
- **预期**：状态栏说明文字（`of 1M`、`会话`、`最后一轮` 等）保持 `var(--fg-dim)` 灰色不变，仅单位字符变亮

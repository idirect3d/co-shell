# FEATURE-567-UC-0006 开关与边界：board-must-reply=off、广播、离线接收方

- 分支：FEATURE-567（v0.81.0）｜类型：运行时 + 单元
- 目的：验证开关退化、广播义务独立计数、离线接收方不产生无意义义务。

## 步骤
1. 置 `board-must-reply=off`，重复 UC-0003 步骤 1：有义务时直接收尾。
2. 置回 `on`，A 用 `to=["*"]` 广播一条需要回复的消息（B、C 在线）。
3. 让 B 回复、C 不回复，观察两侧义务与 hub 侧计数。
4. 关闭 C 的 board（或令其离线）后，A 再发一条定向消息给 C。

## 期望
- 步骤 1：收尾成功（仅 `<board_replies>` 软提醒存在）。
- 步骤 3：B 义务清除；C 义务保留并在窗口到期后按 UC-0004 重投/超时，两者互不影响。
- 步骤 4：A 的 `board_sent` ack 的 `deliveries` 显示 C 未投递及原因；不产生义务、不重投。

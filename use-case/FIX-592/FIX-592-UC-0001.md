# FIX-592 UC-0001：系统默认值优化（6 项）

> 分支：**FIX-592**　版本：**v0.91.8**
> 判定口径：`config.DefaultConfig()` 的 6 个默认值符合新基线；**用户 `config.json` 中的显式值不被覆盖**；`browser-headless` 默认按平台（Linux=off，其余=on）；工作模式默认 `temperature` 为 nil 回落到全局默认；`:set` 设置项仍可用且改动可持久化。
> 本次只改**代码默认值**，不改用户运行时 `config.json`（用户已确认）。

## 背景（改前实测基线）

| 项 | 键 / 字段 | 改前默认 | 位置 |
|---|---|---|---|
| 流窗口块数 | `StreamWindowMaxBlocks` / `stream-window-max-blocks` | 300 | `config/config.go:1260` |
| 流窗口节点数 | `StreamWindowMaxNodes` / `stream-window-max-nodes` | 30000 | `config/config.go:1261` |
| 检索结果字节 | `SearchMaxResultBytes` / `search-max-result-bytes` | 65536 | `config/config.go:1227` |
| 温度 | `Temperature` / `temperature` | 0 | `config/config.go:1191` |
| 看板协作 | `BoardEnabled` / `board-enabled` | false（未设置 → Go 零值） | `config/config.go:1152` |
| 浏览器无头 | `BrowserHeadless` / `browser-headless` | true（全平台） | `config/config.go:1305` |
| 前端兜底值 | `app.js` `streamWindowMaxBlocks/MaxNodes` | 300 / 30000 | `web/static/app.js:863-864` |

温度生效链（实测）：`agent/agent.go:1643-1648` 的合并顺序为 全局 → 模型预设 → **工作模式优先**；而 `DefaultWorkModes()` 把 act/plan/research 都设为 `Float64Ptr(0)`（`config/config.go:1074/1081/1086`），故**只改全局默认时实际生效温度仍为 0**（本用例 D 即为该判定）。

## 变更点

| 位置 | 变更 |
|---|---|
| `config/config.go` `DefaultConfig()` | `StreamWindowMaxBlocks` 300→**128**；`StreamWindowMaxNodes` 30000→**12800**；`SearchMaxResultBytes` 65536→**128000**；`Temperature` 0→**0.5**；`BoardEnabled` →**true**；`BrowserHeadless` → `defaultBrowserHeadless(runtime.GOOS)` |
| `config/config.go` 新增 `defaultBrowserHeadless(goos string) bool` | `"linux"`→false；其余（darwin/windows/freebsd…）→true |
| `config/config.go` `DefaultWorkModes()` | act/plan/research 的 `Temperature` 由 `Float64Ptr(0)` → **nil**（回落全局默认；用户显式设过的模式值仍优先） |
| `config/config.go` `BoardEnabled` 的 JSON tag | `json:"board_enabled,omitempty"` → `json:"board_enabled"`（否则显式 off 存不下、重启回 on） |
| `cmd/config.go` | `board-enabled` 的 `ResetValue` false→**true**；`SetValue` 补 `Save()` |
| `web/static/app.js` | 兜底值 `streamWindowMaxBlocks=128`、`streamWindowMaxNodes=12800` |

## 用例

- **A 默认值基线（单测，`config` 包）**：`DefaultConfig()` 断言 `StreamWindowMaxBlocks==128`、`StreamWindowMaxNodes==12800`、`SearchMaxResultBytes==128000`、`Temperature==0.5`、`BoardEnabled==true`。
- **B 平台分支（单测，`config` 包）**：`defaultBrowserHeadless("linux")==false`；`"darwin"`/`"windows"`/`"freebsd"` → true；`DefaultConfig().LLM.BrowserHeadless` 在本机（darwin/arm64）==true。
- **C 显式配置优先（单测，Load/Save 往返）**：临时 `config.json` 显式写入 6 项**旧值**（含 `browser_headless:false`、`board_enabled:false`、`temperature:0`），加载后逐项等于**文件中的显式值**而非新默认；`Save()` 后再 `Load()` 仍不变 —— 其中 `board_enabled:false` 必须能存下（omitempty 修复的判定点）。
- **D 工作模式温度回落（单测）**：`DefaultWorkModes()` 三个模式的 `Temperature==nil`；按 `agent/agent.go:1643-1648` 合并规则，nil 时取全局默认（0.5）；若某模式显式设 0.9 仍取 0.9（模式优先级不变）。
- **E 设置项仍可改（单测，`cmd` 包）**：`:set temperature 0.8`（0~2.0 校验）、`:set stream-window-max-blocks 64`（10~100000）、`:set stream-window-max-nodes 20000`（1000~10000000）、`:set browser-headless off|on`、`:set board-enabled off` 后 `Save()`→`Load()` 得 false（**持久化**）；`board-enabled` 的 ResetValue 归位到 **on**。
- **F 前端兜底一致（静态检查）**：`web/static/app.js` 中 `streamWindowMaxBlocks = 128`、`streamWindowMaxNodes = 12800`；`node --check` 语法通过。
- **G 设置面板默认显示（单测，`cmd` 包）**：`cmd/settings_web.go` 的 6 项 `Default` 取自 `config.DefaultConfig()`，等于新基线（`board-enabled` 显示 on；`browser-headless` 显示本机平台值）。
- **H 回归**：`go build ./... && go vet ./...` 通过；`gofmt -l` 无输出；`go test ./... -short` 失败集为 main 基线的子集（零新增失败）。

- 不改模型预设（`ModelConfig.Temperature`）的取值，模型级/模式级显式值优先级保持不变。

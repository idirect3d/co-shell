# FEATURE-492 hub 界面 2 项小优化 — 测试用例

> 分支：FEATURE-492 ｜ 版本：v0.43.0 ｜ 应用：co-shell-hub
> 测试方式：启动 co-shell-hub，用浏览器打开 hub Web UI 验证

## 用例 1：logo/版本信息框初始显示 3 秒

- **前置**：打开 hub Web UI 页面
- **步骤**：观察左上角 co-shell-hub logo/版本信息框（#hubBadge）
- **预期**：页面加载后 #hubBadge 以不透明状态显示，持续约 3 秒

## 用例 2：3 秒后渐变透明（仍盖住下方、可点击）

- **前置**：页面加载完成超过 3 秒
- **步骤**：观察 #hubBadge 状态
- **预期**：3 秒后 #hubBadge 渐变为完全透明（opacity 0），但元素仍占据原位置（盖住下方 co-shell logo 区域），且仍可接收点击（点击仍能切换 Agent 抽屉）

## 用例 3：鼠标划过恢复不透明

- **前置**：#hubBadge 已透明
- **步骤**：将鼠标移动到 #hubBadge 位置
- **预期**：#hubBadge 恢复为不透明（opacity 1），显示 logo 和版本信息

## 用例 4：鼠标移走变回透明

- **前置**：#hubBadge 因 hover 恢复不透明
- **步骤**：将鼠标移出 #hubBadge
- **预期**：#hubBadge 再次渐变为完全透明

## 用例 5：实例列表抽屉右上角为图钉图标

- **前置**：打开 hub Web UI
- **步骤**：将鼠标移到左侧边缘（#edge）或点击 #hubBadge 展开 Agent 抽屉
- **预期**：抽屉右上角显示图钉图标（📌 或类似），不再是原来的收起图标（«）

## 用例 6：点击图钉钉住后不自动收起

- **前置**：Agent 抽屉已展开
- **步骤**：点击图钉图标（钉住），然后将鼠标移出抽屉
- **预期**：抽屉保持展开状态，不自动收起（原逻辑 mouseleave 600ms 后自动收起被禁用）

## 用例 7：再次点击图钉取消钉住

- **前置**：抽屉已钉住
- **步骤**：再次点击图钉图标（取消钉住），然后将鼠标移出抽屉
- **预期**：抽屉恢复自动收起行为（mouseleave 600ms 后自动收起）

## 用例 8：钉住状态视觉反馈

- **前置**：Agent 抽屉已展开
- **步骤**：点击图钉图标
- **预期**：图钉图标有视觉状态变化（如颜色变亮/旋转/填充），提示用户当前已钉住

## 用例 9：钉住状态在切换视图后保持

- **前置**：抽屉已钉住
- **步骤**：切换到"新建/设置"视图，再返回 Agent 列表
- **预期**：钉住状态保持，抽屉仍不自动收起

## 用例 10：编译与回归

- **前置**：代码修改完成
- **步骤**：`go build ./... && go vet ./...`；编译 co-shell-hub 到 ~/bin/
- **预期**：编译通过，无 vet 告警；co-shell-hub 可正常启动，上述交互均正常

# FEATURE-402 调整"+"号按钮位置到录入框左边 + 去掉对话条背景色

## 背景

FEATURE-401 将"+"号按钮放在 logo 和消息框之间，但用户希望调整："+"号嵌入到录入框（input-row）的左边，留好和边框和录入区域的边距；logo 位置、对齐方式保持现状；去掉对话条（#bottom）背景色。

## 验收标准

1. "+"号按钮嵌入到录入框（input-row）的左边（`#input` 前面）。
2. "+"号按钮与边框和录入区域留好边距。
3. logo 位置、对齐方式保持现状。
4. 对话条（#bottom）去掉背景色。
5. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

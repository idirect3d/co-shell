# FEATURE-570 用例组 G/H/I：SVG 尺寸自适应、缩放平移、提示词与回归（UC-0021 ~ UC-0032）

- 分支：FEATURE-570（v0.84.0）｜类型：运行时（浏览器实测为主，少量静态检查）
- 前置：同 UC-0001（`--serve` 启动 Web UI，浏览器打开对话页）。
- 本组需求来源：用户 Q1~Q4 答复——
  - 缩放交互：按钮 + 滚轮 + 拖拽平移（Q1-B）
  - 缩放仅影响显示；显示倍率；25%~400% 钳制；导出始终原始图形（Q2）
  - 「放到合适大小的容器显示，尽量不要单独创建满宽满高的 SVG」（Q3）
  - 并入 FEATURE-570，沿用当前分支（Q4）

## 组 G：SVG 尺寸自适应（不再满宽满高）

## FEATURE-570-UC-0021 默认尺寸 = min(设计尺寸, 容器宽度)

**tree**：`figure{width:360,height:240,axes:false,grid:false}` + 一个 10×7 的 `polygon`。
**步骤**：在宽度 ≥ 480px 的容器中渲染 → 量取 `svg.getBoundingClientRect()`。
**期望**：显示宽度 = 360px（设计尺寸）而非容器宽度；显示高度 = 240px；`svg` 的 `viewBox` 仍为 `0 0 360 240`；无滚动条。

## FEATURE-570-UC-0022 设计尺寸大于容器时收缩且不溢出

**tree**：`figure{width:1600,height:1000}`（同一图元集）。
**步骤**：在 480px 宽容器中渲染 → 量取 svg 宽度与父容器宽度；再缩窗口到 320px。
**期望**：显示宽度 = 容器可用宽度（≤ 容器宽，不出现横向溢出/裁剪）；宽高比保持 1.6:1（高度按比例换算，误差 < 2px）；页面无横向滚动条。

## FEATURE-570-UC-0023 width/height 作为设计像素的语义一致性

**tree**：三张并列图，分别 `width/height = 240×160 / 480×320 / 900×600`。
**步骤**：同一容器中渲染 → 量三张图的实际显示宽高。
**期望**：三张图显示尺寸分别为 240×160、480×320、min(900,容器宽)×对应高；三图内部几何**相对比例一致**（同一 tree 缩放后形状不变形）；字号随设计尺寸等比缩放（放大 2 倍 → 字号视觉高度约 2 倍）。

## 组 H：缩放与平移

## FEATURE-570-UC-0024 工具栏按钮与倍率显示

**步骤**：渲染任意 figure → 检查 head 内的控件。
**期望**：存在「缩小 / 放大 / 重置」三个按钮与一个倍率文本，初值为 **100%**；按钮均带 `type="button"` 且点击不触发外层折叠/actions；连续点「放大」→ 倍率按步进递增并以百分比显示（如 100%→125%→150%）；点「重置」→ 回到 100% 且图形恢复初始尺寸。

## FEATURE-570-UC-0025 滚轮缩放（含光标锚点）

**步骤**：将光标停在图内某点 → 滚轮上滚 3 次、下滚 5 次。
**期望**：向上放大、向下缩小；倍率文本同步更新；**页面本身不滚动**（事件被图拦截，`preventDefault` 生效）；缩放后光标下的图形位置基本不动（锚点漂移 < 5px）；缩放过程无 JS 异常。

## FEATURE-570-UC-0026 拖拽平移（可滚动视口）

**步骤**：放大到 300% → 在图上按住左键拖动 120px → 松开；再检验未放大（100%）时拖动。
**期望**：放大后拖拽可平移视图（视口 `scrollLeft/scrollTop` 随之改变），松手后不再跟随；拖拽期间光标变为 `grabbing` 且**不选中文字、不触发 actions 点击**；100% 且内容未超出容器时拖动无效果（无滚动空间）；鼠标移出图区域后移动不再影响图形。

## FEATURE-570-UC-0027 缩放范围钳制 25% ~ 400%

**步骤**：从 100% 连续点「缩小」12 次；再从下限连续点「放大」20 次。
**期望**：下限停在 **25%**、上限停在 **400%**，不越界、不出错；按钮在到达上下限时变为不可用（或点击无效）；倍率文本始终为 25%~400% 区间内的整数百分比。

## FEATURE-570-UC-0028 缩放不影响「下载 SVG」导出

**步骤**：把图放大到 250% 并平移到非原点位置 → 点击「下载 SVG」→ 用文本编辑器查看导出文件首行与 `svg` 标签。
**期望**：导出文件的 `width`/`height` = **原始设计尺寸**（非缩放后的像素值），`viewBox` = 原始 `0 0 w h`；内容完整（未被平移裁切）；颜色为实际 RGB（不依赖 CSS 变量）；与缩放前的导出结果逐字节一致（或仅在空白/属性顺序上等价）。

## FEATURE-570-UC-0029 update 原地重绘与缩放的交互

**步骤**：渲染 figure（id=X）→ 放大到 200% → 用 `UI.updateTree` 修改其中一个图元 → 观察。
**期望**：图元更新生效；缩放状态保持或用新尺寸重新计算，**不出现 NaN/0 宽高的空白图**；倍率文本与实际显示一致；连续 update 20 次无内存/尺寸漂移。

## 组 I：提示词与回归

## FEATURE-570-UC-0030 提示词补充尺寸规律（zh/en）

**步骤**：`grep` i18n/zh_ui.go 与 i18n/en_ui.go 的 figure 说明段。
**期望**：中英两版均明确说明——(1) `width`/`height` 是**设计像素尺寸**（同时是 viewBox）；(2) 实际显示宽度 = min(设计宽度, 容器宽度)，不会默认撑满；(3) 需要小图就直接写小尺寸（如 360×240），不再需要靠调整宽高比压缩；(4) 给出 2~3 个推荐档位（小插图/常规/大幅）。中英语义一致、字数相当。

## FEATURE-570-UC-0031 既有能力回归（不破坏）

**步骤**：对本组改动后重新跑既有用例的代表项：四主题配色（dark/dark-muted/light/eyecare）、`actions` 点击回传 `{type:"point",x,y}`、图元数/点数超限被后端拒绝、非法表达式图内降级、XSS 仅字面文本、REPL 与飞书文本降级。
**期望**：全部与改动前一致；缩放容器不吞掉图元上的 `click` 事件（点击图元仍能回传坐标）；图内文字选中/复制不被破坏（拖拽仅在按住并移动时生效）。

## FEATURE-570-UC-0032 多图并存与容器宽度差异

**步骤**：一屏内渲染 3 张 figure（尺寸 240×160 / 480×320 / 1600×1000），并在 375px（手机宽）视口复看。
**期望**：每张图各自独立显示与缩放，互不影响；宽容器下小图保持原尺寸（不被拉伸）；375px 下三图均收缩到容器宽且不横向溢出；缩放状态互不串台。

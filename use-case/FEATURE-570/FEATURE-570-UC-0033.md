# FEATURE-570 增强二：figure 视窗（相机）平移 + 右上角抓手 3D 旋转 — 测试用例

> 分支：`FEATURE-570`　版本：v0.84.0　基线：BUILD-1156（增强一已完成：设计像素尺寸 + 缩放控件 + 导出恒原始尺寸）
> 关联：需求来自用户 2026-10-01 指令（视窗式平移 + 右上角抓手旋转），5 项设计决策经 ask_user 确认，全部取推荐项，并追加「回正」按钮。
> 用例编号接续 `FEATURE-570-UC-0021.md`（UC-0021~UC-0032）。

## 0. 本轮设计基线（已与用户确认，作为用例判定前提）

| 项 | 决策 |
| --- | --- |
| D1 相机模型 | **平移与缩放统一为视图层变换**（`<g class="ui-fig-view">` 上的 translate+scale），不再使用容器 scrollLeft/scrollTop；旋转复用同一套视图/相机状态 |
| D2 旋转轴 | 左右拖 = 绕**竖直轴 yaw**，上下拖 = 绕**水平轴 pitch**（轨道相机） |
| D3 2D 图 | 纯 2D（无 z）图**也允许旋转**：z=0 平面倾斜成 3D 视角 |
| D4 旋转中心 | 视窗内**可见对象**的中心：(x,y) 取可见顶点包围盒中心，z 取可见顶点 z 深度中心；旋转时该中心屏幕位置不漂移 |
| D5 导出与重置 | 导出**反映当前视角**（所见即所得）；**重置**复位缩放+平移+视角；**新增「回正」**按钮：只把视角/位移摆正（保留当前缩放倍率） |

## 1. 组 J｜视窗（相机）式平移（UC-0033 ~ UC-0036）

### UC-0033 平移不再依赖容器滚动条
- **目标**：确认平移改由视图层变换实现，容器不再出现滚动条。
- **步骤**：① 打开 demo 页（含 2D 图与 3D 图）；② 读取 `.ui-figure-viewport` 的 `scrollWidth/clientWidth/scrollHeight/clientHeight`；③ 放大到 400% 后再次读取。
- **期望**：两次读取中 `scrollWidth === clientWidth` 且 `scrollHeight === clientHeight`（无滚动空间）；DOM 中存在 `.ui-figure-view` 且其 `transform` 含 translate。
- **判定依据**：`viewport.scrollWidth===viewport.clientWidth` 且 `viewport.scrollHeight===viewport.clientHeight`。

### UC-0034 上下方向可拖动（不再受内容高度限制）
- **目标**：竖直方向拖拽可以移动图（此前纵向无滚动空间时完全不可动）。
- **步骤**：① 100% 倍率下（内容未超出容器），在图上按住并纵向拖动 -80px；② 读取 `.ui-figure-view` 的 transform；
- **期望**：transform 的 translate 出现纵向位移（≈ +80 用户单位，方向与拖动相反即“跟手”）；横向同理。
- **判定依据**：拖拽前后 `translateY` 差值 ≥ 60。

### UC-0035 视图变换与缩放叠加正确（滚轮锚点仍不漂移）
- **目标**：确认缩放改为视图层 scale 后，滚轮锚点补偿仍成立。
- **步骤**：① 记录某图元中心屏幕坐标 P0；② 在 P0 处派发 `wheel(deltaY=-100)`；③ 再测该图元中心 P1。
- **期望**：`|P1-P0| < 5px`（锚点不漂移）；倍率文本从 100% 变为 125%。
- **判定依据**：漂移 < 5px。

### UC-0036 视图变换不破坏图元 actions 与 update
- **目标**：平移/缩放后，图元点击回传与 `UI.updateTree` 原地重绘仍正常。
- **步骤**：① 先拖拽平移 60px、再放大到 200%；② 点击带 actions 的 point 图元；③ 调用 `UI.updateTree` 删除一个图元。
- **期望**：click 回传 payload 仍为该图元数据；updateTree 后图元数 -1 且无重复 figure；变换状态不丢失。
- **判定依据**：actions 回调被调用 1 次；`document.querySelectorAll('.ui-figure').length` 不变。

## 2. 组 K｜右上角抓手 3D 旋转（UC-0037 ~ UC-0042）

### UC-0037 抓手按钮存在且位于图形右上角
- **目标**：确认抓手按钮已挂载且位置正确。
- **步骤**：① 定位 `.ui-figure` 内抓手元素（`.ui-fig-grip`）；② 比较其中心与 `.ui-figure-viewport` 的右上角距离。
- **期望**：元素存在、可见、`cursor:grab`；其中心距 viewport 右上角 < 60px（右上方区域）。
- **判定依据**：存在性与几何位置断言均通过。

### UC-0038 左右拖动 = 绕竖直轴 yaw 旋转
- **目标**：验证水平拖动改变 yaw 并触发重投影。
- **步骤**：① 记录 3D 图中某顶点的屏幕坐标；② 在抓手上按下并水平拖动 +60px；③ 再次读取该顶点坐标与视角状态。
- **期望**：该顶点屏幕坐标发生变化（位移 > 10px）；视角状态 yaw 绝对值 > 0；图形整体仍居中（画面未跑出视窗）。
- **判定依据**：坐标变化且 yaw≠0。

### UC-0039 上下拖动 = 绕水平轴 pitch 旋转
- **目标**：验证竖直拖动改变 pitch。
- **步骤**：① 在抓手上按下并竖直拖动 +60px；② 读取视角状态与顶点坐标。
- **期望**：pitch 绝对值 > 0；顶点屏幕坐标变化 > 10px；到 ±90° 附近不出现 NaN/白屏（数学退化被钳制）。
- **判定依据**：pitch≠0 且无 NaN、无空 SVG。

### UC-0040 旋转中心 = 视窗可见对象的 (x,y) 中心 + z 深度中心，且不漂移
- **目标**：验证旋转围绕“标定中心”而非画布原点。
- **步骤**：① 计算当前可见对象的 3D 包围盒中心 C；② 记录 C 的屏幕坐标 S0；③ 在抓手上拖动 40px；④ 重新计算 C 的屏幕坐标 S1。
- **期望**：`|S1-S0| < 8px`（中心锁定）；同时远端顶点位移明显（> 15px）证明发生了旋转而非平移。
- **判定依据**：中心漂移 < 8px 且远端位移 > 15px。

### UC-0041 纯 2D 图也可旋转（z=0 平面倾斜）
- **目标**：确认 D3 生效：2D 示意图在抓手拖动下产生 3D 倾斜观感。
- **步骤**：① 对纯 2D 图（无任何 z）水平拖动抓手；② 比较旋转前后图形的包围盒宽高比。
- **期望**：包围盒宽高比发生变化（倾斜导致横向压缩/纵向变化）> 3%；无渲染错误提示。
- **判定依据**：宽高比变化 > 3%。

### UC-0042 旋转期间的稳定性与安全性
- **目标**：旋转不得产生异常结构或注入风险。
- **步骤**：① 连续拖动抓手 20 次（大幅来回）；② 检查 DOM、控制台错误。
- **期望**：无 JS 异常；`svg` 内元素数量不超过 200 图元对应的合理上限；label 文本仍为字面文本（无 `<img>`/`<script>` 注入）；图元 id 与 class 结构保持不变。
- **判定依据**：无未捕获异常、无注入元素。

## 3. 组 L｜回正 / 重置 / 导出 / 回归（UC-0043 ~ UC-0048）

### UC-0043 「回正」按钮：视角与位移复位但保留缩放
- **目标**：验证新增的回正按钮语义。
- **步骤**：① 放大到 200% → 拖拽平移 → 拖动抓手旋转；② 点击「回正」；③ 读取视图状态。
- **期望**：yaw/pitch 归零（视图与初始投影一致）、translate 归零；scale 仍为 200%（保留）。
- **判定依据**：`view.transform` 中仅剩 scale 分量；倍率文本仍显示 200%。

### UC-0044 「重置」按钮：缩放+平移+视角全部复位
- **目标**：验证重置语义（D5）。
- **步骤**：① 制造 200% + 平移 + 旋转状态；② 点击「重置」。
- **期望**：scale=100%、translate=0、yaw=pitch=0；倍率文本 `100%`；图形回到初始外观（与未交互前的顶点坐标一致，容差 < 2px）。
- **判定依据**：三项状态同时归零且初始坐标一致。

### UC-0045 导出 SVG 反映当前视角
- **目标**：验证 D5 的导出语义（所见即所得）。
- **步骤**：① 旋转 + 平移 + 缩放后，拦截 Blob 取导出文本；② 检查根节点尺寸与视图层。
- **期望**：导出的 `svg` 保留 `width/height`（设计尺寸）与 `<g class="ui-figure-view">` 的当前 transform；导出的图元坐标与屏幕所见一致（非初始投影）。
- **判定依据**：导出文本含 view transform 且图元坐标 ≈ 当前屏幕坐标（差 < 2px）。

### UC-0046 抓手与既有缩放控件的互不干扰
- **目标**：抓手拖动不应触发缩放、滚轮缩放不应改动视角。
- **步骤**：① 拖动抓手后检查倍率文本未变；② 滚轮缩放后检查 yaw/pitch 未变；③ 拖动抓手时检查按钮未被误点。
- **期望**：三者状态互不串扰；拖动抓手期间页面不出现文字选中。
- **判定依据**：倍率/视角状态在各自操作前后保持稳定。

### UC-0047 四主题与既有控件回归
- **目标**：新交互不破坏配色与既有 12 种控件。
- **步骤**：① 依次切换 dark/dark-muted/light/paper 四主题，检查抓手与视图层样式；② 渲染 card/kv/table/chart/steps/callout/progress/form/html 等控件。
- **期望**：抓手颜色随主题变化（走 CSS 变量/语义类）；既有控件渲染正常、0 个“图元渲染失败”降级提示。
- **判定依据**：四主题下抓手可见且颜色不同；无降级提示。

### UC-0048 构建与静态检查
- **目标**：交付质量门禁。
- **步骤**：① `node --check web/static/ui-figure.js`；② `go build ./... && go vet ./...`（一次性执行）。
- **期望**：JS 语法通过；Go 编译与 vet 全绿。
- **判定依据**：两条命令退出码为 0。

# FEATURE-395 去掉右上角下拉菜单中三个菜单项的图标

## 背景

Web UI 右上角下拉菜单中，工作区（🗂）、任务进展（📋）、状态条（📊）三个菜单项带有 emoji 图标，视觉上较杂乱。本任务去掉这三个菜单项的图标，只保留文字，功能不变；系统设置（⚙️）图标保留。

## 验收标准

1. 右上角下拉菜单中，工作区、任务进展、状态条三个菜单项不再显示 emoji 图标。
2. 三个菜单项的文字标签保留（工作区/任务进展/状态条）。
3. 三个菜单项的功能不变（工作区切换面板、任务进展切换面板、状态条切换显示）。
4. 系统设置菜单项保留 ⚙️ 图标。
5. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

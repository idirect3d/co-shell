# FEATURE-496 模型联通性检测 — 测试用例

> 任务：新增模型联通性检测能力——通过调用各模型 endpoint 的 /models 接口检查目标模型是否可用。用于 ① 用户提交指令前（可配置 on_submit/on_send/off，默认 on_submit）若主模型不可用则终止任务并报告；② 前端模型列表（状态条主/视觉模型列表、模型管理列表）将不可用模型字体变灰显示。
> 分支：FEATURE-496　版本：v0.44.0
> 测试方式：Go 单元测试（llm/config/agent 包）+ 浏览器手动验证（serve 模式）+ node --check 语法检查

## 前置条件
- 配置中至少有两个已启用模型（一个主模型、一个视觉模型），且可访问真实 endpoint
- 以 `--serve` 启动 Web UI（不自动打开浏览器），用调试浏览器访问
- 联通性检测配置项 `model_connectivity_check` 已暴露在系统设置中

## 用例

### A. 联通性检测函数（llm 包单元测试）

### UC-001 目标模型在 /models 列表中 → 可用
- **操作**：对某真实可用模型调用联通性检测函数（endpoint/apiKey/model 均正确）
- **预期**：返回 available=true，无错误

### UC-002 目标模型不在 /models 列表中 → 不可用
- **操作**：对某 endpoint 可达但 model 名不在其 /models 返回列表中的模型调用检测
- **预期**：返回 available=false（接口成功但列表不含该模型）

### UC-003 endpoint 不可达 → 不可用
- **操作**：对 endpoint 无效（如错误端口/域名）的模型调用检测
- **预期**：返回 available=false，并带错误信息（接口调用失败）

### UC-004 API Key 无效 → 不可用
- **操作**：对 API Key 错误的模型调用检测
- **预期**：返回 available=false（接口返回 401/403 等非 200）

### B. 配置项（config 包单元测试）

### UC-005 默认值为 on_submit
- **操作**：读取 DefaultConfig().LLM.ModelConnectivityCheck
- **预期**：值为 "on_submit"

### UC-006 三种取值合法
- **操作**：分别设置 off / on_submit / on_send
- **预期**：均可正常保存与读取，无校验错误

### C. agent 提交/发送前检查（agent 包 + 手动验证）

### UC-007 on_submit：主模型不可用时提交指令被终止并报告
- **操作**：将主模型 endpoint 改为不可达，配置为 on_submit，提交一条指令
- **预期**：任务立即终止，不向 LLM 发送请求，向用户报告"主模型不可用"及原因

### UC-008 on_submit：主模型可用时正常执行
- **操作**：主模型可用，配置为 on_submit，提交一条指令
- **预期**：任务正常执行，无额外阻塞（联通性检测通过）

### UC-009 on_send：agent 每次发消息前检测
- **操作**：配置为 on_send，任务运行中（多轮工具调用）将主模型 endpoint 改为不可达
- **预期**：下一次 agent 发消息前检测到不可用，终止任务并报告

### UC-010 off：关闭检测，主模型不可用时仍尝试发送
- **操作**：配置为 off，主模型 endpoint 不可达，提交指令
- **预期**：不进行联通性检测，直接尝试发送（由 LLM 调用自身报错兜底）

### UC-011 视觉模型不可用时的处理
- **操作**：主模型可用、视觉模型不可用，提交一条带图片的指令（触发视觉模型）
- **预期**：若当前需用视觉模型且其不可用，任务终止并报告视觉模型不可用；若主模型可处理则正常

### D. 前端模型列表字体变灰（浏览器手动验证）

### UC-012 模型管理列表不可用模型字体变灰
- **操作**：打开模型管理弹窗（#models），其中某模型 endpoint 不可达
- **预期**：该模型行字体显示为暗色/灰色（区别于可用模型），其余可用模型正常显示

### UC-013 状态条主模型列表不可用模型字体变灰
- **操作**：点击状态条主模型选择器（#modelMenu），其中某模型不可用
- **预期**：不可用模型项字体变灰，可用模型项正常

### UC-014 状态条视觉模型列表不可用模型字体变灰
- **操作**：点击状态条视觉模型选择器（#modelVisionMenu），其中某视觉模型不可用
- **预期**：不可用视觉模型项字体变灰

### UC-015 不可用模型仍可点击切换（仅视觉提示）
- **操作**：在模型列表中点击一个不可用模型项
- **预期**：字体变灰仅为视觉提示，点击行为不受影响（仍可切换，切换后由提交前检测兜底）

### E. 语法与回归

### UC-016 语法与回归

- **预期**：编译与语法检查通过；既有模型切换、模型管理、提交指令流程不受影响

# FIX-313: OpenAI 模式 ToolExamples 节误用 XML 格式示例

## 现象

OpenAI 工具调用模式下，系统提示词的 ToolExamples 节输出的是 XML 格式示例（`<cs:execute_command>` 等带前缀标签），而非 OpenAI API 的 JSON 格式参数结构。LLM 被要求使用 JSON 格式的 tool_calls 机制，却看到 XML 格式样例，导致思维混乱。

## 排查结论（根因）

| 事实 | 证据 |
|---|---|
| `KeySystemPromptToolUsageExamples` 是为 OpenAI 模式设计的 JSON 格式示例 | i18n/keys.go 注释「Non-XML tool usage examples and task progress (for OpenAI mode)」；内容为 `# 工具调用示例` + JSON 参数结构 |
| 但该 key **从未被代码引用**（孤儿 key） | `grep -r "KeySystemPromptToolUsageExamples" agent/` 仅 system_prompt.go 的 **getRawSectionText** 中引用（卸载用），`buildNamedSection` 未引用 |
| `buildNamedSection` 的 `ToolExamples` case 固定引用 `KeySystemPromptXMLExamples` | agent/system_prompt.go:400-404：`return i18n.T(i18n.KeySystemPromptXMLExamples)`，**不感知 tool call mode** |
| OpenAI 模式下 ToolExamples 节可被包含 | `getWorkModeSectionNames` 在 work_mode 未匹配时回退 `DefaultBuiltInSections()`（12 节，含 ToolExamples）；用户自定义模式也可含 ToolExamples |
| 示例中的工具参数缺少 `intent` 必填字段 | FEATURE-252 要求所有工具（除 4 个特例外）必填 `intent`，但 `KeySystemPromptToolUsageExamples` 中的 execute_command/write_to_file/search_files/replace_in_file 均缺 `intent` |

**根因定论**：`buildNamedSection` 的 `ToolExamples` case 缺少 tool call mode 条件分支，固定输出 XML 格式示例。为 OpenAI 模式设计的 `KeySystemPromptToolUsageExamples`（JSON 格式）从未被使用，且其内容参数结构缺少 `intent` 必填字段。

## 修复内容

### `agent/system_prompt.go`

1. **`buildNamedSection` 的 `ToolExamples` case**：根据 `cfg.LLM.ToolCallMode` 分支——
   - `"openai"` → `i18n.T(i18n.KeySystemPromptToolUsageExamples)`（JSON 格式）
   - 其他（含 ""、xml）→ `i18n.T(i18n.KeySystemPromptXMLExamples)`（XML 格式，保持现状）

2. **`getRawSectionText` 的 `ToolExamples` case**：同样按 mode 分支，保证 `UnloadModeSections` 卸载内容与运行时一致。

### `i18n/zh_system.go` + `i18n/en_system.go`

为 `KeySystemPromptToolUsageExamples` 补全工具调用的 `intent` 必填字段（execute_command、write_to_file、search_files、replace_in_file）。

## 修复效果

- OpenAI 模式 + ToolExamples 节 → JSON 格式示例（`KeySystemPromptToolUsageExamples`），LLM 按 API tool_calls 机制理解参数结构
- XML 模式 + ToolExamples 节 → XML 格式示例（`KeySystemPromptXMLExamples`），行为不变
- 示例参数结构补全 `intent`，与 FEATURE-252 工具定义一致

## 用例（循环模式）

| # | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| 1 | OpenAI 模式 ToolExamples 用 JSON 示例 | `cfg.LLM.ToolCallMode="openai"`，`buildNamedSection("ToolExamples",...)` | 结果字符串 == `i18n.T(KeySystemPromptToolUsageExamples)`，不含 `<cs:` 或 `<{XML_TAG_PREFIX}` |
| 2 | XML 模式 ToolExamples 用 XML 示例 | `cfg.LLM.ToolCallMode="xml"`，`buildNamedSection("ToolExamples",...)` | 结果字符串 == `i18n.T(KeySystemPromptXMLExamples)`，含 `{XML_TAG_PREFIX}` 占位符 |
| 3 | 空 ToolCallMode（默认）用 XML 示例 | `cfg.LLM.ToolCallMode=""`，`buildNamedSection("ToolExamples",...)` | 保持现状，返回 XML 示例 |
| 4 | OpenAI JSON 示例含 intent（en） | `i18n.T(KeySystemPromptToolUsageExamples)`（en） | execute_command/write_to_file/search_files/replace_in_file 均含 `"intent"` 字段 |
| 5 | OpenAI JSON 示例含 intent（zh） | `i18n.T(KeySystemPromptToolUsageExamples)`（zh） | 同上（中文本地化） |
| 6 | KeySystemPromptToolUsageExamples 不再孤儿 | 全代码库 grep | agent/system_prompt.go 两处引用（buildNamedSection + getRawSectionText） |

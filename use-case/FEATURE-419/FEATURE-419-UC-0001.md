# FEATURE-419 Web UI 三项优化

## 背景

Web UI 存在三个体验问题：
1. 状态条会话列表展开时未滚动到当前会话，用户需手动查找当前会话位置。
2. 工作区文件/分支状态只在任务全部结束后刷新，未在每次迭代（显示块完成后去掉"..."时）更新，用户无法实时看到文件/分支变化。
3. 快捷键收集阶段只没收了数字和字母，其他符号（如 !@#$%^&*() 等）会漏给录入框，用户需反复删除无用内容。

## 方案

修改 `web/static/app.js`：
1. `renderSessionMenu` 渲染会话列表后，菜单展开时滚动到当前会话项（`scrollIntoView`）。
2. `token_iter`/`token_task` 事件（去掉"..."处）增加 `refreshBranch()` + `loadTree()` 刷新工作区状态。
3. 快捷键收集阶段（interaction pending 且非 supplement 模式）没收全部按键，无论是否触发下一步操作都不再返还给页面。

## 验收标准

1. 会话列表展开时默认滚动到当前会话项，用户无需手动查找。
2. 工作区文件/分支状态在每次迭代（显示块完成后去掉"..."时）刷新，而非仅在任务全部结束后。
3. 快捷键收集阶段没收全部按键（数字、字母、符号、功能键等），不再漏给录入框。
4. 补充输入模式（supplement mode）下仍可自由输入，不受影响。
5. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 会话列表展开时滚动到当前会话
- 前置：存在多个会话，当前会话不在列表顶部
- 步骤：鼠标悬停状态条 💬 图标展开会话列表
- 期望：列表自动滚动到当前会话项（带 `.current` 类），当前会话可见

### UC-002 会话列表为空时不滚动
- 前置：无任何会话
- 步骤：鼠标悬停状态条 💬 图标展开会话列表
- 期望：显示空提示，无滚动异常

### UC-003 工作区状态每次迭代刷新
- 前置：Agent 正在执行任务，工作区文件/分支可能变化
- 步骤：观察每次 LLM 迭代结束（显示块"..."消失）时
- 期望：工作区文件树和分支标签自动刷新，无需等待任务全部结束

### UC-004 工具调用完成后工作区状态刷新（回归）
- 前置：Agent 执行工具调用
- 步骤：观察工具调用完成时
- 期望：工作区文件树和分支标签仍自动刷新（原有行为不丢失）

### UC-005 快捷键收集阶段没收数字和字母
- 前置：interaction pending（如工具确认），焦点在录入框
- 步骤：按数字键 1-9 或字母键 a-z
- 期望：按键触发对应操作，且不泄漏到录入框

### UC-006 快捷键收集阶段没收符号键
- 前置：interaction pending，焦点在录入框
- 步骤：按符号键（如 ! @ # $ % ^ & * ( ) 等）
- 期望：符号不泄漏到录入框，录入框内容不变

### UC-007 快捷键收集阶段没收功能键
- 前置：interaction pending，焦点在录入框
- 步骤：按功能键（如 F1-F12、方向键、Tab 等）
- 期望：按键不泄漏到录入框，录入框内容不变

### UC-008 补充输入模式可自由输入
- 前置：interaction pending，进入补充输入模式（supplement mode）
- 步骤：输入任意字符（字母、数字、符号）
- 期望：字符正常输入到录入框，不受没收影响

### UC-009 编译验证
- 前置：无
- 步骤：运行 `go build ./... && go vet ./... && go build -o work/co-shell .`
- 期望：全部通过，无编译错误、无 vet 告警

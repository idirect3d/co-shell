# FIX-573 运行时测试用例：窄/宽屏切换（或窗口缩放）后底部控件位置错乱

> 分支：**FIX-573**　版本：**v0.85.1**　被测：co-shell Web UI（`web/static/app.js` / `index.html` / `style.css`）
> 需求（用户反馈）：窗口切换显示模式（窄屏/宽屏）或窗口放大缩小后，很大概率出现
> ① 左下角 co-shell logo 旁的「新建会话 ＋」按钮跑到对话输入框**右边**；
> ② 状态条中的几块内容位置错乱。

## 0. 测试环境与断点规则

- 被测页面：`web/static/index.html`（+ `app.js` 等）。
- 断点规则（`updateResponsive`）：`narrow = window.innerWidth < brandWidth() * 3`；跨断点才会触发控件搬迁/还原。
- **静态验证站**（推荐，不干扰用户正在使用的实例）：把 `index.html` 与 `static/` 放到同一个 HTTP 根下用静态服务器打开（如 `python3 -m http.server`），再用调试浏览器（`browser_*` 工具）在页面内用 `browser_evaluate` 断言。
- 模拟断点（页面内脚本，无需真实缩放窗口）：
  ```js
  function setVW(w){ Object.defineProperty(window,'innerWidth',{value:w,configurable:true,writable:true}); window.dispatchEvent(new Event('resize')); }
  ```
- 基线（**修复前后都必须先采集**，用于顺序比对）：
  ```js
  const orderOf = (sel) => Array.from(document.querySelector(sel).children).map(e => e.id || ('#' + e.tagName));
  const BASE_INPUT = orderOf('.input-row');
  const BASE_SB    = orderOf('#statusbar');
  ```
  初始（宽屏、未搬迁）应为：
  - `.input-row` = `[newSessionBtn, input, attachBtn, sendBtn, yoloSwitch]`
  - `#statusbar` = `[modeSeg, sbSessionsWrap, sbModelTextWrap, sbModelVisionWrap, sbSessionWrap, sbLastWrap]`

## A 组：DOM 顺序（核心回归，循环断言）

| 用例 | 步骤 | 期望结果 |
|------|------|----------|
| **UC-0001** 宽屏初始基线 | 页面加载后（宽屏）取 `BASE_INPUT` / `BASE_SB` | 与第 0 节列出的初始序列**完全一致** |
| **UC-0002** 窄屏搬迁 | `setVW(480)`；等 1 帧 | `document.body.classList.contains('narrow') === true`；8 个可搬迁控件（modeSeg、sbModelTextWrap、sbModelVisionWrap、newSessionBtn、sbSessionsWrap、attachBtn、yoloSwitch、sendBtn）**全部**在 `#narrowTools` 内；`#newSessionBtn` 不在 `.input-row` 内；`#narrowTools` 不含 `hidden` |
| **UC-0003** 窄→宽还原：输入行顺序 | `setVW(480)` → `setVW(1400)`；比对 | `.input-row` 序列 === `BASE_INPUT`（**`newSessionBtn` 必须是第一个**，不得出现在 textarea 之后） |
| **UC-0004** 窄→宽还原：状态条顺序 | 同 UC-0003，比对 `#statusbar` | `#statusbar` 序列 === `BASE_SB`（不得变成「会话用量/最近用量/模式/主模型/视觉模型/会话数」） |
| **UC-0005** 循环幂等（5 轮） | `for (i=0;i<5;i++){ setVW(480); setVW(1400); }` 每轮结束比对 | 5 轮宽屏下的 `.input-row` 与 `#statusbar` 序列**每轮都等于基线**（不允许第 2 轮起才错乱） |
| **UC-0006** 父节点与锚点回归 | 5 轮后检查 | `#newSessionBtn.parentNode.classList.contains('input-row')`；`#newSessionBtn.nextSibling` 与基线时记录的 `nextSibling` 节点相同；其余 7 个控件亦回各自原父节点 |
| **UC-0007** 极窄/极宽抖动 | 连续 `setVW` 交替 320 / 2000 共 10 次（不等帧）后 `setVW(1400)` | 宽屏下两处序列仍等于基线（防抖/竞态下不丢位置） |

## B 组：视觉位置（getBoundingClientRect 断言）

| 用例 | 步骤 | 期望结果 |

# FIX-575 UC-0001：单轮多次工具调用，刷新前后 TOOL 块数量/顺序/标题一致

> 分支：**FIX-575**　版本：**v0.85.3**　被测：Web UI 消息回放（`web/eventcoalesce.go`、`web/static/app.js`）
> 对应验收标准：**§1（块数量/顺序/标题一致）**、**§2（无结果事件后仍各自成块）**
> 缺陷现象：重启/刷新恢复会话后，同一 turn 内部分工具调用不再成块（被并入上一块或被吞），滚动加载也无法补回。

## 目的

锁定「一个 turn 内连发多个工具调用」这一最容易触发缺陷的场景：恢复后必须与实时渲染**逐个成块**，数量、顺序、标题（intent）完全一致。

## 前置条件

- 被测程序：`work/co-shell-0.85.3.darwin.arm64`（本分支编译产物）
- 启动（不自动开浏览器，用调试浏览器访问）：
  ```bash
  ./work/co-shell-0.85.3.darwin.arm64 --serve --port 28256
  ```
- 会话需产生「同一轮内连续 3 次 `read_file`」：可用提示词
  `请在一轮内依次读取 main.go、go.mod、README.md 三个文件，每个文件只读前 20 行，然后再统一汇总。`
- **不要**在同一 turn 内插入需要用户确认的中断操作（避免 turn 被切分）。

## 步骤

1. 在 Web UI 打开会话，发送上述提示词，等待本轮全部工具执行完毕（正文出现 3 个 `⚙️ read_file` TOOL 块）。
2. **实时基线**：执行下方脚本 A，记录 `toolCount / heads / lineCount / yellowCount`。
3. 按 `F5` 刷新页面（或关闭页面后重新打开同一会话），等待历史回放完成（消息流不再增长）。
4. **回放结果**：再次执行脚本 A，记录同样 4 个值。
5. 向上滚动触发更早历史加载，再执行一次脚本 A，确认数值不变。

### 脚本 A（浏览器控制台）

```js
(() => {
  const tool  = [...document.querySelectorAll('#stream .ev.tool')];
  const heads = tool.map(b => {
    const el = b.querySelector('.ev-head-label') || b.querySelector('.ev-head');
    return el ? el.textContent.trim() : '';
  });
  const lines  = [...document.querySelectorAll('#msgVizTrack .msgviz-line, #msgVizTrack .line')];
  const yellow = lines.filter(l => {
    const s = l.getAttribute('style') || '';
    return /facc15|250,\s*204,\s*21/i.test(s) || l.classList.contains('tool') || l.dataset.kind === 'tool';
  });
  return { toolCount: tool.length, heads, lineCount: lines.length, yellowCount: yellow.length };
})()
```

## 预期结果

| 断言 | 期望 |
|------|------|
| A1 实时 `toolCount` | == 本轮实际工具调用数（示例为 **3**） |
| A2 回放 `toolCount` | **与 A1 完全相等**（不得出现“缺 1 个”或“只剩 1 个”） |
| A3 `heads` 数组 | 回放与实时**逐项相等**，顺序相同，且每项含对应工具名（如 `read_file`） |
| A4 `yellowCount` | == `toolCount`（见 UC-0006） |
| A5 滚动加载后 | 上述数值不发生变化（不重复、不丢失） |
| A6 每个块自身完整 | 每个 `⚙️ read_file` 块内参数区含**自己**的 `path`（不得把 `README.md` 的参数并到 `main.go` 块里） |

## 修复前失败现象（基线）

- 回放后 `toolCount` 常为 **1**（只保留第一块），其余 2 次调用被并入第一块；`heads` 长度骤减；
- 或被吞掉的块参数完全消失（文本被静默丢弃）；
- 刷新多次结果不稳定（取决于前一工具是否留下结果事件）。

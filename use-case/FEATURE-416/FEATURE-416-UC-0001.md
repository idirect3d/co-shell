# FEATURE-416 LLM 输出时主内容区滚动锁定优化

## 背景

LLM 输出内容时，主内容区的滚动条几乎被锁定在最新一行内容处，用户无法专注查看历史信息。需要设计一种机制提升用户查看历史内容的体验。

## 方案

LLM 正在输出时（运行按钮为红色"暂停"状态），若用户向上翻页（滚动条/滚轮/PgUp/PgDn），立即在主输出框下方生成高度自适应、最大高度为主输出区 1/4 的动态输出区域 A，将最后一个输出块挪到 A 区继续动态输出，后续输出块也在 A 区累积；原输出区变为静态区域 B，用户可持久专注查看历史内容。只要区域 A 存在，就在 B 区下方总是显示一个悬浮的向下箭头图标（指向横线，表示可与下方内容对接），用户点击后将 A 区最新内容合并到 B 区下面，删除 A 区，恢复为整体输出区。

## 验收标准

1. LLM 正在输出时，用户向上翻页（滚动条/滚轮/PgUp/PgDn）→ 生成动态输出区域 A（最大高度为主输出区 1/4）。
2. 最后一个输出块被挪到区域 A 继续动态输出，后续输出块也在区域 A 累积。
3. 原输出区变为静态区域 B，用户可专注查看历史内容，不被新输出打扰。
4. 只要区域 A 存在，B 区下方总是显示一个悬浮的向下箭头图标。
5. 用户点击向下箭头 → 将 A 区最新内容合并到 B 区下面，删除 A 区，恢复为整体输出区。
6. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 向上翻页生成动态输出区域 A
- 前置：Web UI 已加载，LLM 正在输出（运行按钮为红色"暂停"状态）
- 步骤：用户向上翻页（滚动条/滚轮/PgUp/PgDn）
- 期望：主输出框下方生成动态输出区域 A（最大高度为主输出区 1/4），最后一个输出块被挪到 A 区

### UC-002 后续输出在区域 A 累积
- 前置：区域 A 已生成，LLM 仍在输出
- 步骤：观察后续输出块
- 期望：后续输出块在区域 A 累积，原输出区（区域 B）不再变化

### UC-003 区域 B 静态可专注查看
- 前置：区域 A 已生成
- 步骤：观察区域 B
- 期望：区域 B 内容不再随新输出变化，用户可专注查看历史内容

### UC-004 B 区下方显示向下继续图标
- 前置：区域 A 已生成
- 步骤：观察区域 B 下方
- 期望：区域 B 下方总是显示一个悬浮的向下箭头图标（指向横线）

### UC-005 点击向下箭头合并恢复整体
- 前置：区域 A 已生成，向下箭头图标可见
- 步骤：点击向下箭头图标
- 期望：区域 A 的最新内容合并到区域 B 下面，删除区域 A，恢复为整体输出区

### UC-006 编译验证
- 前置：无
- 步骤：运行 `go build ./... && go vet ./... && go build -o work/co-shell .`
- 期望：全部通过，无编译错误、无 vet 告警

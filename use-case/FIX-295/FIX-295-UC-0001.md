# FIX-295-UC-0001: Token 用量显示多余空行和重复区块

## 描述
当会话结束时，token 用量统计显示中存在多余的空白分隔线和重复的 `token_task` 区块。

## 前置条件
1. 已启动 co-shell 并进入 REPL
2. 使用 `:task` 模式

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 发送一条简单消息如 `hello` | LLM 正常回复 |
| 2 | 等待对话结束 | 观察输出的 token 统计区域 |

## 验收标准

1. token 统计区域应只显示以下区块：
   - 1 个 `token_iter` 区块（含首字延迟/TPS/用量百分比）
   - 1 个 `token_task` 区块（含输入/输出/总计）
2. 不应存在只有分隔线而无内容的空区块
3. `token_iter` 和 `token_task` 不应重复出现

## 验证方法

发送消息后检查终端输出中 `────` 分隔线之间的区块：

```
────────────────────────────────────────────────────────────────────────────────
Token用量: ...
────────────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────────────
本次任务 Token 总计: ...
────────────────────────────────────────────────────────────────────────────────
```

以上为完整的、不应有任何额外重复的 token 统计输出。

# FIX-333: 英文资源中文英文化

## 背景

`i18n/en.go` 英文资源中大量条目实际存储的是中文（误复制自 zh.go 中文内容）。其中 `KeyCmdMig_*` 系列 381 个 key（模型/模式/向导管理类输出文本）在 en.go 与 zh.go 中值完全一致，全部为中文。另有 5 处零散条目（`KeySettingCmd_613/614/615`、`KeyNoActiveTaskPlan`、`KeyNoRecentIterations`）也含中文样例或双语文案。英文环境下用户看到的是中文输出，不符合"英文资源应使用英文"的国际化要求。

## 修复方案

新增 `bin/translate_en_cmdkeys.py` 脚本，内置 381 条 `KeyCmdMig_*` 的中文→英文映射：

- 按行正则匹配 `KeyCmdMig_\d+: "..."`（支持尾逗号与 Tab 缩进），仅替换值为英文映射，保留 Go 字符串转义（`%s`/`%d`/`\n`/`\"` 等）与格式占位符
- 执行 `gofmt -w i18n/en.go` 恢复 Go 源码规范缩进
- 手工修正剩余 5 处含中文/全角符号的条目：
  - `KeySettingCmd_613`：示例从中文改为英文（'analyze the chart data' 等）
  - `KeySettingCmd_614`：'微软雅黑' → 'Microsoft YaHei'
  - `KeySettingCmd_615`：content 示例 '## 3.2 新章节\n\n这是新内容段落。' → '## 3.2 New Section\n\nThis is the new content paragraph.'
  - `KeyNoActiveTaskPlan`：全角双语 → 纯英文 "No active task plan"
  - `KeyNoRecentIterations`：全角双语 → 纯英文 "No recent iterations"

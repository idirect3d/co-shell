# FEATURE-400 TOOL 输入参数子块

## 背景

TOOL 调用时，动态输出的输入参数（tool_call_stream 流式片段）累积显示，之后被执行前摘要（phase=input 参数摘要）替换冲掉。希望将动态输出的输入参数内容输出到当前 TOOL 块中的一个子块：子块有滚动条、子标题栏（"输入参数"）、标题栏右上角有完全展开/固定高度切换按钮，固定高度时可滚动。

## 验收标准

1. TOOL 块中，动态输出的输入参数（流式片段）输出到一个子块（`tool-params`）。
2. 子块有子标题栏（"输入参数"）。
3. 子块标题栏右上角有完全展开/固定高度切换按钮。
4. 子块内容在固定高度时可以滚动（有滚动条）。
5. 执行前摘要（phase=input）不再替换流式参数（子块就是参数容器）。
6. 执行结果（phase=result）追加到 TOOL 块 body。
7. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 输入参数子块存在
- 前置：Web UI 已加载，触发 TOOL 调用（有流式参数）
- 步骤：观察 TOOL 块
- 期望：TOOL 块中有输入参数子块（`tool-params`），子标题栏显示"输入参数"

### UC-002 流式参数累积进子块
- 前置：Web UI 已加载，触发 TOOL 调用
- 步骤：观察流式参数输出
- 期望：流式参数片段累积显示在子块内容区

### UC-003 子块有滚动条
- 前置：Web UI 已加载，触发 TOOL 调用（参数较多）
- 步骤：观察子块
- 期望：子块内容在固定高度时可滚动（有滚动条）

### UC-004 展开/固定高度切换按钮
- 前置：Web UI 已加载，触发 TOOL 调用
- 步骤：点击子块标题栏右上角的切换按钮
- 期望：子块在完全展开和固定高度之间切换

### UC-005 执行前摘要不替换流式参数
- 前置：Web UI 已加载，触发 TOOL 调用
- 步骤：观察执行前摘要（phase=input）到来后的子块
- 期望：子块仍显示流式参数，不被参数摘要替换

### UC-006 执行结果追加到 TOOL 块
- 前置：Web UI 已加载，触发 TOOL 调用
- 步骤：观察执行结果（phase=result）到来后的 TOOL 块
- 期望：执行结果追加到 TOOL 块 body（子块之后）

- 前置：无

- 期望：全部通过，无编译错误、无 vet 告警

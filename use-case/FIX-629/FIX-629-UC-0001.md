# FIX-629 UC-0001：ask 问答弹窗去掉底部重复按钮、警告上移进度行

> 分支：**FIX-629**　版本：**v0.108.4**　BUILD：**待编译**
> 需求（用户 2026-10-10 13:08 提出，13:12/13:13 确认）：
> ① 核实：多题表单底部操作条里的 “[回车] 下一个/确认” 与 “[−] 我要再想想，先退出” 是否与当前题提示行重复 → **确认重复**；
> ② 保留提示行的 “[-] 取消”（键帽可点击、键盘 `-` 仍等同于点击它），删除底部 “[−] 我要再想想，先退出”；
> ③ 同时删除底部重复的 “[回车] 下一个/确认”；
> ④ 必答未答警告 `.qs-warn` 上移到 `Question N/M` 进度行右侧。
>
> 目标：缩减该弹窗占用的垂直空间（底部整行消失）。

## 现状与根因（改动前）

| 层次 | 内容 | 位置 |
|---|---|---|
| 顶部进度 | `Question N/M` + 已答数量 + 进度条 | `renderQuestions()`，`.qs-progress*` |
| 当前题卡片 | 选项（数字热键）、备注输入 | `.qs-card` / `.qs-option` / `.qs-hotkey` |
| 当前题提示行 | `[回车] 下一个或确认 · [+] 上一个 · [空格] 备注 · [-] 取消`（键帽均可点击） | `renderHint()`，`.qs-hint` |
| 底部操作条 | `.qs-submit`（`[回车] 下一个/确认`）+ `.qs-warn` + `it.keys` 固定键按钮（`[-] 我要再想想，先退出`） | `.qs-bar` |

- **回车重复**：提示行的 `[回车]` 与底部 `.qs-submit` 是同一个键、同一个动作（`goNext()` / 最后一题 `submitAnswers()`）。
- **取消重复**：底部固定键来自后端 `it.keys`（`agent/ask_user.go:100`，`{Key:"-", Value:"think_exit"}`，标签“我要再想想，先退出”），与提示行的 `[-] 取消` 是同一个 `think_exit` 动作，仅措辞不同。

## 设计基线（本次改动）

| 位置 | 变更 |
|------|------|
| `web/static/app.js` → `renderQuestions()` | 不再创建 `.qs-bar`：删除 `.qs-submit` 按钮与 `it.keys` 固定键按钮；`qsWarn` 改挂到 `.qs-progress-head` 右侧 |
| `web/static/app.js` → `refreshSubmit()` | 收缩为“清除必答高亮 + 警告显隐 + 进度刷新”（函数名与调用点保持不变） |
| `web/static/app.js` → `renderHint()` / 键盘处理 | **不变**：`[回车]`、`[+]`、`[空格]`、`[-]` 键帽仍可点击；键盘 `Enter` / `-` / `+` / `空格` / 数字仍生效 |
| `web/static/style.css` | 删除失去引用的 `.qs-bar` / `.qs-submit`（及仅此处使用的 `.qs-key`）；补 `.qs-warn` 在进度行右侧的排版（不换行、靠右） |
| 不改动 | 后端（`agent/ask_user.go`、`interaction_questions.go`）、提交协议、`index.html` |

## 术语

- **(R)** 离线静态校验　**(M)** 运行时浏览器断言
- **think_exit**：`[-] 取消` 对应的固定键值（“我要再想想，先退出”），提交后表单关闭。

## 用例清单

### UC-01 (R) 底部操作条不再创建

- 断言：`app.js` 的 `renderQuestions()` 中不再出现 `.qs-bar` 与 `.qs-submit` 的创建，也不再由 `it.keys` 生成按钮。
- 验证命令：`grep -n "qs-bar\|qs-submit\|qs-key" web/static/app.js web/static/style.css`

### UC-02 (R) 提示行保留全部键帽

- 断言：`renderHint()` 仍包含 `qsKeyEnter`（回车）、`qsKeySpace`（空格）、`+`（上一个）、`-`（取消，绑定 `cancelForm`）。
- 断言：每个键帽都是可点击按钮（`kbdSpan(p.kbd, p.click)`）。

### UC-03 (R) 提交/取消动作与键盘处理未被削弱

- 断言：`goNext()` / `submitAnswers()` / `cancelForm()` 逻辑不变；`cancelForm()` 仍取 `it.keys` 中 `think_exit` 发送 `{action:"select", value:"think_exit"}`。
- 断言：全局 keydown 处理仍响应 `Enter`（前进/提交）、`-`（取消）、`+`（上一个）、`空格`（备注）、数字（选选项）。

### UC-04 (M) 底部不再出现重复按钮

- 断言：弹窗底部**没有** “[回车] 下一个/确认” 按钮，也**没有** “[-] 我要再想想，先退出” 按钮；底部整行不再占高度。
- 断言：同一信息的唯一入口是当前题提示行（`[回车] … · [+] 上一个 · [空格] 备注 · [-] 取消`）。

### UC-05 (M) 提示行键帽点击仍可用

- 断言：点击 `[回车]` 键帽 = 前进（最后一题 = 提交）；点击 `[-]` 键帽 = 取消（发送 `think_exit`，表单关闭）。

### UC-06 (M) 键盘快捷键仍可用

- 断言：不点击任何按钮，按 `Enter` 前进/提交、按 `-` 取消，行为与点击提示行键帽一致。

### UC-07 (M) 必答未答警告出现在进度行右侧

- 断言：存在必答未答时按回车，警告文案出现在 `Question N/M` 进度行**右侧**（不再是底部行），内容与措辞不变；
- 断言：把必答补齐后警告消失。

### UC-08 (R) 编译与版本一致性

- 断言：`go build ./... && go vet ./...` 通过。
- 断言：`main.go` `version` 与 `cmd/co-shell-hub/main.go` `hubVersion` = `0.108.4`；`build`/`hubBuild` 同步递增且相等。
- 断言：二进制与 App 可构建（App 输出到独立目录，不覆盖运行中的 bundle）。

### UC-09 (R) 改动范围最小

- 断言：`git diff --name-only` 只含 `web/static/app.js`、`web/static/style.css`、`ROADMAP.md`、`main.go`、`cmd/co-shell-hub/main.go`、`use-case/FIX-629/**`。
- 断言：未改 `web/static/index.html`、后端 Go 逻辑、App 源码。

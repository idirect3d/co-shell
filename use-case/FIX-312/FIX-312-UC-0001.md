# FIX-312: OpenAI 模式系统提示词出现 "==== system_prompt_tool_usage"

## 现象

openai 工具调用模式下，系统提示词中出现原始 i18n key：

```
==== system_prompt_tool_usage
```

其中 `====` 是节分隔符，`system_prompt_tool_usage` 是 i18n key 而非实际内容。该 key 字符串被当作 ToolUsage 节的内容写入 system prompt，污染发给 LLM 的提示词。

## 排查结论（根因）

| 事实 | 证据 |
|---|---|
| `ToolUsage` 节在 OpenAI 模式下应输出空内容 | i18n/zh_system.go:77、i18n/en_system.go:54 中 `zhMessages[KeySystemPromptToolUsage] = `` ` / `enMessages[KeySystemPromptToolUsage] = `` ` |
| `i18n.T()` 对空值翻译回退返回原始 key | i18n/i18n.go:114-129：`lookup()` 对「key 存在但值为空」与「key 不存在」都返回 `""`，`T()` 无法区分，最终 `return key` |
| `toolUsageText[0]` 拿到的是原始 key 而非空串 | agent/agent.go:54（`New()`）与 agent/agent.go:973（`rebuildSystemPrompt()`）传入 `i18n.T(i18n.KeySystemPromptToolUsage)` |
| `toolUsageText[0]` 非空时覆盖段落内容 | agent/system_prompt.go:332-334 |
| XML 模式未暴露此问题 | XML 模式的 `toolUsageText` 由 `BuildToolUsagePrompt(ToolCallModeXML, ...)` 动态生成非空内容 |

**根因定论**：`i18n.T()` 的回退逻辑无法区分「key 存在但翻译为空字符串（合法的『无内容』语义）」与「key 不存在」，导致 OpenAI 模式被故意清空的 `system_prompt_tool_usage` 返回了原始 key 字符串。

## 修复内容

### `i18n/i18n.go`

修改 `lookup()` 返回 `(string, bool)` 二元组，区分「key 存在」与「key 不存在」：

- `lookup(lang, key)` 返回 `(msg, ok)`；key 存在（即使值为空串）时 `ok=true`。
- `T(key)`：
  - 当前语言存在该 key → 直接返回翻译（可能是空串，表示「无内容」）。
  - 否则回退中文；中文也不存在 → 返回原始 key（保留开发期调试 fallback 行为）。

此修复同时解决其他被故意清空的 key（如 `KeyWorkModeAct/Plan/Research`）潜在的同类泄漏。

## 修复效果

- OpenAI 模式系统提示词不再出现 `==== system_prompt_tool_usage`；ToolUsage 节为空 → `buildSystemPromptWithMode` 跳过该节，不再输出分隔符。
- 完全缺失的 key 仍返回原始 key，不影响其他依赖该 fallback 的代码路径。

## 用例（循环模式）

| # | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| 1 | 空值翻译不泄漏 key（zh） | `i18n.SetLang("zh")` 后 `i18n.T("system_prompt_tool_usage")` | 返回 `""`（空串），而非 `"system_prompt_tool_usage"` |
| 2 | 空值翻译不泄漏 key（en） | `i18n.SetLang("en")` 后 `i18n.T("system_prompt_tool_usage")` | 返回 `""`（空串），而非 `"system_prompt_tool_usage"` |
| 3 | 缺失 key 仍返回原始 key | `i18n.T("no_such_key_xyz")` | 返回 `"no_such_key_xyz"`（fallback 不变） |
| 4 | 正常翻译不受影响 | `i18n.T(i18n.KeyError)` | 返回中/英文翻译，非原始 key |
| 5 | 集成：OpenAI 模式 system prompt 无泄漏 | `buildSystemPromptWithMode` 传入 `i18n.T(i18n.KeySystemPromptToolUsage)` 作为 `toolUsageText[0]` | 结果不包含 `"system_prompt_tool_usage"` 子串 |
| 6 | 集成：XML 模式行为不变 | `BuildToolUsagePrompt(ToolCallModeXML, tools, lang)` 后走 `buildSystemPromptWithMode` | XML 工具说明正常生成，不含原始 key |

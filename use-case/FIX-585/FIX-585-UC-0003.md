# FIX-585-UC-0003 移动端：启动屏白等去除 + AppIcon 重制（B / C 组）

> 分支：`FIX-585` ｜ 版本：`v0.91.1` ｜ 编号：FIX-585
> 背景：为发布 App Store 做准备。用户反馈（2026-10-02）：① 启动时「白底 + 黑色 co-shell 文字」停留，属无意义的等待；② 图标左右两条较粗光影线条要删掉，改为上边缘光照明显、下边缘弱于上边缘。
> 代码层用例见 `FIX-585-UC-0001.md`，运行时条目见 `FIX-585-UC-0002.md`。

## 一、B 组：启动屏白等去除

### 现状（实测）

| 项 | 现状 |
|---|---|
| `mobile/ios/Runner/Base.lproj/LaunchScreen.storyboard` | 背景 `rgb(1,1,1)`（纯白）+ 居中 `co-shell` 黑字（semibold 28pt） |
| `WebViewController` | `WKWebView` 未设 `isOpaque`/背景色 → 加载期默认**白底**（深色模式下同样白屏） |

### 方案

1. 启动屏去掉文字；背景改为**自适应颜色集** `Assets.xcassets/LaunchBackground.colorset`（Any = 系统背景白，Dark = 黑），与首屏 `view.backgroundColor = .systemBackground` 一致 → 启动屏到首屏**无可见跳变**。
2. `WebViewController`：`webView.isOpaque = false`，`webView.backgroundColor` / `webView.scrollView.backgroundColor` 设为同一自适应背景 → 网页加载期不再白屏。
3. **不改** 导航栏标题（`CoShellLogoView` + `co-shell` 文字保持不变）。

### 用例

| 编号 | 名称 | 步骤 | 期望结果 |
|---|---|---|---|
| RT-B1 | 浅色模式冷启动 | 模拟器（浅色外观）冷启动 App | ① 启动屏**无文字**、无白底黑字停留；② 启动屏 → 首屏 → 网页无可见跳变/闪烁 |
| RT-B2 | 深色模式冷启动 | 模拟器（深色外观）冷启动 App | ① 启动屏为近黑背景；② **全程无白色闪屏**（启动屏、网页加载期均为深色） |
| RT-B3 | 已配置直连 | 已配置服务端/KEY 时冷启动 | 直接进入 Web UI；加载期背景与启动屏同色，无白屏 |
| RT-B4 | 首次启动（未配置） | 清除配置后冷启动 | 进入原生设置页；启动屏 → 设置页过渡自然（无白色闪屏） |
| RT-B5 | 静态校验 | 检查 storyboard 与资源 | ① storyboard 内不再出现 `co-shell` 文本节点与纯白背景字面量；② `LaunchBackground.colorset` 存在且被 storyboard 引用；③ `xcodebuild` 编译通过 |

## 二、C 组：AppIcon 重制

### 现状（视觉分析实测，1024 主图）

| 部位 | 现状 |
|---|---|
| 左右两侧 | 各一条**粗竖直光带**（左 x≈35–70、右 x≈955–990，宽约 25–35px，色 ≈`#2E6B3E`/`#2A6138`）——本次要去掉 |
| 上下边缘 | 仅 2–4px 细描边（上 ≈`#2F7040`、下 ≈`#24552F`）——本次要改造为上强下弱的边缘光 |
| 主体 | 暗绿 squircle + 中央像素外星人 + 左下 `›_` 提示符（≈`#3DE86B`）——**保持不变** |

### 方案（确定性像素处理，非重绘、非 AI 生成）

1. **去侧带**：以水平插值填充左右带区（用带两侧干净背景列线性插值），使该区域回到与相邻背景一致的平滑渐变。
2. **加边缘光**：沿 squircle 轮廓叠加边缘高光——上边缘 0–6px 亮芯 + 约 20px 柔和衰减（明显）；下边缘同等结构但强度约为上边缘的 1/2～2/3（弱于上边缘）。
3. **重采样**：由 1024 主图 LANCZOS 生成 20/29/40/60/76/83.5 各尺寸，`Contents.json` 不变；导出 PNG 不带 alpha（App Store 要求）。

### 用例

| 编号 | 名称 | 判据（脚本量化 + 人工目视） |
|---|---|---|
| RT-C1 | 左右粗光带已消除 | 对 y∈[200,824] 逐行比较「原带内列均值」与「带外 20px 参考列均值」的亮度差 \|Δ\|：修复前 ≥20/255 → 修复后 **≤3/255**（无亮度阶跃） |
| RT-C2 | 上边缘光照明显、强于下边缘 | 沿 squircle 轮廓取上/下各 0–4px 环带平均亮度增量 Δtop、Δbot：满足 **Δtop > Δbot > 0** 且 **Δtop / Δbot ≥ 1.5** |
| RT-C3 | 主体不变 | 原图高亮绿前景（像素外星人 + `›_` 提示符）区域改动 **≤2/255**，位置与尺寸不变；squircle 外形与配色基调不变 |
| RT-C4 | 尺寸齐全一致 | `AppIcon.appiconset` 内 15 个 PNG 全部由 1024 主图重采样，视觉一致、无拉伸错位；`Contents.json` 未改动 |
| RT-C5 | 设备观感 | 模拟器/真机 Home 屏：深色壁纸下轮廓清晰，边缘光自然（上强下弱），无左右"边框感" |
| RT-C6 | 交付物 | ① 重制后的 15 个 PNG；② 可复现的生成/校验脚本（拟放 `mobile/tools/appicon_regen.py`，输出上述量化指标）；③ 校验输出摘要附在验收记录中 |

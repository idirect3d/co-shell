# FIX-585-UC-0002 工具超时不再误报为“用户中断” · 运行时端到端用例

> 分支：`FIX-585` ｜ 版本：`v0.91.1` ｜ 编号：FIX-585
> 代码层用例见 `FIX-585-UC-0001.md`；移动端条目见 `FIX-585-UC-0003.md`。
> 本文即**用户复核清单**：逐条执行后，通过日志与界面即可确认修复是否达标。

---

## 一、测试环境

| 项 | 值 |
|---|---|
| 程序 | `work/co-shell-0.91.1.darwin.arm64`（本平台编译产物） |
| 启动命令 | `work/co-shell-0.91.1.darwin.arm64 --serve --port <端口> --yolo`（**必须带 `--serve`**，避免自动开浏览器占用单客户端连接） |
| 日志 | `log/co-shell-<今日>.log`（日志开关已开、级别 info） |
| 观测方式 | ① Web 界面消息流；② `grep` 日志关键行 |

**统一判据**：
- 超时 → 日志含 `Timeout kill: killing process group of PID ... after Ns timeout`，**不含** `interrupted by user`；界面报“命令超时”，**本轮对话继续**。
- 用户中断 → 日志含 `Interrupt: killing process group of PID ...` 与 `interrupted by user (reason=web-interrupt)`；界面出现中断提示，本轮结束。

## 二、用例

| 编号 | 名称 | 步骤 | 期望结果（可核验） |
|---|---|---|---|
| RT-A1 | 超时不再中断本轮 | 让 agent 执行 `sleep 90`（`timeout_seconds=30`, `on_timeout=kill`） | ① 约 30s 后工具返回超时错误（文案含 `timed out after 30 seconds`）；② **本轮未结束**，agent 可在同一轮继续（例如汇报“命令超时”并给出后续动作）；③ 日志有 `Timeout kill: ... after 30s timeout`，无 `interrupted by user`；④ 界面无“工具已中断”提示 |
| RT-A2 | 真实中断仍生效（回归 FEATURE-582） | 执行 `sleep 60`（`timeout_seconds=120`），运行中按 ESC / 暂停按钮 | ① ≤1s 内中断并回输入态；② 日志有 `Interrupt: killing process group of PID ...` 与 `interrupted by user (reason=web-interrupt)`；③ 未闭合的 assistant 消息与本轮工具结果被丢弃（保持原行为） |
| RT-A3 | **原缺陷场景复现验证** | 执行 `grep -ril "splash" --include=* .`（`timeout_seconds=60`，工作区含 ~1GB 日志目录） | ① 60s 后按超时终止；② **会话不再被“中断”**：日志为 `Timeout kill:`（非 `Interrupt:`）、无 `interrupted by user`；③ agent 收到超时错误后能继续对话（如改为限定目录重搜） |
| RT-A4 | 中断后连续可用 | RT-A2 中断后立即再发一条普通指令（如 `echo hi`） | 正常执行并返回；中断标记在新一轮被清除（`InterruptTool: already interrupted` 不再出现于新轮） |
| RT-A5 | 全局回归 | `go build ./... && go vet ./...`（一次完整执行）；`go test ./...` | 全绿；与 main 基线失败集一致（无新增失败） |
| RT-A6 | 日志可区分（文案检查） | `grep -cE "Timeout kill" log/co-shell-<今日>.log` 与 `grep -cE "interrupted by user \(reason=\)" log/co-shell-<今日>.log` | 前者 ≥1（RT-A1/A3 产生）；后者 = 0（**空 reason 的“被中断”记录不再出现**） |

## 三、通过标准

- RT-A1/A3/A6 为用户报告的缺陷点，**必须全部通过**；
- RT-A2/A4 用于确认未破坏 FEATURE-582 的中断语义，**必须全部通过**；
- RT-A5 为质量门禁，**必须全绿**。

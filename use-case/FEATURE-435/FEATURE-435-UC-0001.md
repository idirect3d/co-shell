# FEATURE-435 文件预览标题栏改进

## 背景

文件预览（FEATURE-425/432）的悬浮标题栏位于文件显示区域顶部，用户需精确滑过标题栏才能高亮（区域太小不易操作）；关闭图标颜色不突出；md 文件缺少 Raw 开关切换原始文本/解析渲染。

## 方案

1. **标题栏移到文件显示区域下方**：标题栏从顶部（`top: 8px`）移到文件显示区域底部，与底边留一些空间。
2. **关闭图标用高亮颜色**：关闭图标（✕）用高亮颜色（如 accent 色），不再用暗淡色。
3. **鼠标滑过文件显示区域下方 100px 区域标题栏即高亮**：不必精确滑到标题栏，滑过文件显示区域下方 100px 区域标题栏就开始高亮（避免标题栏太小看不清）。
4. **md 文件时增加 Raw 按钮开关**：在标题栏相同水平位置，旁边增加一个与标题栏风格类似的 Raw 按钮开关，用来切换原始文本和解析渲染，默认为关（即默认自动渲染 md）。

## 验收标准

1. 文件预览标题栏显示在文件显示区域下方，与底边留空间。
2. 关闭图标用高亮颜色显示。
3. 鼠标滑过文件显示区域下方 100px 区域，标题栏即高亮（不必精确滑到标题栏）。
4. 打开 md 文件时，标题栏同水平位置旁边显示 Raw 按钮开关，默认为关（自动渲染 md）。
5. 点击 Raw 开关打开时，md 文件显示原始文本；关闭时恢复解析渲染。
6. 非 md 文件不显示 Raw 按钮开关。
7. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

- 期望：标题栏显示在文件显示区域下方，与底边留空间（不再在顶部）

### UC-002 关闭图标用高亮颜色
- 前置：Web UI 启动，打开一个文本文件预览
- 步骤：观察标题栏关闭图标（✕）颜色
- 期望：关闭图标用高亮颜色（accent 色）显示

### UC-003 鼠标滑过文件显示区域下方 100px 区域标题栏即高亮
- 前置：Web UI 启动，打开一个文本文件预览
- 步骤：鼠标滑过文件显示区域下方 100px 区域（不必精确滑到标题栏）
- 期望：标题栏即开始高亮（背景填充、文字清晰）

### UC-004 md 文件显示 Raw 按钮开关（默认为关）
- 前置：Web UI 启动，打开一个 md 文件预览
- 步骤：观察标题栏同水平位置

- 前置：Web UI 启动，打开一个 md 文件预览

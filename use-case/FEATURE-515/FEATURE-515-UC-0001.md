# FEATURE-515 测试用例 — Web UI 交互优化（THINK 块固定高度 / 文件列悬停延时 / hub 边栏悬停延时）

> 分支：FEATURE-515
> 版本：v0.54.0
> 关联任务：FEATURE-515
> 关联特性/缺陷：FEATURE-400 / FEATURE-461（固定高度 + 展开按钮的既有范式）、FEATURE-383（工作区侧栏长文件名自适应宽度）、FEATURE-492（hub 左侧热区抽屉）

## 背景

本次为三处既有交互做「限高 / 延时」优化，均属前端行为调整，无后端接口变更：

1. **co-shell THINK 块**：当前思考内容全部展开，长思考会把事件流撑得很长。需求是按既有 TOOL 输入参数块（`.tool-params-body{max-height:200px;overflow-y:auto}`）的范式，给 THINK 正文固定 200px 高度、超出内部滚动，并在标题栏提供展开/收起按钮（用户已确认：按钮**始终显示**，高度 **200px**）。
2. **co-shell 工作区文件列表**：当前 `row.mouseenter` 一旦发现名称被截断（`name.scrollWidth > name.clientWidth`）就**立即**给 `#layout` 加 `sidebar-auto`（侧栏自适应加宽）。需求是鼠标**停留超过 1 秒**才加宽，1 秒内移开不触发。
3. **co-shell-hub 左侧热区**：当前 `edge.mouseenter` 直接 `openPanel()`，鼠标扫过左边缘即弹出抽屉。需求是**停留超过 1 秒**才展开。

## 验收标准

- THINK 块正文默认最大高度 200px，内容超出时块内滚动；标题栏常驻展开/收起按钮，点击后正文完整展开（再点回到固定高度）。
- 工作区文件行悬停满 1 秒才加宽侧栏；不足 1 秒不改变布局。
- hub 左边缘悬停满 1 秒才展开 Agents 抽屉；不足 1 秒不展开。
- `go build ./... && go vet ./...` 通过。

## 运行时用例

### UC-0001 THINK 块超长内容 → 固定 200px + 内部滚动（核心）

**前置条件**
- `co-shell --serve --port <port>` 启动（Web UI 测试必须带 `--serve`，避免自动打开的系统浏览器占用单客户端连接），浏览器打开页面。

**步骤**
1. 发送一个会触发长思考的请求（例如「请逐步推理：用 30 行以上说明 X 的推导过程」）。
2. 待 THINK 块渲染出明显超过 200px 的内容。

**预期**
- THINK 块正文区域高度约 200px，不再随内容继续增高。
- 正文内部可滚动（出现滚动条，滚轮只滚动该块，页面不被撑长）。
- 标题栏右侧可见展开按钮（⤢）。

### UC-0002 THINK 块展开/收起按钮 → 展开后完整显示，再点回到固定高度

**步骤**
1. 在 UC-0001 的 THINK 块上点击展开按钮（⤢）。

**预期**
- 正文完整展开（无高度上限、无内部滚动条），按钮变为收起图标（⤡）。
- 再次点击 → 回到 200px 固定高度并恢复内部滚动，按钮变回 ⤢。

### UC-0003 THINK 块短内容 → 按钮仍在，正文不出现滚动条（对照）

**步骤**
1. 触发一次只产生一两行思考的请求。

**预期**
- 正文高度自适应（小于 200px），不出现无用滚动条。
- 展开/收起按钮依然显示（用户确认：始终显示）。

### UC-0004 流式思考过程中 → 高度保持恒定，不随内容增长而抖动

**步骤**
1. 触发长思考，观察 THINK 块从开始到结束的渲染过程。

**预期**
- 块高度在内容超过 200px 后即保持恒定，事件流滚动位置不被反复推挤。

### UC-0005 THINK 块的折叠动作（标题栏 ▾）与展开按钮互不干扰

**步骤**
1. 点击 THINK 块标题栏的折叠按钮（▾），确认整块收起为标题栏。
2. 再次点击展开整块，然后点击块内展开按钮（⤢）。

**预期**
- 折叠/展开（整块显隐）与固定高度/完整高度（正文限高）两种状态互不影响，均可正常切换。

### UC-0006 历史回放中的 THINK 块 → 同样限高且按钮可用（回归）

**步骤**
1. 刷新页面，等待历史回放完成（含 THINK 块）。

**预期**
- 回放出的 THINK 块同样为 200px 固定高度 + 可展开，按钮可点击。

### UC-0007 文件列表长名称悬停 <1s → 侧栏不加宽（核心）

**前置条件**
- 工作区中存在名称长到在侧栏中被截断（显示省略号）的文件或文件夹。

**步骤**
1. 鼠标移入该长名称行，停留约 0.5 秒后移出。

**预期**
- 侧栏宽度**不变**（不出现自适应加宽）。

### UC-0008 文件列表长名称悬停 >1s → 侧栏加宽（核心）

**步骤**
1. 鼠标移入同一长名称行，静止停留超过 1 秒。

**预期**
- 约 1 秒后侧栏自动加宽至可完整显示最长名称。

### UC-0009 快速掠过多个文件行 → 不发生加宽抖动

**步骤**
1. 鼠标自上而下快速划过若干行（含长名称行），每行停留 <0.3s。

**预期**
- 侧栏全程不加宽；无闪烁。

### UC-0010 短名称文件行悬停 >1s → 侧栏不加宽（对照）

**步骤**
1. 鼠标移入名称未被截断的行并停留 2 秒。

**预期**
- 侧栏不加宽（该行名称本就完整可见）。

### UC-0011 加宽后移出侧栏 → 1s 后恢复固定宽度（既有行为回归）

**步骤**
1. 按 UC-0008 使侧栏加宽。
2. 鼠标移出侧栏区域。

**预期**
- 约 1 秒后侧栏恢复原固定宽度（FEATURE-383 既有行为保持不变）。

### UC-0012 hub 左边缘悬停 <1s → 抽屉不展开（核心）

**前置条件**
- 运行 `co-shell-hub --serve`，浏览器打开 hub Web UI。

**步骤**
1. 鼠标从左侧快速划入边缘热区（约 0.3 秒）后移开。

**预期**
- Agents 抽屉**不展开**，页面保持原状。

### UC-0013 hub 左边缘悬停 >1s → 抽屉展开（核心）

**步骤**
1. 鼠标移入最左侧边缘区域并静止停留超过 1 秒。

**预期**
- 约 1 秒后 Agents 抽屉滑出展开，列出已注册 Agent。

### UC-0014 hub 徽标点击开合与热区延时互不冲突（回归）

**步骤**
1. 点击左上角 co-shell-hub 徽标 → 抽屉展开；再次点击 → 抽屉收起。
2. 再执行 UC-0013。

**预期**
- 徽标点击仍然是即时开合；热区延时逻辑不影响点击行为。

### UC-0015 热区划过即离开后再次停留 → 仍能正常展开（计时器复位）

**步骤**
1. 鼠标划入边缘热区 <0.5 秒后移出（不展开）。
2. 立即再次移入并停留 >1 秒。

**预期**
- 第二次停留能正常展开抽屉（计时器在离开时被清除，不残留旧计时）。

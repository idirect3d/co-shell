# FEATURE-410 测试用例：Web UI 模式切换胶囊控件

## 背景
在 Web UI 中增加模式切换功能：在页面底部状态条（statusbar）中靠左放置一个横向长胶囊分段控件，分为 1-N 段对应 1-N 个模式选项，每段有文字，高亮段代表选中，用户直接选择一段，高亮效果滑动到用户选择的段上。胶囊降低高度（调低文字上下间距）以免撑高状态条。

## 用例列表

### UC-001 胶囊控件显示在状态条靠左
- **前置**：Web UI 已启动，状态条已开启。
- **步骤**：打开 Web UI，观察页面底部状态条。
- **预期**：状态条最左侧出现一个横向长胶囊分段控件，包含所有模式段（act/plan/research 等），其他状态项靠右。

### UC-002 当前模式段高亮
- **前置**：Web UI 已启动，当前工作模式为 act。
- **步骤**：观察胶囊控件。
- **预期**：act 段高亮显示（active 样式），高亮滑块位于 act 段。

### UC-003 点击其他段切换模式且高亮滑动
- **前置**：胶囊控件已显示，当前模式为 act。
- **步骤**：点击 "plan" 段。
- **预期**：模式切换成功，plan 段变为高亮，高亮滑块平滑滑动到 plan 段。

### UC-004 切换后模式持久化
- **前置**：已通过胶囊控件切换到 plan。
- **步骤**：刷新页面。
- **预期**：胶囊控件中 plan 段仍高亮，说明切换已持久化到配置。

### UC-005 胶囊高度不撑高状态条
- **前置**：Web UI 已启动，状态条已开启。
- **步骤**：观察胶囊控件高度与状态条高度。
- **预期**：胶囊控件高度较低（文字上下间距调低），不会撑高状态条。

### UC-006 后端 mode_get 返回模式列表
- **前置**：WebSocket 已连接。
- **步骤**：前端发送 `mode_get` 消息。
- **预期**：后端返回 `mode` 消息，包含当前模式名和所有可用模式列表。

### UC-007 后端 mode_switch 切换模式（含内置模式）
- **前置**：WebSocket 已连接。
- **步骤**：前端发送 `mode_switch` 消息，value 为 "plan"（内置模式）。
- **预期**：后端切换模式成功，返回 `mode_result` 消息（ok=true），配置已更新。内置模式（act/plan/research）均可切换。

### UC-008 运行/暂停按钮左侧无模式按钮
- **前置**：Web UI 已启动。
- **步骤**：观察输入行运行/暂停按钮（▶）左侧。
- **预期**：运行/暂停按钮左侧没有模式切换按钮（已移除，改为状态条中的胶囊控件）。

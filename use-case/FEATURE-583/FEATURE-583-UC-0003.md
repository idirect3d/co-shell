# FEATURE-583-UC-0003 技能标签矢量图标与分类顺序

## 需求

1. 系统设置页左侧分类中，「技能」分类的图标不再复用 MCP 的插头图标，改为**专属矢量图标**（钢琴键盘造型，矢量 SVG）：琴体宽高比 **5:4**，4 个白键（3 条分隔线）+ 3 个黑键（半音键，位于分隔线处，长度约琴体高度 2/3）。
2. 「技能」分类移动到「MCP Server」分类**上方**。
3. 「已加载技能」面板标题（右侧任务面板内的 skillHead）使用**同一个**矢量图标，保持视觉一致。

## 运行时用例

### UC-0003-01 技能分类图标为专属矢量图标
- 前置：co-shell 以 `--serve` 启动，打开系统设置。
- 步骤：观察左侧分类「技能」一行的图标。
- 预期：显示钢琴键盘造型的矢量图标（`#i-skills`），且与「MCP Server」的插头图标（`#i-mcp`）**不同**；线条粗细/尺寸与其他分类图标一致（1em、currentColor）。

### UC-0003-02 技能分类位于 MCP Server 上方
- 前置：同 UC-0003-01。
- 步骤：读取左侧分类列表自上而下的顺序。
- 预期：「技能」紧邻「MCP Server」**上方**；其余分类相对顺序不变。

### UC-0003-03 切换分类后刷新仍停留在当前分类
- 前置：同 UC-0003-01。
- 步骤：选中「开发者」分类，触发一次设置刷新（如修改任一设置项后重新拉取设置）。
- 预期：仍停留在「开发者」分类（FEATURE-470 行为不因本次插入分组而回归）。

### UC-0003-04 已加载技能面板标题带同一图标
- 前置：会话中已加载至少一个 skill（`skill_load` 或设置页加载）。
- 步骤：观察右侧面板「已加载技能」标题。
- 预期：标题左侧显示与设置页「技能」分类相同的钢琴键盘矢量图标，文字与图标间距正常。

### UC-0003-05 中英文界面均正常
- 前置：同 UC-0003-01。
- 步骤：切换界面语言（中/英）。
- 预期：「技能 / Skills」分类名与图标均正常显示，无键名泄漏、无图标丢失。

## RT-0001 REPL：LLM 自主加载与卸载

- **步骤**：在 REPL 提出一个明显需要某技能的请求（如"用 image-generate 生成一张图"），让模型自行调用 `skill_load`；随后要求"卸载刚才加载的技能"。
- **期望**：
  1. 工具调用行显示 `skill_load`，其后有加载提示行（含技能名、字节数、累计字节、估算 token）；
  2. 同一轮内模型**不再**重复 `read_file` 该 SKILL.md（提示词中已说明无需重复读取）；
  3. 卸载时输出对应提示行，且文案明确"内容将在下一次上下文重整时移除"。

## RT-0002 REPL：用户手动干预命令

- **步骤**：`:skill list`；`:skill load demo`；`:skill list`；`:skill reload demo`；`:skill unload demo`；`:skill list`。
- **期望**：`list` 标注 `[loaded]`、来源（workspace/global）、字节数与 sha256 前 8 位；`load/unload/reload` 与 LLM 工具共享同一状态；`reload` 能刷新为磁盘最新内容；非法名/未加载名给出明确提示（不崩溃）。

## RT-0003 Web UI：已加载技能区

- **步骤**：`--serve` 启动 Web UI → 触发一次 `skill_load` → 观察界面。
- **期望**：在"任务进展/子代理"同区域出现**已加载技能**列表（名称、来源、大小、加载时间）；卸载后该条目消失；刷新页面后状态与后端一致。

## RT-0004 设置页：Skills 启用/禁用

- **步骤**：打开系统设置 → Skills 页 → 关闭 `demo` 的开关 → 回到会话（或新会话）提出需要 `demo` 的请求 → 再开启开关复测。
- **期望**：
  1. 页面上半部列出当前 skill 清单（名称/来源/大小/描述/是否已加载）+ 每项滑动开关；未配置项显示为"跟随默认"；
  2. 关闭后：该技能不再出现在 SKILLS 索引中，模型也无法加载（若强行加载应报"已被禁用"）；
  3. 重新开启后：索引恢复、可正常加载；
  4. 页面下半部"默认启用"开关：置为关闭后，新增（或未配置过）的技能默认不可见/不可加载，需手动开启（白名单用法）。

## RT-0005 压缩实测：内容不丢失（R3 关键）

- **步骤**：加载 `demo` → 让会话持续到上下文接近阈值，触发 `reorganize_context`（或手动要求模型调用）；压缩完成后继续追问 demo 技能里的某个细节。
- **期望**：压缩后模型仍能准确回答 SKILL.md 中的细节（说明正文完整在场）；若用 `:context` 查看，可见 pinned 的 assistant+tool 消息对仍在（位于 system 之后、摘要消息之前）。

## RT-0006 window 裁剪与会话切换

- **步骤**：把上下文策略设为 window（`context-policy=window` 且 limit=-1）并触发裁剪；随后切换会话再切回。
- **期望**：裁剪后 pinned 内容仍在；切回会话后加载集合与内容按"状态+磁盘"恢复（含"文件已变更提示"若有）。

## RT-0007 重启恢复

- **步骤**：加载 `demo` → 退出程序 → 用同一 session 重新启动 → 继续对话。
- **期望**：加载状态与内容恢复；`:skill list` 显示 `[loaded]`；若磁盘文件已变更，提示可用 `:skill reload`。

## RT-0008 告警可见（D-E）

- **步骤**：加载一个正文较大的 SKILL.md（超过单文件阈值）或连续加载多个技能使累计超阈值。
- **期望**：加载**成功**（不被拒绝）；REPL 行 / 工具结果 / Web 事件中出现 `warn` 与估算 token 提示。

## RT-0009 边界与回归

- **步骤**：① 加载后执行 `attempt_completion`（观察 `task_message_no` 指针前移）；② 触发一次解析失败/回退重试；③ 用子 Agent 处理一个需要该技能的任务。
- **期望**：①② 加载内容仍在（指针/回退不影响 pinned）；③ 父会话的加载**不继承**给子 Agent（子 Agent 自行加载；如需共享技能请装到全局目录）——此条为**已知边界**，只需要行为符合说明，不视为缺陷。

## RT-0010 中断与并发

- **步骤**：在 `skill_load` 执行期间触发中断（Web ESC / TUI Ctrl+C）；随后再次加载。
- **期望**：无残留半加载状态（状态表与 pin 消息保持一致）；再次加载可正常完成。

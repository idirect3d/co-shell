# FEATURE-378-UC-0001: web 底部状态条（上下文 token 统计）

## 描述
在用户消息框下方（窗口最底部）增加一条状态条，实时显示当前上下文长度统计；通过右上角下拉菜单新增开关控制是否显示状态条。

## 状态条显示内容
1. 当前会话总输入+总输出 token 数（累积所有迭代的 prompt + completion）
2. 最后一次输入 token（最近一次迭代的 prompt）
3. 首字延迟（最近一次迭代的 ft）
4. 总输出 token（累积所有迭代的 completion）
5. 用时（最近一次迭代从 turn_start 到 token_iter 的耗时）
6. token（最近一次迭代的 total）

## 前置条件
1. 已启动 `co-shell serve` 并打开 Web UI
2. 浏览器已连接 WebSocket

## 用例

### UC-0001: 状态条默认显示
- 操作：打开 Web UI
- 预期：状态条出现在消息输入框下方（窗口最底部），显示 6 项统计（初始为 0 或空）

### UC-0002: token_iter 事件更新状态条
- 操作：发送一条指令，等待 LLM 迭代完成（产生 token_iter 事件）
- 预期：状态条更新为本次迭代的 token 数据——最后一次输入 token = prompt、首字延迟 = ft、token = total；累积值 = 会话总输入+总输出、总输出 token

### UC-0003: 多次迭代累积
- 操作：连续发送多条指令（多次 token_iter 事件）
- 预期：会话总输入+总输出 token 数、总输出 token 为多次迭代的累积值；最后一次输入 token、首字延迟、token、用时为最近一次迭代的值

### UC-0004: 菜单开关控制显示/隐藏
- 操作：点击右上角 ☰ 菜单，点击"状态条"开关
- 预期：状态条隐藏；再次点击恢复显示

### UC-0005: 开关持久化
- 操作：关闭状态条后刷新页面
- 预期：状态条保持隐藏（localStorage 持久化）

### UC-0006: 用时显示
- 操作：发送指令，观察状态条"用时"字段
- 预期：用时显示为最近一次迭代的耗时（秒）

## 验证方法
1. `node --check web/static/app.js` 语法检查通过
2. `go build ./... && go vet ./... && go test ./...` 全绿
3. headless 浏览器验证状态条渲染、token_iter 数据更新、菜单开关切换与持久化

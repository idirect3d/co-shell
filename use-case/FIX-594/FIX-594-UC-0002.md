# FIX-595 UC-0001：移除 content-visibility 隔离（修复翻页黑屏重渲染与滚动 CPU 飙升）

> 分支：**FIX-594**（同一会话沿用）　版本：**v0.92.1**　任务号：**FIX-595**
> 判定口径：修复后，`.ev` 不再使用 `content-visibility` 隔离；滚动时块保持"已渲染"状态（不再出现黑屏→内容的重渲染观感）；`#streamB.scrollHeight` 恢复到与真实内容高度一致的量级；滚动期间布局不再反复修正。
> 判定方式：静态检查 + Chrome 帧级/布局实测对比（修复前基线见下表）+ 目视观感复核（Safari）。

## 背景（改前实测基线）

| 项 | 改前实测 | 测量方式 |
|---|---|---|
| `.ev` 计算样式 | `content-visibility: auto`；`contain-intrinsic-size: auto 300px` | `getComputedStyle` |
| `#streamB.scrollHeight`（150 个真实 md 渲染块 / 51901 节点） | **95,357 px**（content-visibility: auto） | 页面内实测 |
| 同上（`content-visibility: visible`） | **570,031 px** | 页面内实测 |
| 估算误差 | `contain-intrinsic-size` 300px vs 真实块高 ≈ 3800px → **差 12 倍** | 由上面两项推得 |
| Chrome 反复滚动（2.5s，上下往返 22 次） | 两种设置均无 >50ms 长任务（Safari 上被放大） | PerformanceObserver('longtask') |

引入来源：`3b895b69` **FIX-590**（v0.91.6 / BUILD-1195），意图是让"每次强制布局"便宜（当时实测强制布局 1MB→66ms…20MB→2.21s）。该前提已被 **FIX-591（v0.91.7）** 与 **FIX-594（v0.92.1）** 消除。

## 变更点

| 位置 | 变更 |
|---|---|
| `web/static/style.css` | 移除 `.ev { content-visibility: auto; contain-intrinsic-size: auto 300px; }` 与 `.ev:last-child { content-visibility: visible; }`（保留简短说明注释） |
| `web/static/app.js` | `updateFollowState` 的 scroll 探针加 **100ms 限频**（移除隔离后 `scrollHeight` 读取重新与会话体量成正比）；`jumpToBottom` 改用 `scrollTop = 1e9` 钳制，不再读 `scrollHeight` |

## 用例

- **A 样式已移除（静态 + 运行时）**：`web/static/style.css` 中不再存在 `.ev` 的 `content-visibility` / `contain-intrinsic-size` 声明；页面上 `.ev` 的 `getComputedStyle(...).contentVisibility === "visible"`，且 `containIntrinsicSize` 为空/默认。
- **B 滚动条高度一致性（主判定，实测）**：注入 150 个真实 md 渲染块后，`#streamB.scrollHeight` 与"全部块均可见（visible）"时的数值一致（差值 <2%）；改前该值仅为后者的 **~1/6**。
- **C 滚动观感（目视，Safari 复核）**：上下滚动长会话时，已划过的块**保持已渲染**，不再出现"从黑屏开始渲染/内容动态加载"的观感；滚动位置不因块高修正而跳动。
- **D 滚动期布局成本（实测）**：滚动 2.5s（上下往返 ≥20 次）期间不出现 >50ms 长任务；`updateFollowState` 探针调用次数被限频到 ≈10 次/秒（改前为每滚动帧 1 次）。
- **E 跟随输出行为回归**：滚到底部时新输出仍自动跟随；离开底部 >100px 时停止跟随并显示浮动下箭头；点击箭头回到底部并恢复跟随。
- **F 编译与静态检查**：`go build ./... && go vet ./...` 通过；`node --check web/static/app.js` 通过。
- **G 回归**：`go test ./... -short` 失败集为 `main` 基线的子集（零新增失败）。

## 不在本次范围

- 浏览器与 co-shell 通讯解耦（前端按需拉取）仍属待讨论议题，不在本次。

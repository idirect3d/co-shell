# FEATURE-457 Web UI 设置页分组折叠+搜索 — 测试用例

> 版本：v0.25.0 ｜ 分支：FEATURE-457 ｜ 类型：Web UI 前端功能
> 前置条件：启动 Web UI（`./work/co-shell --serve --port <port>`），打开浏览器访问设置页（点击菜单「系统设置」）。

## UC-0001 设置页默认分组折叠
- **前置**：打开设置页
- **步骤**：观察设置页 5 大分组（模型/显示输出/安全确认/记忆上下文/开发者）的展示
- **预期**：每个分组默认折叠，只显示组标题（带 ▸ 箭头），组内设置项不显示；组标题可点击

## UC-0002 点击组标题展开分组
- **前置**：设置页已打开，分组默认折叠
- **步骤**：点击「安全确认」组标题
- **预期**：该组展开，组内设置项（confirm-tool、supervisor-enabled 等）显示，标题箭头变为 ▾

## UC-0003 再次点击折叠分组
- **前置**：某分组已展开
- **步骤**：再次点击该组标题
- **预期**：该组折叠，组内设置项隐藏，箭头恢复为 ▸

## UC-0004 各分组独立折叠互不影响
- **前置**：设置页已打开
- **步骤**：展开「模型」组，再展开「安全确认」组
- **预期**：两个组都展开，互不影响；折叠其中一个不影响另一个

## UC-0005 搜索框输入关键词过滤设置项
- **前置**：设置页已打开
- **步骤**：在顶部搜索框输入「supervisor」
- **预期**：只显示 key 或 desc 包含「supervisor」的设置项（supervisor-enabled、supervisor-entry-object 等），其他设置项隐藏；匹配的分组自动展开

## UC-0006 搜索匹配分组标题
- **前置**：设置页已打开
- **步骤**：在搜索框输入「安全」（分组标题关键词）
- **预期**：显示「安全确认」分组下的所有设置项，该组自动展开

## UC-0007 搜索无匹配时隐藏分组
- **前置**：设置页已打开
- **步骤**：在搜索框输入不存在的关键词（如「zzzz」）
- **预期**：所有分组隐藏，设置页显示为空（无匹配项）

## UC-0008 清空搜索恢复默认折叠
- **前置**：已输入搜索关键词，分组被过滤/展开
- **步骤**：清空搜索框内容
- **预期**：所有设置项恢复显示，所有分组恢复默认折叠状态

## UC-0009 搜索后修改设置项仍生效
- **前置**：搜索框输入「supervisor」，显示 supervisor 相关设置项
- **步骤**：切换 supervisor-enabled 开关
- **预期**：开关切换生效（发送 settings_set 消息），设置项仍保持过滤显示状态

## UC-0010 搜索框在设置页顶部显示
- **前置**：打开设置页
- **步骤**：观察设置页布局
- **预期**：搜索框位于设置页顶部（外观组之前），带 🔍 图标占位符，样式与设置页协调

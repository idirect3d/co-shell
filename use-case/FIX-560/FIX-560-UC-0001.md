# FIX-560 测试用例 —— hub 列表项红色删除按钮显示修复

> 分支：**FIX-560**｜版本：**v0.76.3** (BUILD-1131)｜产物：`work/co-shell-0.76.3.darwin.arm64`、`work/co-shell-hub-0.76.3.darwin.arm64`

## 需求

| 编号 | 需求 |
|------|------|
| R1 | 红色删除按钮**平时隐藏**（不可见），仅在用户滑动将要露出时才显示 |
| R2 | 透明度随滑动位置**动态渐入**，该过程在滑动 **16px 内**完成（≥16px 时完全不透明） |
| R3 | 红色删除按钮**左边至少延长 20px** |
| R4 | 消除「平时右圆角处漏出红色边缘」与「左滑时看到红色左边缘」两个瑕疵 |
| R5 | 删除功能本身行为不变（滑动阈值、回弹、点击删除） |

## A 组：自动验证（已自测通过）

单测文件：`hub/gateway/fix560_test.go`；浏览器实测：独立冒烟实例（`-web-addr 127.0.0.1:28401 -tcp-addr 127.0.0.1:12899`，独立 registry/board）。

| 编号 | 用例 | 断言 / 实测值 | 结果 |
|------|------|---------------|------|
| A-001 | 静止态删除按钮不可见 | `.agent-del` 含 `opacity:0`；真实页面 `getComputedStyle().opacity === "0"` | ✅ |
| A-002 | 按钮左边延长 ≥20px 且新增规则唯一 | `width:84px`（63 露出 + 20 余量）、`padding:0 0 0 20px`、`.agent-del {` 仅出现 1 次 | ✅ |
| A-003 | 渐入跨度 = 16px | `var DELETE_FADE_PX = 16;` + `setDelOpacity(card, -dx / DELETE_FADE_PX)` | ✅ |
| A-004 | 渐入与位移成比例、16px 内完成 | 拖动 4px→`0.25`、8px→`0.5`、16px→`1`、40px→`1`、90px（钳位 −63px）→`1` | ✅ |
| A-005 | 开 / 合状态端点正确 | 滑开：`style.opacity === "1"`；短滑（<32px）松手：`"0"` | ✅ |
| A-006 | 拖动期间跟手无延迟 | `begin()` 中 `card._del.style.transition = 'none'`（实测 `del.style.transition === "none"`） | ✅ |
| A-007 | 竖向滚动中断复原（无残留红边） | 纯竖向与斜向首帧中断后：`style.opacity === "0"`、`translateX(0px)` | ✅ |
| A-008 | 滑动行为未变 | `setSwipe(card, dx < -32)`、`Math.max(-63, ...)`、`translateX(-63px)`、`Math.abs(mx) > 4` 均在 | ✅ |
| A-009 | 打开态几何：左边缘不再可见 | 实测 wrap 8..471、card −55..408、del 386..470 → 按钮左边缘 22px 藏在卡片下，可见红色宽 62px | ✅ |
| A-010 | 版本 / build 同步 | co-shell `0.76.3/1131` = co-shell-hub `0.76.3/1131`；`/api/hub-info` = `{"version":"0.76.3","build":"1131"}` | ✅ |

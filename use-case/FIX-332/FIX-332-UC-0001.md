# FIX-332: i18n 转义多字节字符改为直接书写

## 背景

`i18n/en.go` 与 `i18n/zh.go` 中大量字符串以 `\uXXXX` 形式转义书写中文/符号（如 `\u5f53\u524d\u503c` 表示"当前值"），共 762 处（en.go 381 + zh.go 381）。此类转义严重影响源码可读性，用户要求统一改为直接书写中文字符（如 `"当前值"`）。

## 修改方案

新增 `bin/decode_u_escapes.py` 脚本，按 Go 词法逐字符解析源文件：

- **仅转换双引号字符串内的** `\uXXXX`：单反斜杠 + 4 位十六进制 Unicode 转义 → 对应的 UTF-8 字符
- **保护以下内容不被误转**：
  - 反引号 raw string（`\u` 在其中是字面文本，非转义）
  - 行注释 `//` 与块注释 `/* */`
  - `\\u` 字面量（双反斜杠，表示字面 `\u` 文本）
  - 其他转义序列（`\n`、`\t`、`\"` 等）原样保留

完成后 en.go / zh.go 各 381 处 `\uXXXX` 全部替换为直接字符，运行时字符串值不变（Go 规范保证双引号内 `\uXXXX` 与直接 UTF-8 字节等价）。

## 用例列表

### UC-0001 中文转义解码（静态检查）
**前置条件**：转换后文件。
**步骤**：`grep -c '\\u[0-9a-fA-F]' i18n/en.go i18n/zh.go`。
**预期**：两文件分别为 0、0。

### UC-0002 直接中文字符正确（静态检查）
**前置条件**：转换后文件。
**步骤**：查看 `KeyCmdMig_001` 等条目。
**预期**：显示 `→ 当前值: %s\n` 等直接中文，`\n` 等非 Unicode 转义保留。

### UC-0003 语义等价（构建验证）
**前置条件**：转换后文件。
**步骤**：`go build ./...` + `go test ./i18n/`。
**预期**：编译通过、测试通过（Go 规范保证 `\uXXXX` 与直接字符字节等价，转换不改变运行时值）。

### UC-0004 非双引号上下文未误伤（静态检查）
**前置条件**：转换后文件。
**步骤**：抽查 raw string / 注释区域。
**预期**：原始内容未变。

## 验收标准
1. `go build ./...` 通过
2. `go vet ./i18n/...` 无警告
3. `go test ./i18n/` 全绿
4. i18n/en.go、i18n/zh.go 中 `\uXXXX` 数量为 0

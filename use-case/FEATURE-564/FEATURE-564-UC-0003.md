# FEATURE-564 运行时用例 UC-0003：会话隔离、实时刷新与面板显隐

## 目标

验证子代理清单的三项行为：

1. **会话隔离**：清单只显示当前会话创建的子代理（含该会话已完成的）。
2. **实时刷新**：子代理运行中其任务计划推进时，主界面清单进度自动更新（B2：日志 tail watcher 推送）。
3. **面板显隐**：当前会话存在子代理时，即使没有主 Agent 任务计划，右侧「任务进展」面板也显示。

## 前置条件

- 本分支构建的 co-shell（v0.78.0）`--serve` 运行，Web UI 中有两个会话（会话 A、会话 B）。
- 「任务进展」面板在菜单中处于开启状态（未被人为关闭）。

## 步骤

### 场景 A：会话隔离

1. 在会话 A 中执行：
   `launch_sub_agent(tasks=[{id:"uc3-a", instruction:"在会话A创建的子代理"}], timeout_seconds=60)`
2. 在会话 B 中执行：
   `launch_sub_agent(tasks=[{id:"uc3-b", instruction:"在会话B创建的子代理"}], timeout_seconds=60)`
3. 在会话 A 中观察清单，然后切换到会话 B 再观察清单。

**预期**：会话 A 只看得到 `uc3-a`（看不到 `uc3-b`）；切到会话 B 只看得到 `uc3-b`。

### 场景 B：实时刷新

4. 启动一个会建立多步任务计划的子代理（同 UC-0002 场景 B），停留在主界面不操作，
   观察进度数字是否**自动**从 `(0/5)` 推进到 `(1/5)`…`(5/5)`（无需发送任何消息或刷新页面）。

**预期**：进度随子代理内部任务计划的推进自动更新（无需手动刷新）。

### 场景 C：面板显隐

5. 新建会话 C（无任务计划），在其中创建一个子代理。

**预期**：右侧「任务进展」面板出现（栏目上方无主任务计划内容），下方显示 `uc3-c ...(0/1)` 形式的清单项。
6. 删除会话或切换到无子代理的会话 D。

**预期**：会话 D 中不显示其他会话的子代理；若该会话既无任务计划也无子代理，面板隐藏。

## 验证方式

- 浏览器截图对比 + `browser_evaluate` 读取清单 DOM 文本断言只含当前会话 id。
- 场景 B 采用“停留观察”验证：连续两次截图（间隔 ≥5s）比较进度数字是否变化。
- 后端侧可对照日志：`{workspace}/sub-agents/<id>/run-*.jsonl` 的 task_plan 事件时间戳与界面刷新时间一致。

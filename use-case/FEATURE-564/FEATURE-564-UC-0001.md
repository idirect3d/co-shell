# FEATURE-564 运行时用例 UC-0001：面板下方子代理清单的基础展示与格式

## 目标

验证 Web UI 右侧「任务进展」面板下方，按“垂直向下对齐”的方式显示当前会话的 sub-agent 清单，
且每行格式为：

```
{sub-agent-id} {指令，超过 30 字符以 ... 截断}({进度})
```

## 前置条件

- 工作区为 co-shell 仓库，`work/` 下已构建本分支可执行码（v0.78.0）。
- 主 agent 已开启 sub-agent 能力（配置/工具已注册）。
- 浏览器打开 `co-shell --serve` 提供的 Web UI。

## 步骤

1. 在主会话中让主 agent 创建一个子代理，指令长度 **小于** 30 个字符（例如 `ls -la` 之类）：
   `launch_sub_agent(tasks=[{id:"uc1-short", instruction:"列出当前目录"}], timeout_seconds=60)`
2. 观察右侧「任务进展」面板。
3. 再创建一个指令长度 **大于** 30 个字符的子代理：
   `launch_sub_agent(tasks=[{id:"uc1-long", instruction:"请统计仓库中所有 Go 文件的函数数量并分目录汇总成表格"}], timeout_seconds=60)`
4. 观察右侧面板中两行的显示。

## 预期结果

- 右侧「任务进展」面板下方出现子代理清单区域，每一项**垂直向下排列**（逐行、左对齐）。
- `uc1-short` 行显示：`uc1-short 列出当前目录(0/1)` 或 `(1/1)`（无任务计划时 0/1 表示未完成、1/1 表示已完成）。
- `uc1-long` 行显示指令被截断为 30 个字符并以 `...` 结尾，例如：
  `uc1-long 请统计仓库中所有 Go 文件的函数数量并...(0/1)`（具体截断位置以 30 字符为准）。
- 清单不破坏原「任务进展」内容的排版（仍在其上方正常显示）。

## 验证方式

- 人工视觉检查（浏览器截图比对）。
- 也可用 `browser_evaluate` 读取清单 DOM 文本，断言包含 `uc1-short`、`uc1-long` 与 `(.../...)` 形式的进度。

# FEATURE-469-UC-0002 文件选择/拖拽加入与删除、预览

## 前置条件
- 启动 Web UI（`co-shell --serve`）
- 准备好本地普通文件（如 report.pdf、data.zip）与一张图片文件

## 操作步骤
1. 点击录入框旁 📎 按钮，多选以上文件与图片
2. 观察附件托盘：图片显示缩略图，普通文件显示「📄 + 文件名」图标，二者并排平铺
3. 将另一文件拖放到录入框上，确认也被加入附件托盘
4. 将鼠标悬停到某缩略图右上角，点击 ✕ 删除该项，确认该项消失且其余项不变
5. 点击附件区右侧「清空附件」✕，确认全部附件被清空、托盘隐藏
6. 重新添加一张图片，点击其缩略图，确认弹出大图预览（含分辨率信息）；添加普通文件并点击，确认预览显示文件类型提示

## 预期结果
- 📎 按钮打开系统文件多选；选择的文件立即进入录入框下方附件托盘
- 图片为缩略图、普通文件为图标+名称，两者同排平铺
- 拖放文件到录入框也能加入附件托盘
- 每项右上角 ✕ 仅删除该项；托盘右侧 ✕ 清空全部并隐藏托盘
- 图片点击放大预览（复用 #preview 弹层，展示宽×高）；普通文件点击预览提示「发送后将保存到工作区（可被工具读取）」

# FEATURE-469-UC-0001 剪贴板粘贴图片生成缩略图

## 前置条件
- 启动 Web UI（`co-shell --serve`）
- 打开主消息录入框所在页面
- 剪贴板中已复制一张截图/图片（如 macOS `Cmd+Ctrl+Shift+4` 截图或系统复制图片）

## 操作步骤
1. 将光标聚焦到主消息录入框
2. 直接按 `Ctrl+V`（macOS `Cmd+V`）
3. 观察录入框下方是否出现附件托盘，托盘内是否出现该图片的缩略图
4. 连续粘贴第 2 张图片，观察两张缩略图是否并排平铺且文件名不冲突
5. 在录入框输入普通文字后再次粘贴纯文本，确认不会生成缩略图

## 预期结果
- 录入框下出现附件托盘（.attach-bar），内含 84×84 图片缩略图（.attach-item img.attach-thumb）
- 剪贴板图片被重命名为 `clip-<时间戳>-<序号>.png` 形式的唯一文件名，避免多次粘贴同名覆盖
- 缩略图区域可横向滚动/换行容纳多张图，互不覆盖
- 粘贴纯文本不触发缩略图，正常输入文字

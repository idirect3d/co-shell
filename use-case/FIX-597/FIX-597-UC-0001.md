# FIX-597 UC-0001：hub 聚合页 `attachSwipe` 监听器泄漏修复

> 分支：**FIX-596**（会话分支，任务编号 FIX-597）　版本：**v0.92.2**　BUILD：**1204**
> 判定口径：hub 聚合页在轮询/重建列表时**不再向 `window` 注册持久监听器**，滑动删除手势行为不变。

## 背景（改前基线，实测）

| 项 | 值 |
|---|---|
| 现象（Safari） | hub 聚合页所在 WebKit WebContent 进程 **CPU 10~70%**、内存 **1.6~1.8GB**（±200MB 抖动），GPU 进程常驻 15~86%；关闭其它标签页后依然如此 |
| 原生采样（`sample` 3s） | 最热叶子 `WebCore::EventTarget::addEventListener` **160 样本**、`JSEventListener::operator==` **135 样本**；调用链 `Timer → refresh() → renderList() → attachSwipe()` |
| 零代码计数（运行中的 hub 页，21 个 agent） | 22 秒内 **294 次** `window.addEventListener`（147 `mousemove` + 147 `mouseup`）= 21 卡片 × 2 × 7 次 3 秒轮询 ≈ **4.8 万个/小时** |

**根因**：`hub/gateway/webui_static.go` 的 `renderList()` 每轮为每张卡片调用 `attachSwipe(card)`，而 `attachSwipe()` 在构建卡片时无条件在 `window` 上注册 `mousemove`/`mouseup`，且从不注销 —— 监听器列表无上限增长（每次注册线性扫描已有监听器），泄漏闭包又永久持有被丢弃卡片的 DOM 子树。

## 变更点

| 位置 | 变更 |
|---|---|
| `hub/gateway/webui_static.go` | `attachSwipe` 新增 `listen()`/`unlisten()` 与 `listening` 幂等开关：鼠标按下（开始拖拽）时注册 `window` 的 `mousemove`/`mouseup`，拖拽结束或转为竖向滚动（取消）时注销；卡片构建路径不再注册任何 `window` 监听器 |
| `hub/gateway/fix597_test.go` | 新增 `TestAttachSwipeDoesNotLeakWindowListeners`：断言两个事件各自注册/注销恰好 1 次、存在 `listen/unlisten` 与幂等守卫、`end()` 与竖向取消路径都调用 `unlisten()` |

## 用例与实测结果

- **A 列表重建零注册（主判定）** → ✅ 在修改后的 hub 页（21 个 agent）触发 **10 次列表重建**，`window.addEventListener` 增量 **0**（改前每次重建 +42）。
- **B 长时间轮询零注册** → ✅ 空闲观察 **25 秒**（约 9 轮 3 秒轮询）后累计计数仍为 **4/4**，即轮询期间 **0 次注册**（改前为 294 次/22 秒）。
- **C 拖拽期成对注册/注销** → ✅ 鼠标按下：`mousemove` +1、`mouseup` +1；松手：两者各 −1；全程累计注册 4 / 注销 4，**完全成对**。
- **D 手势行为无回归** → ✅ 横向拖动 45px 后 `card.style.transform = translateX(-45px)`、删除按钮 `opacity=1`、卡片 `_open=true`；竖向拖动 30px 时 `transform` 保持 `translateX(0px)`（让位页面滚动）且监听器被注销；点击空白处收起沿用原有 `listEl` 点击处理（未改动）。
- **E 单元测试** → ✅ `TestAttachSwipeDoesNotLeakWindowListeners` 通过；`hub/gateway` 既有 Focus 用例全绿；`go build ./... && go vet ./...`（主模块与 hub 模块）通过。
- **F 回归** → 主模块 `go test ./... -short` 仅 `agent` 包 2 例失败（`TestLineRendererTokenEvents`、`TestRetryCountLimit_EnterResets`），为**语言环境导致的既有失败**：`LANG=zh_CN.UTF-8` 重跑即通过；hub 模块 `go test ./...` 全绿。
- **G 产物** → `work/co-shell-0.92.2.darwin.arm64`、`work/co-shell-hub-0.92.2.darwin.arm64`（BUILD-1204）。

## 不在本次范围

- 不改 WebUI 流式渲染策略（FIX-596 的增量渲染方案按 Safari 实测收益仅 ~1%，暂不实施）。
- 运行中的旧 hub（0.83.0）页面里已泄漏的监听器无法回收，需**重载页面/重启 hub** 后才生效。

## 用例详情

### A. iOS 静态断言（建议落在 `web/fix619_test.go` 中读取 Swift 源码做结构断言）

> 沿用 FIX-608 的做法：以源码文本断言结构，避免依赖 Xcode 才能在 CI 上跑。

- **A-101**：断言 `refreshTapped`（或刷新入口）内出现 `stopLoading()`，且位于重新加载调用之前。
- **A-102**：断言出现 `WKWebsiteDataTypeMemoryCache` 与 `WKWebsiteDataTypeDiskCache`；断言**不出现** `WKWebsiteDataTypeCookies` 或 `httpCookieStore.delete`（避免误删 `access_key`）。
- **A-103**：断言出现 `cachePolicy: .reloadIgnoringLocalCacheData`（或 `.reloadIgnoringLocalAndRemoteCacheData`）与 `timeoutInterval:`（值 ≤ 20）。
- **A-104**：断言存在重试计数/退避数组（含 1、3、5 秒语义）与「重试耗尽 → `showError`」的分支；断言 `didFailProvisionalNavigation` 中的 `NSURLErrorCancelled` 早退保持存在。
- **A-105**：断言存在 WebView 重建路径（`removeFromSuperview()` + 重新赋值 `webView` + 重新 `addSubview` + 约束重建）。
- **A-106**：断言重建路径最终调用 `loadHub()`（或等价 cookie 注入 + `load`），确保 `access_key` cookie 仍被注入后再加载。

### C. 服务端运行时用例（Go 单测，建议 `web/fix619_ws_test.go`，复用 `ws_test.go` 的 `dialWSPath`/`wsHandler`）

- **C-101 ping 周期**：建立连接后静默等待一个 ping 周期（测试中可用注入的短周期，如 200ms）。
  - 断言：客户端收到 `wsOpPing` 帧（或约定心跳帧），且连接保持打开。
- **C-102 读超时断开 + 清理**：
  - 步骤：建立连接后完全静默（不回 pong、不发消息），等待超过读超时（测试注入短超时）。
  - 断言：服务端关闭连接；`s.conns` 中该连接已被 `removeConn`（连接计数回到基线）；若为 gateway 连接则 `clearGatewayConn` 已执行。
- **C-103 活跃连接不误杀**：
  - 步骤：周期性发送业务帧（如 `{"type":"mode_get"}`）超过两个读超时窗口。
  - 断言：连接保持打开，且正常收到响应。
- **C-104 回归**：`go test ./web/... -run WS` 全绿；特别是既有「多客户端 fan-out」「断连不 failAll」「client_id 标签」相关用例不变。

### D. 端到端验收（需真机 + 真实 hub，由用户配合执行）

- **D-001 自动恢复**
  - 步骤：手机在 hub 页面（已连上、能收发）→ 熄屏或切后台 ≥30 分钟（或飞行模式模拟断网 5 分钟以上）→ 回到 App 前台。
  - 断言：**不做任何手动操作**，≤30s 内连接指示灯恢复「已连接」，发送一条消息能正常得到回复。
- **D-002 一次刷新恢复**
  - 步骤：构造自动恢复失败（如在断网状态下反复刷新使网络栈处于坏状态）→ 恢复网络 → 点一次导航栏刷新。
  - 断言：一次刷新即恢复，不再需要杀 App 重启。
- **D-003 弹窗策略**
  - 步骤：断网状态下点刷新。
  - 断言：不立即弹错误框；自动重试（约 1s/3s/5s）后才出现提示（恢复网络后可自愈）。
- **D-004 分层判据**
  - 步骤：复现失败时对照 hub 终端日志 `webui: GET /agent/{id}/ ... from <手机IP>`。
  - 断言：能明确区分「日志无该请求（客户端未发出）」与「有请求但仍失败（隧道/服务端）」，并在报告中给出结论（用于验证根因推断）。
- **D-005 分发验证**
  - 步骤：`xcodebuild archive` → `exportArchive`（ExportOptions-upload.plist）上传；或 `xcrun devicectl device install app` 直装。
  - 断言：归档/上传成功；设备侧 `设置 → co-shell` 显示版本 **0.102.3**（`CURRENT_PROJECT_VERSION` 递增）；TestFlight 处理完成可安装。

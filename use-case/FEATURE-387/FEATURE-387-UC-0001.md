# FEATURE-387-UC-0001: web UI 状态栏会话菜单

## 描述
在 web UI 状态栏增加 💬 图标 + 会话数，鼠标悬停向上展开会话菜单，列出所有会话标题，可切换/删除会话。

## 前置条件
1. 已启动 `co-shell serve` 并打开 Web UI
2. 存在至少两个命名会话（可通过 `.session` 命令创建）

## 用例

### UC-0001: 状态栏显示 💬 图标 + 会话数
- 操作：打开 Web UI
- 预期：状态栏显示 💬 图标 + 会话总数（如 `💬 3`）

### UC-0002: 鼠标悬停展开会话菜单
- 操作：鼠标移到 💬 区域
- 预期：向上展开会话菜单，列出所有会话标题

### UC-0003: 悬停会话项提示关键字 + 时间
- 操作：鼠标悬停某个会话项
- 预期：显示该会话的关键字 + 创建时间

### UC-0004: 点击会话项切换会话
- 操作：点击某个会话项
- 预期：切换到目标会话，状态栏会话数/当前会话更新，任务进展刷新

### UC-0005: 点击删除符号删除会话
- 操作：点击某个会话项左侧的删除符号
- 预期：删除该会话，会话列表更新，会话数减少

### UC-0006: 当前会话不可删除
- 操作：尝试删除当前正在使用的会话
- 预期：删除被阻止或提示，当前会话保留

## 验证方法
1. `go build ./... && go vet ./... && go test ./...` 全绿
2. 单元测试：`web` 包新增测试验证 `session_list`/`session_switch`/`session_delete` 消息处理
3. Node DOM shim 加载真实 app.js 驱动假事件，验证状态栏 💬 图标、会话菜单展开、切换/删除
4. headless 浏览器验证会话菜单交互

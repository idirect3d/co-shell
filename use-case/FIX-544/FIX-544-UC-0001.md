# FIX-544 测试用例：「身份与个性」窗口正方形化与保存提示文案

- **分支**：FIX-544（基于 main，v0.68.5 已合并）
- **版本**：v0.68.6 [BUILD-1088]
- **需求**：
  1. 加宽「身份与个性」设置窗口右半部分，使整体成为正方形（增宽、高度不变）；宽屏下最大宽高为页面 90%；窄屏保持「充满屏幕 + 翻页式」不变。

- **用户确认**：归入 v0.68.6（patch 递增）；文案不带书名号等符号；尺寸 800×800、左栏仍 200px、右栏 400→600px。

## 回归关注点

- `identity_result` 的 `Message` 语义变更（成功时不再携带 key）：改前已 `grep identity_result web/*_test.go` 确认无测试依赖，UC-0010 复验。
- `.identity-box` 与 `.settings-box`（系统设置窗口）是两套独立尺寸规则，本任务**只动 identity**，系统设置窗口必须保持 600×800 不变。
- `identityFields` 在 `renderIdentity` 时赋值，`identitySavedText` 依赖它取 label；若字段列表尚未到达则回退显示 key，不报错。
- 窄屏翻页（`identityShowPane` / `identityShowList`）与标题栏 agent name 同步（FIX-542）逻辑未触碰。

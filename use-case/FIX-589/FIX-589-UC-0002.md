# FIX-589 UC-0002：前端逐层加载 + 收起清空 DOM 与数据

> 分支：**FIX-589**　版本：**v0.91.5**　需求：用户 2026-10-03「修复 C（/api/tree 按需加载）；另外，当收起一个文件夹时清理收起文件夹下 DOM 内容，待再次打开时再重新加载」
> 判定口径：侧栏文件树的**每一层数据只在需要时请求**；**收起目录时清空其子行 DOM 并丢弃该层数据**，再次展开必须重新向服务端请求该层并正确重建；未展开目录仍显示 git 变更计数徽标与文件状态字母。

## 目的

消除「每次刷新拉取整树 + 全量重建」的浪费，并把展开态的内存/DOM 占用收敛到「用户当前真正展开的层级」。本用例锁定前端行为与回归面。

## 变更点（前端）

| 位置 | 变更 |
|---|---|
| `loadTree()`（app.js:5112） | 只拉根层（`api/tree`）；按 `expandedDirs` 逐个补齐已展开层的请求 |
| `treeNode()` / `fillDirChildren()`（app.js:5145-5275） | 建行时不再依赖整树数据；目录 `<ul>` 初始为空，展开时按需请求并批量插入 |
| 目录行点击（app.js:5228-5238） | 展开：请求该层并建行；**收起：清空子行 DOM + 丢弃该层数据 + 清除已填充标记** |
| `highlightAffectedFiles()` / `revealInTree()`（app.js:5033/5863） | 不变：仍先登记祖先目录到 `expandedDirs`，再 `loadTree()`；`loadTree` 负责把已展开层补齐后再高亮/滚动 |

> 不改动：目录徽标、文件状态字母、单击预览、双击打开、拖拽上传、远程模式（下载/隐藏 reveal）、受影响文件高亮、`applyAffectedHighlight()` 的匹配逻辑。

## 用例 A：首屏只请求一层

- 打开/刷新页面并完成连接。
- 断言：仅发出 `GET api/tree`（无 `path` 参数）；**不发出 `depth=full` 请求**。
- 断言：侧栏渲染根行 + 根的直接子项；根行处于展开态（`expandedDirs` 含 `""`）。
- 断言：根层响应体量显著下降（真实 co-shell 工作区根层 < 100 KB；改前整树 6.89 MB）。

## 用例 B：展开目录 → 恰好一次该层请求

- 点击某目录行（首次展开）。
- 断言：恰好发出 **1** 次 `GET api/tree?path=<该目录相对路径>`（路径已 URL 编码）。
- 断言：子行一次性批量插入（单个 fragment append，符合 FIX-518）；子项目录显示 `dir-count` 徽标、文件显示 git 状态字母；目录排在文件之前、名称升序。
- 断言：请求未返回前重复点击不会产生重复请求或重复行（并发保护）。

## 用例 C：收起目录 → 清空 DOM 与丢弃数据；再次展开重新请求

- 展开某目录后折叠它。
- 断言：该目录 `<ul>` 内**没有任何子行 DOM**（`ul.querySelectorAll("li").length === 0`），展开/折叠图标回到折叠态。
- 断言：该目录的内存数据被丢弃（`node.children` 不再保留；实现中移除已填充标记）。
- 断言：**再次展开该目录会重新发出 1 次** `api/tree?path=<该目录>`，重建后的行内容与徽标与首次一致。

## 用例 D：反复收起/展开不累积

- 对同一目录连续做 5 次「展开 → 收起」。
- 断言：累计请求数 = 5；每次展开后子行数量恒定（无重复行、无残留节点）；DOM 节点数在收起后回到收起前水平。

## 用例 E：刷新（工具结果触发的 loadTree）后展开态与高亮保持

- 令工作区刷新被触发（LLM 迭代 / 工具完成 / 手动刷新按钮）。
- 断言：请求数 = **1 + 当前展开目录数**（每个已展开目录各请求自己那一层）。
- 断言：刷新后展开结构不变；受影响文件高亮（`aff-pred` / `aff-pred-fg`）与文件选中态恢复；滚动位置不被强制跳到底部。

## 用例 F：受影响文件高亮 / 在树中定位

- 触发一次带 affected 文件（深层路径）的工具调用；或点击预览器里的路径做 `revealInTree`。
- 断言：其祖先目录（含根）被自动展开，请求按层级依次发出，最终目标行可见并高亮/滚动到视野内。
- 断言：某一中间层请求失败时，其余层不受影响，函数不抛异常。

## 用例 G：失败处理

- 令某层请求返回 500 或超时。
- 断言：该目录保持收起（不出现半截空列表），控制台有告警；后续点击可重试成功。
- 断言：其它目录的展开/收起不受影响；不产生重复行。

## 用例 H：回归面

- 拖拽文件到目录行上传 → 上传成功且目录行展开后可见新文件。
- 单击文件 → 预览；双击 → 系统打开；图片 → 图片查看器。
- 远程访问模式：文件显示下载图标、目录不显示 reveal；本地模式显示 reveal。
- 被排除目录（TreeExcludes）在每层都不出现。

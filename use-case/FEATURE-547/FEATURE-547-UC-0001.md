# FEATURE-547 测试用例（UC-0001 ~ UC-0016）

> 主题：工作区图片点击预览由「全屏模态弹窗」改为「中央主工作区非模态视图 + 底部文件信息气泡」
> 版本：v0.70.0　分支：FEATURE-547（基于 main，v0.69.0 已合并打 tag）
> 验收口径：点图片**不出模态遮罩**、预览**只覆盖中央主工作区**（不挡左侧文件列表/输入框）、底部气泡显示文件名/大小/修改时间/分辨率且**仅 ✕ 关闭**、预览期间可在左侧列表**直接切换**文件（图片↔图片、图片↔文本互斥）

---

## 一、编码前调研结论（用例设计依据，全部为硬事实）

| 项 | 现状 | 位置 |
|---|---|---|
| 图片单击入口 | `row.onclick = () => { if (IMAGE_EXT.test(node.name)) openImagePreview(node); else openFilePreview(node); }` | `web/static/app.js:4911` |
| 图片预览实现 | `openImagePreview(node)`：填 `#pvName/#pvSize/#pvMtime/#pvRes` → `previewImg.src` → `preview.classList.remove("hidden")` | `web/static/app.js:4951` |

| 文档 i18n | 标题栏按钮文案走 `title` 属性（中文硬编码，如 `title="关闭预览"`），无新增 i18n key 需求 | `index.html:427` |

## 二、实现约定（经 ask_user 确认 + 编码口径）

1. **版本 v0.70.0、任务号 FEATURE-547**（用户确认）。
2. **再次单击「当前正在预览的同一张图片」即关闭预览**（与文本预览 FEATURE-425 行为一致，用户确认）。
3. **信息气泡仅 ✕ 按钮可关闭**（气泡本体不响应点击，与文本预览气泡一致，用户确认）。
4. 新增 `#imgViewer`，**复用** `.file-viewer` / `.fv-titlebar` / `.fv-close` 等既有样式类（只新增图片填充所需的少量 CSS），不改动 `.preview` 模态样式与附件放大逻辑。
5. 图片预览与文本预览**互斥**：打开一方即隐藏另一方。
6. 图片预览打开时同步 `highlightTreeFile()` 并上报 `view_file` 动态事件（与文本预览一致）。

## 三、用例清单

### A 组：结构静态校验（Go 单测，可自动执行）

#### UC-0001 `/static/index.html` 含非模态图片预览容器
- **前置**：`newTestServer(t)`（既有测试脚手架）
- **步骤**：`GET /static/index.html`，断言响应体
- **预期**：存在 `id="imgViewer"`，且其 `class` 含 `file-viewer` 与 `hidden`；容器位于中央主工作区所在的 `<section>` 内（即出现在 `</section>` 之前、且在 `id="preview"` 模态块之前）。
- **失败判据**：无 `imgViewer`，或它出现在 `<main>` 之外。

#### UC-0002 图片预览容器内含信息气泡与关闭按钮
- **预期**：`imgViewer` 块内存在 `class="fv-titlebar"` 的气泡，且含 `id="ivName"`、`id="ivSize"`、`id="ivMtime"`、`id="ivRes"`、`id="ivClose"` 与一个 `<img>` 元素。
- **失败判据**：任一元素缺失，或气泡使用了 `preview-titlebar`（旧模态气泡类）。

#### UC-0003 `#preview` 模态与附件放大链路保留（回归）
- **预期**：`index.html` 仍存在 `id="preview"`、`id="previewImg"`、`id="previewClose"`；`app.js` 仍存在 `previewClose.onclick` 与附件放大调用点。
- **失败判据**：`#preview` 或其关闭绑定被删除（会破坏附件缩略图放大）。

#### UC-0004 图片单击不再走模态弹窗
- **步骤**：读取 `web/static/app.js`，定位 `function openImagePreview`
- **预期**：`openImagePreview` 函数体内**不出现** `preview.classList.remove`（即不再打开 `#preview` 模态）；出现 `imgViewer` 与 `highlightTreeFile(`。
- **失败判据**：函数体内仍 `preview.classList.remove("hidden")`。

### B 组：图片预览打开形态（浏览器实测）

#### UC-0005 单击图片打开非模态预览，无遮罩
- **前置**：`work/co-shell-0.70.0.darwin.arm64 --serve --port <p>` 启动，浏览器打开工作区
- **步骤**：左侧文件列表单击任一图片文件
- **预期**：中央主工作区出现图片预览，**无半透明黑色遮罩**（原模态的 `rgba(0,0,0,.6)` 全屏层不出现）；左侧文件列表、顶部标题栏、底部输入行均可正常看见/点击。
- **失败判据**：屏幕整体变暗，或点击左侧文件列表被遮罩吞掉。

#### UC-0006 预览只覆盖中央主工作区
- **步骤**：打开图片预览后截图观察布局
- **预期**：预览区域上边界贴合消息区标题栏下方（与文本预览一致，约 35px 偏移），左/右/下边界贴合主工作区；**不覆盖**左侧工作区树、右侧任务进展面板、底部输入行。
- **失败判据**：预览溢出到左栏或输入行上方。

#### UC-0007 图片自适应显示，不裁剪、不溢出
- **步骤**：分别预览一张大图（>视口）与一张小图（如 32×32 favicon）
- **预期**：大图等比缩放完整可见（`object-fit: contain`，无裁剪、无横向滚动条）；小图居中显示且**不被强行拉伸变形**。
- **失败判据**：出现裁剪、拉伸变形或滚动条。

#### UC-0008 图片加载失败时的表现
- **步骤**：预览一个扩展名是图片但内容损坏/非图片的文件（如把文本命名为 `.png`）
- **预期**：气泡仍显示文件名/大小/修改时间，分辨率位为空；页面无 JS 报错（控制台可见可读的错误或静默无分辨率），预览视图不崩溃、可正常 ✕ 关闭。
- **失败判据**：整个预览白屏且 ✕ 不可用，或控制台抛未捕获异常阻断后续点击。

### C 组：底部信息气泡（浏览器实测）

#### UC-0009 气泡内容与格式
- **步骤**：单击图片，等待加载完成后查看底部气泡
- **预期**：依次显示「文件名 / 文件大小（如 `12,345B`）/ 修改时间（`YYYY-MM-DD HH:MM:SS`）/ 分辨率（`宽 × 高`，如 `1920 × 1080`）」，右侧为 ✕ 关闭按钮；气泡样式（胶囊形、半透明边框、hover 填充）与文本预览气泡一致。
- **失败判据**：分辨率恒为空（即使图片已加载成功）、大小/时间格式与文本预览不一致。

#### UC-0010 仅 ✕ 可关闭；气泡本体点击无效
- **步骤**：① 单击气泡空白/文字区域；② 单击 ✕
- **预期**：① 预览保持打开（不关闭）；② 预览关闭，回到普通消息视图。
- **失败判据**：点击气泡本体即关闭（与用户确认口径不符）。

#### UC-0011 点击主工作区其它位置不关闭
- **步骤**：预览打开时，点击预览区内的图片本体、以及点击主工作区之外（标题栏/输入框）的位置
- **预期**：预览保持打开（非模态，无「点外部关闭」逻辑）。
- **失败判据**：点击任意位置导致预览消失。

#### UC-0012 长文件名不撑破气泡
- **步骤**：预览一个文件名很长的图片（如 80+ 字符）
- **预期**：文件名以省略号截断，气泡整体宽度不超过预览区域（`max-width: 90%`），✕ 按钮仍可见可点。
- **失败判据**：气泡溢出到屏幕外或 ✕ 被挤出可视区。

### D 组：快速切换（本次核心诉求，浏览器实测）

#### UC-0013 非模态预览期间可直接在列表切换图片
- **步骤**：预览图片 A → 直接在左侧文件列表单击图片 B
- **预期**：预览内容与气泡信息**直接切换为 B**（无需先关闭），树高亮从 A 移到 B，全程无模态遮罩出现。
- **失败判据**：必须先关闭才能点列表（列表被遮挡），或切换后气泡仍显示 A 的信息。

#### UC-0014 图片 ↔ 文本互斥切换
- **步骤**：① 图片预览中 → 单击一个 `.md/.go` 文本文件；② 文本预览中 → 单击一张图片
- **预期**：① 图片预览关闭、文本预览打开（两者不同时显示）；② 文本预览关闭、图片预览打开。
- **失败判据**：两个预览视图同时叠加显示，或切换后旧视图仍在。

#### UC-0015 再次单击当前图片即关闭
- **步骤**：预览图片 A → 再次单击列表中同一张图片 A
- **预期**：预览关闭（与文本预览「点同一文件关闭」一致），树高亮清除。
- **失败判据**：预览保持打开，或高亮残留。

### E 组：回归与健壮性

#### UC-0016 附件放大与双击系统打开不回归
- **步骤**：① 在输入框粘贴/附加一张图片，点击缩略图放大；② 双击工作区图片文件
- **预期**：① 仍弹出原模态放大窗口（点击遮罩可关闭）——附件链路不受影响；② 仍调用系统默认程序打开（非预览）。
- **失败判据**：附件放大改为非模态或失效；双击变成预览。

#### 补充回归（合并前必查）
- 文本预览全部既有能力（行号、diff 高亮、Raw 切换、HEX 视图、按需加载）不受影响。
- 四套主题（dark / light / light-tp / paper）下气泡与预览背景颜色正常。
- 窗口缩放时预览区域随主工作区自适应（不出现错位/溢出）。

# FEATURE-399 优化询问用户（ask_followup_question）交互

## 背景

Web UI 中"询问用户"（select）场景渲染了无用的 [1]-[9] 批准次数按钮（标签"批准N次"，对 select 场景无用），且选项按钮是普通样式（`1. 选项`），没有快捷按钮。希望选项用虚拟键盘风格渲染——每个选项一个方形键按钮（数字 1..N）+ 选项文字，点击按钮或按物理数字键即选择对应选项；按空格可录入补充说明。

## 验收标准

1. "询问用户"（select）场景中，每个选项渲染为一个数字方形键按钮（1..N）+ 选项文字。
2. 点击选项的方形键按钮，或按物理数字键，即选择对应选项。
3. 不再显示无用的 [1]-[9] 批准次数按钮。
4. 不再显示 Enter 批准按钮。
5. 按空格可录入补充说明。
6. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

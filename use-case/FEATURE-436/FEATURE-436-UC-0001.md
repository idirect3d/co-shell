# FEATURE-436 四项 UI 改进

## 背景

1. Raw 按钮按下后切换其他文件时状态被重置（FEATURE-435 每次打开文件都重置 fvRaw=false）。
2. MD 文件解析后的内容显示时没有行号列。
3. 自动分屏融合按钮高亮背景形状与图标不对称。
4. 底部状态栏右侧预装/输出速度（XXXt/s）未用千分位格式。

## 方案

1. **Raw 状态保持**：Raw 状态用 localStorage 持久化，切换文件时保持。
2. **MD 行号列**：MD 解析渲染时也显示行号列。
3. **融合按钮胶囊形状**：融合按钮高亮背景形状改为横向胶囊，图标横向纵向居中。
4. **状态栏千分位**：状态栏速度（XXXt/s）以千分位格式显示。

## 验收标准

1. Raw 按钮按下后，切换其他文件时保持打开状态；再次打开 md 文件仍为 Raw 模式。
2. MD 文件解析后的内容显示时，左侧显示行号列。
3. 自动分屏融合按钮高亮背景为横向胶囊形状，图标横向纵向居中。
4. 底部状态栏右侧预装/输出速度（XXXt/s）以千分位格式显示（如 1,234t/s）。

## 测试用例

### UC-001 Raw 状态切换文件时保持
- 前置：Web UI 启动，打开一个 md 文件预览
- 步骤：点击 Raw 按钮打开，然后切换打开另一个 md 文件
- 期望：Raw 状态保持打开（新 md 文件仍显示原始文本）

### UC-002 Raw 状态刷新页面后保持
- 前置：Web UI 启动，打开一个 md 文件预览，点击 Raw 打开
- 步骤：刷新页面，重新打开 md 文件
- 期望：Raw 状态保持打开（localStorage 持久化）

### UC-003 MD 文件解析后显示行号列
- 前置：Web UI 启动，打开一个 md 文件预览（Raw 关，自动渲染）
- 步骤：观察 md 渲染内容
- 期望：md 渲染内容左侧显示行号列

### UC-004 融合按钮高亮背景为横向胶囊
- 前置：Web UI 启动，触发自动分屏（用户上滚）
- 步骤：观察融合按钮高亮背景形状
- 期望：融合按钮高亮背景为横向胶囊形状，图标横向纵向居中

### UC-005 状态栏速度千分位
- 前置：Web UI 启动，有 token 统计
- 步骤：观察状态栏右侧预装/输出速度
- 期望：速度（XXXt/s）以千分位格式显示（如 1,234t/s）

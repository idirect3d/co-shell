# FEATURE-621 UC-0001：任务进展「从无到有」时自动切回「任务进展」视图

> 分支：**FEATURE-621**　版本：**v0.104.0**　BUILD：**待定（编码后回填）**
> 需求（用户 2026-10-07 21:15 确认）：
> ① 触发口径 = **任务进展栏内容维度**——**任务计划 / 子代理列表 / 已加载技能** 任一由「全空」变为「非空」；
> ② 行为 = **强制切回「任务进展」视图**（与既有「自动切到动态信息」逻辑对称，**不写永久记忆**，刷新后仍按用户记忆的视图）。
>
> 现状：`web/static/app.js` 的 `applyPanels()` 只有单向自动逻辑（无任务进展内容但有动态感知内容 → 自动切到「动态信息」）；缺少反向逻辑：任务进展**从无到有**时不会把「动态信息」拉回「任务进展」，于是面板停在「动态信息」时用户看不到刚出现的新任务进展。

## 术语

- **任务进展栏内容** = `hasPlanContent = !!lastPlan || lastSubAgents.length > 0 || lastSkills.length > 0`（`applyPanels()` 内已有变量）。
- **从无到有** = 上一次 `hasPlanContent` 为假（全空）、本次为真（非空）的**状态跃变**（只在跃变的那一次处理，持续为真不重复触发）。
- **基线** = 连接态 `state` 帧带来的首帧快照——它是「加载」而非运行期「从无到有」，不触发切换（保证刷新/重连后仍按记忆视图）。

## 变更点（计划）

| 位置 | 变更 |
|---|---|
| `web/static/app.js`（模块级） | 新增 1 个变量记录「任务进展栏内容上一次的空/非空」（哨兵值表示尚无基线） |
| `web/static/app.js` `applyPanels()` | 在既有自动切 dyn 逻辑之后追加：**上一次为空 ∧ 本次非空 ∧ `planView === "dyn"`** → 把 `planView` 置回 `"plan"` 并同步开关样式（移除 `dyn` 类 / `aria-checked="false"`），**不写 localStorage** |
| `web/static/app.js` 连接态 `state` 帧处理 | 把该帧内的渲染标记为「基线」，避免连接快照把视图从记忆的「动态信息」拉回 |
| 其它 | 不改动（既有自动切 dyn 逻辑、手动切换与持久化、`setPlanView` 行为、`renderPlan`/`renderSubAgents`/`renderSkills` 均保持） |

## 用例与结果

`(R)` = 离线断言脚本（抽取真实 `applyPanels` 源码 + DOM 桩）可验证；`(M)` = 需在 `--serve` 隔离实例 + 调试浏览器实测。
> 运行时循环：先跑 `(R)` 全绿，再用浏览器对每个 `(M)` 用例逐一注入状态、断言面板视图与开关几何，最后汇总。

### A. 核心：从无到有 → 强制切回「任务进展」

- **UC-01（M）** 视图停在「动态信息」时，**任务计划**出现（`renderPlan(非空计划)`）→ 视图切回「任务进展」，`planBody` 可见并显示该计划（标题 + 步骤）。
- **UC-02（M）** 视图停在「动态信息」时，**子代理列表**由空变有（`renderSubAgents([...status=running])`）→ 切回「任务进展」，`subAgentBody` 可见。
- **UC-03（M）** 视图停在「动态信息」时，**已加载技能**由空变有（`renderSkills([...loaded])`）→ 切回「任务进展」，`skillBody` 可见。
- **UC-04（R/M）** 切换后开关状态正确：`#planSwitch` 不含 `dyn` 类、`aria-checked="false"`，文字「任务进展」回到旋钮对侧（`--ps-p` 未被残留，或与既有自动逻辑一致）。

### B. 不触发 / 无误伤

- **UC-05（R）** 视图本就是「任务进展」时内容从无到有 → 无副作用（仍为 plan，开关状态不变）。
- **UC-06（R）** 内容**从有到有**（非从空，如步骤更新、子代理增删、技能增删）→ 不触发切换。
- **UC-07（R）** 内容**从有到无** → 本逻辑不触发（不因清空而切到「动态信息」；是否切到 dyn 仍由既有单向逻辑决定，行为与改动前一致）。
- **UC-08（R）** 面板被关闭（`panelPrefs.plan === false`）时执行从无到有逻辑不抛错，`planView` 与开关状态仍同步。

### C. 记忆与加载（刷新 / 重连）

- **UC-09（M）** 记忆视图为「动态信息」时刷新页面（连接态 `state` 帧已带任务计划）→ 加载后仍停在「动态信息」（基线不触发切回）。
- **UC-10（R/M）** 自动切回**不写永久记忆**：切换后 `localStorage["co-shell.planView"]` 仍为切换前的值。
- **UC-11（M）** 断线自动重连（收到带计划的 `state` 帧）→ 视图不被重连拉回（保持连接前视图）。

### D. 回归（既有行为不变）

- **UC-12（R/M）** 无任务进展内容但有动态感知内容、且视图为「任务进展」→ 仍自动切到「动态信息」（既有单向逻辑保持）。
- **UC-13（M）** 手动点击 / 拖拽开关切换视图仍生效，并被记忆（`persist=true` 写 localStorage）；自动切换不会被再次误触发而覆盖用户之后的手动选择。
- **UC-14（R/M）** 头部计数胶囊随视图刷新：视图为「任务进展」显示 `已完成+进行中/总数`，为「动态信息」显示待确认 + 未确认数；从无到有自动切换后即时更新。

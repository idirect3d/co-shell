# FEATURE-536 用例：身份与个性设置界面提示信息（分支 FEATURE-536 / v0.66.0）

> 需求（用户原话）：
> 对新的身份与个性设置界面再做一个优化：
> 1、在左侧标签栏的底部，增加一个提示信息，提示用户该配置中的数值与系统提示词相关，如果修改可能导致大模型请求缓存命中率降低、增加费用和变更后首次访问预处理时间变长，需要谨慎修改。
> 【在各输入栏下方增加显示以下提示信息，位置在保存按钮的左边，使用字体可显示两行，两行的高度基本保持与保存按钮高度一致】
> 2、"Agent 名称"：命名当前 co-shell 实例，会注入系统提示词，可能影响 LLM 的行为，也可用于在 co-shell-hub 中辨识当前实例。
> 3、"Agent 描述"：描述当前 co-shell 实例的职责，会注入系统提示词，可能影响 LLM 的行为，也可用于在 co-shell-hub 中向其他 co-shell 实例介绍自己的能力。
> 4、"用户名"：用于 co-shell 辨识你，可能轻微影响 LLM 的行为。
> 5、"用户描述"：用于 co-shell 了解你的岗位、职责、偏好等，以便更好的为你提供帮助，可能直接影响 LLM 的行为。
> 6、"Agent 核心原则"：co-shell 的核心工作原则，直接影响 LLM 的行为。
> 7、"Agent 能力"：让 co-shell 了解自己的能力，直接影响 LLM 的行为。
> 8、"规则"：co-shell 的做事规则，尽量不要修改/删除 {} 占位符，直接影响 LLM 的行为。

## 实现（改动面）

- `web/static/index.html`：身份弹窗左侧导航容器（`#identityNav`）改为「分类列表 + 底部提示」两段式（新增底部提示节点）。
- `web/static/app.js`：① `I18N.zh` / `I18N.en` 新增 `identityNavHint` 与 7 条字段说明 `identityHint{Name,Description,UserName,UserDescription,Principles,Capabilities,Rules}`；② `renderIdentityNav` 渲染底部提示；③ `renderIdentityField` 把「字段说明 + 保存按钮」包进同一行（`.identity-field-foot`），说明在左、保存按钮在右。
- `web/static/style.css`：新增 `.identity-nav-hint`（左栏底部提示，可换行、小字、弱化色）与 `.identity-field-foot` / `.identity-hint`（说明行 = flex 行、说明占满剩余宽度、两行字号/行高使两行总高≈保存按钮高度）。

## UC-0001（静态）左栏底部提示存在，且文案覆盖四项要点（中文）

**前置**：`web/static/app.js` 为当前分支版本。

**操作**：检查 `identityNavHint` 的中文文案。

**预期**：文案非空，且同时包含以下语义要点（关键词命中）：
- 与系统提示词相关（含「系统提示词」）；
- 可能降低请求缓存命中率（含「缓存命中率」）；
- 增加费用（含「费用」）；
- 变更后首次访问预处理时间变长（含「预处理」）；
- 谨慎修改（含「谨慎」）。

**验证方式**：`node -e` 提取 `I18N.zh.identityNavHint` 逐词断言，或浏览器切到中文后肉眼核对。

## UC-0002（运行时）打开身份与个性弹窗，左栏底部提示可见且不遮挡分类项

**前置**：以 `--serve` 启动 co-shell（调试浏览器单客户端）；窗口为宽屏（≥900px）。

**操作**：点击 Logo → 「身份与个性」，在五个分类间切换。

**预期**：
- 左栏 5 个分类项完整可见、均可点击切换；
- 左栏**底部**显示提示文案（与最后一个分类项之间有明显间隔），文案为多行小字、完整可见不截断；
- 提示在任意分类下均显示（不随分类切换消失）；
- 弹窗本体无纵向滚动条，提示不超出弹窗边界。

**验证方式**：浏览器截图核对 + `browser_evaluate` 读取 `#identityNav .identity-nav-hint` 的 `textContent`、`offsetHeight`、`scrollHeight`（`scrollHeight <= offsetHeight` 表示未截断）。

## UC-0004（运行时）说明为两行、两行总高与保存按钮高度基本一致

**前置**：同 UC-0002；中文界面。

**操作**：`browser_evaluate` 测量每个字段的 `.identity-hint` 与同一行的 `.identity-save`。

**预期**（口径经用户拍板 = 自动折行）：
- 说明区至少预留两行高度（`min-height` = 2 × line-height ≈ 35px），与同行保存按钮高度差值 ≤ 6px（“基本一致”）；
- 文案能在两行内显示的（中文 6/7 条、窄屏下英文全部）实际渲染为两行；
- 超出两行的长文案（中文「Agent 描述」、宽屏英文）按自然折行显示 3~4 行，**不截断、不加省略号**，文字完整；
- 不出现横向溢出（`scrollWidth <= clientWidth + 1`）；
- 说明与保存按钮垂直居中对齐（`align-items:center`，中心差 ≤ 1px）。

**验证方式**：`browser_evaluate` 输出每行的 `hintLines` / `hintHeight` / `saveHeight` / `diff`，逐项断言。

## UC-0006（运行时）窄屏（drill-down）下提示仍可见、保存按钮完整、文本框自适应不变

**前置**：同 UC-0002。

**操作**：用 `browser_evaluate` 给 `body` 加上 `narrow` 类（模拟窄屏），进入某分类详情后再逐类切换；恢复。

**预期**：
- 进入分类详情后，字段说明与保存按钮同时可见，保存按钮未被裁切（`rect.bottom <= pane.bottom + 1`）；
- 说明仍为两行，未被压缩成省略号；
- 文本框仍择满面板剩余高度（`min-height:160px` 兜底生效），面板溢出为 0；
- 点 `<` 返回分类列表后，左栏底部提示仍在。

**验证方式**：`browser_evaluate` 逐项读取 rect 与 `getComputedStyle` 断言；截图核对。

## UC-0007（回归）保存功能与既有行为不受影响

**前置**：同 UC-0002。

**操作**：在「智能体 / 用户」页修改 `Agent 名称`（或无破坏性地修改后改回），点击保存；分别验证单行与多行字段。

**预期**：
- 保存按钮点击后仍发送 `identity_set` 并收到成功提示，字段值持久化不变（保存链路未被 DOM 结构调整破坏）；
- 切换分类时未保存的编辑内容仍在（既有隐藏而保留 DOM 的行为不变）；
- 系统设置弹窗（`#settings`）样式未受影响（未复用 class 冲突）。

**验证方式**：手动 + `browser_evaluate` 断言 `#identityResult` 出现成功提示；`git diff` 确认仅动身份弹窗相关选择器。

## UC-0008（微调，BUILD-1075）左栏提示：撑满剩余空间 + 垂直居中 + 强调色 + 无分割线

**前置**：同 UC-0002（已打开身份弹窗、左栏已渲染）。

**需求（用户反馈并拍板）**：“标签页下方新增加的提示信息，在此区域内垂直方向居中使用高亮色显示，不要分割线”；区域口径 = **左栏标签列表下方的整块剩余空间**；颜色 = **主题强调色 `var(--accent)`**。

**操作**：打开身份弹窗，用 `browser_evaluate` 取提示块的 `rect`、文字 range 的 `rect` 与 `getComputedStyle`；再切换 `body.narrow` + `.settings-drilled` 复测。

**预期**：
- 提示块 `flex:1 1 auto` 撑满标签列表下方的剩余空间（高度远大于文字高度）；
- 文字在块内垂直居中：上留白 ≈ 下留白；
- `color` = `--accent`（深色主题 `rgb(63, 214, 239)`）；
- `border-top-width: 0px`（无分割线）；
- 弹窗/文档横向溢出 0，左栏纵向溢出 0；7 条字段说明与保存按钮布局不受影响。

**验证方式**：`browser_evaluate` 断言 + 截图核对。

# FIX-618 验收测试用例（UC-0001）：交互控制事件不再产生空 SYS 块

> 权威依据：`ROADMAP.md` v0.102.2 / FIX-618；分支 **FIX-618**，版本 **v0.102.2**（FIX 走 patch 递增）。
> 相关代码：`web/static/app.js`（`renderEvent` 2279 起、事件分发 768-776、通用分支 2855 起、`eventBlockLabel` 2087、`CHAN_LABEL` 925）、`web/session.go`（`emitInteractionEvent` 1349、事件常量 58-59）、`agent/out.go`（`ChannelREPL` = "repl"，34 行）。

> 问题（已受控复现）：`interaction_request` / `interaction_resolved` 以 `ChannelSystem` + **空文本** 下发且**会被持久化**；`app.js:776` 对每个事件**无条件**调用 `renderEvent`；早退分支未覆盖这两个类型 → 落到 `app.js:2855` 通用分支，按 `CHAN_LABEL["system"]="SYS"` 建出一个**空文本的 SYS 块**。一次交互 = 2 个事件 → **正好 2 个空 SYS 块**；因事件持久化，重载回放后会再次画出。FIX-615 拦的是 `pushText`（固定 `ChannelREPL="repl"` → 渲染为 REPL 块），与本路径无关。

> 已确认决策（用户确认，不可改动）：
> ① **方案 A+B**——A：`renderEvent` 早退区显式忽略 `interaction_request`/`interaction_resolved`；B：通用分支在 `makeBlock` 前加「无文本则不建块」兜底；
> ② 版本归属 **v0.102.2**，任务号 **FIX-618**。

> 已知限制（本次不做）：`pushText` 空白过滤保留不动；回放路径不调用 `handleInteractionEvent`（重载后未答复交互不自动重开）另行评估。

## 实现要点（预期）

`web/static/app.js` **仅两处**，其余不动：
1. 早退区（`await_input` / `turn_start` 旁，约 2307 行后）新增：
   `if (ev.type === "interaction_request" || ev.type === "interaction_resolved") return;`
2. 通用分支（约 2855 行）：取 `const text = ev.text || "";`，在 `makeBlock(...)` **之前** `if (!text) return;`，并把该分支内两处 `ev.text || ""` 改用局部 `text`。

不改后端、不改 `handleInteractionEvent`、不改 CSS。

## 用例详情

### A. 静态断言（`web/fix618_test.go`，读 `static/app.js`）

**A-001 显式忽略交互控制事件**
- 断言：含 `ev.type === "interaction_request" || ev.type === "interaction_resolved"`，且该判断行之后紧跟 `return;`。

**A-002 通用分支「无文本不建块」**
- 断言：`if (!text) return;` 出现位置**早于** `makeBlock(eventClass(ev), blockLabel, msgIndex)`；且分支内含 `const text = ev.text || "";`。

### B. 运行时复现对照（静态实例 + 调试浏览器，用真实 `renderEvent`）

**B-001 注入两事件 → 建块数 0**
- 步骤：清空 `#streamB`；依次 `renderEvent({type:"interaction_request", chan:"system", level:"info", text:"", meta:{id:"p1"}})` 与 `renderEvent({type:"interaction_resolved", chan:"system", level:"info", text:"", meta:{id:"p1"}})`；统计 `.ev` 数量。
- 断言：改动前 = **2**（均为 `ev system level-info`、label `SYS`、`bodyLen: 0`）；改动后 = **0**。

**B-002 未知空文本事件不建块**
- 步骤：`renderEvent({type:"unknown_ctl", chan:"system", text:""})`。
- 断言：建块数 0。

### C. 不误伤回归（运行时）

**C-001 非空文本的未知事件仍建块**
- 步骤：`renderEvent({type:"unknown_ctl", chan:"system", text:"hi"})`。
- 断言：建 1 块，label `SYS`，正文 `hi`。

**C-002 REPL 块合并不受影响**
- 步骤：连续 `renderEvent({type:"ui_text", chan:"repl", text:"a"})` 两次。
- 断言：合并为 1 个 `ev repl` 块，正文 `a\na`。

**C-003 流式块不受影响**
- 步骤：`renderEvent({type:"content_chunk", chan:"llm", text:"hello"})`。
- 断言：出现 LLM 块且正文含 `hello`。

**C-004 交互对话框仍正常**
- 步骤：`handleInteractionEvent({type:"interaction_request", meta:{id:"p2", mode:"confirm"}})`。
- 断言：确认对话框出现（`#askArea` 可见或对应 DOM 存在）；关闭后不影响消息流。

### D. 端到端

**D-001 真实会话无空 SYS 块**
- 步骤：隔离实例跑一轮会触发交互（ask / 工具确认 / 完成确认）的会话；结束后统计消息流中 `bodyLen === 0` 的 SYS 块数量。
- 断言：数量 = **0**。

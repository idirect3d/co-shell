# FIX-586 UC-0002：历史 env 三级降级——运行时用例

> 分支：**FIX-586**　版本：**v0.91.2**　产物：`work/co-shell-0.91.2.darwin.arm64`、`work/co-shell-hub-0.91.2.darwin.arm64`
> 观测对象：**真正发给模型的请求体**（`log/llm-interaction-*.log`），不是会话文件、不是 Web 回放、不是 `:context full`。

## 目的

证明修复在真实运行链路上生效：多轮工具调用的会话中，只有最新一条消息带完整 env，其前一条为精简（L1），更早的全部只剩 `<time>` + `<message_no>`（L2）；且会话自身持久化内容不受影响。

## 前置条件

```bash
cd /Users/direct3d/github/co-shell
ls -l work/co-shell-0.91.2.darwin.arm64 work/co-shell-hub-0.91.2.darwin.arm64   # 两个产物均存在
grep -n '"env_history_prune"\|"env_history_full_keep"\|"env_history_lite_keep"' config.json
# 期望：true / 1 / 1
```

> ⚠️ `log/llm-interaction-*.log` 单文件可达 GB 级，**必须**用带文件范围的 grep（`grep ... log/llm-interaction-<本次会话>.log`），禁止对全仓或整个 `log/` 目录做无范围检索（本次缺陷 FIX-585 的起因同源）。

## 用例 A：同一会话多轮工具调用后，请求体出现 L2/L1/L0 三档

```bash
# 1) 用新产物跑一个需要多次工具调用的任务（≥3 轮工具调用）
./work/co-shell-0.91.2.darwin.arm64 run --workdir /tmp/fix586-rt \
  --prompt "依次列出当前目录、当前时间、以及 go 版本，然后给出三行总结"

# 2) 定位本次会话的请求日志，观察 envelope 分档
grep -o '<environment_details>' log/llm-interaction-<本次>.log | wc -l     # envelope 总数
grep -c '<current_dir>' log/llm-interaction-<本次>.log                     # 仅最新一条为 L0
grep -o '<environment_details>[^<]*<time>[^<]*</time>[^<]*<message_no>[^<]*</message_no>[^<]*</environment_details>' \
  log/llm-interaction-<本次>.log | head                                    # 存在 L2 极简 envelope
```

**期望**：
- 最后一轮请求中，带 `<current_dir>` 的 envelope 只有 **1** 个（最新一条，L0）；
- 存在**只含 `<time>` + `<message_no>`** 的 envelope（L2），且条数随会话变长而增加；
- L1 档（含 `<cwd>`、`<task_plan>`，无 `<current_dir>/<tools>/<research>`）在倒数第二条出现。

## 用例 B：关闭开关后恢复全量（对照）

```bash
./work/co-shell-0.91.2.darwin.arm64 run --workdir /tmp/fix586-rt --prompt ":set env-history-prune off" 2>/dev/null || true
# 或直接在 config.json 中将 "env_history_prune" 置 false 后重跑用例 A 的任务
```

**期望**：最后一轮请求中每一条历史 envelope 都含 `<current_dir>`（无 L1/L2 降级），证明修复未改变“关即现状”的承诺。

## 用例 C：会话持久化与回放不受影响（设计使然）

```bash
./work/co-shell-0.91.2.darwin.arm64 run --workdir /tmp/fix586-rt --session <会话 id> --prompt ":context full" | grep -c '<current_dir>'
```

**期望**：会话历史中**每条**含 env 的消息都保留完整 `<current_dir>`（降级只作用于“发给模型的这一份拷贝”，持久历史与 `:context full` 保持完整）。

## 用例 D：FEATURE-583 的 `<skills>` 注入未被降级吞掉

```bash
grep -c '<skills>' log/llm-interaction-<本次>.log    # 期望 >0（每轮请求各一次）
grep -o '<skills>[^<]*</skills>' log/llm-interaction-<本次>.log | head -1
```

**期望**：每轮请求的**最新** envelope 中仍含 `<skills>` 列表（顺序保证：先降级、后注入）；旧 envelope 中不出现 `<skills>`。

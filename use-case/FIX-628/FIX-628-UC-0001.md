# FIX-628 UC-0001：顶栏 agent 名与工作区路径对齐、去掉 “-” 分隔符

> 分支：**FIX-628**　版本：**v0.108.3**　BUILD：**待编译**
> 需求（用户 2026-10-10 11:46 反馈，11:47 确认细节）：
> ① 新增的工作区绝对路径与前面的 agent 名**不在同一水平线**，需垂直居中、上下边距一致；
> ② **去掉两者之间的 “-” 符号**，但保持合理间距（确认取 **8px**）；
> ③ 路径**字号与 agent 名一致（同为 14px）**，仅颜色区分。

## 根因

- `.top-center` 为 `display: flex; justify-content: center;`，**未设 `align-items`**（默认 `stretch`）：两个 flex 项被拉伸到同一高度，但各自字号/字体不同（agent 名继承 14px 无衬线，路径为 12px 等宽），单行文本在各自盒子内顶部排布 → 路径视觉偏高，与 agent 名不在一条水平线。
- 分隔符来自 `web/static/app.js` 的 `renderWorkspacePath()` 中硬编码的 `" - " + path`。

## 设计基线（本次改动）

| 位置 | 变更 |
|------|------|
| `web/static/style.css` → `.top-center` | 增加 `align-items: center;` |
| `web/static/style.css` → `.ws-path` | 删除 `font-size: 12px` 与 `font-family: ui-monospace…`（改为继承，与 agent 名同字号同字体）；新增 `margin-left: 8px;`；保留 `color: var(--fg-faint)`、`min-width: 0`、`overflow: hidden`、`white-space: nowrap` |
| `web/static/app.js` → `renderWorkspacePath()` | 去掉 `" - "` 前缀（三处），只渲染路径本身；中间省略与 `title` 完整路径逻辑不变 |
| 不改动 | 后端、`app/macos/CoShellApp.swift`、窄屏隐藏规则（`body.narrow .ws-path { display: none; }`） |

### UC-02 (R) 路径与 agent 名同字号、仅颜色区分、8px 间距

- 断言：`.ws-path` 含 `margin-left: 8px;` 且颜色仍为 `var(--fg-faint)`。

### UC-03 (R) 文本不含 “-” 分隔符

- 断言：`app.js` 的 `renderWorkspacePath()` 中不再出现 `" - "` 拼接（三处均已去除）。

### UC-04 (M) 浏览器实测：同一水平线 + 间距 8px + 无 “-”

- 断言：`#wsPath` 文本**不以** ` - ` 开头，且等于工作区绝对路径。

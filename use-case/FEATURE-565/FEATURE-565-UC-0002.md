# FEATURE-565 运行时用例 UC-0002：子代理 id 的必填与合法性校验

## 目标

验证 `launch_sub_agent` 的 `id` 参数在新模型中**必填**，且只能取当前会话 A1..An 中**当前未运行**的槽位；
不传、格式非法、超出范围（`A0`、`A{n+1}`）、已被运行中的子代理占用，都必须被拒绝并给出多语言错误提示。

## 前置条件

- 工作区为 co-shell 仓库，`work/` 下已构建本分支可执行码（v0.79.0）。
- 上限 N = 5（默认），即合法 id 集合为 `A1..A5`。
- 会话未运行任何子代理。

## 步骤

1. 不带 id 调用：`launch_sub_agent(tasks=[{instruction:"ls -la"}], timeout_seconds=60)`。
   - 预期：**拒绝**，错误提示 id 为必填，且说明合法取值来自当前会话的 A1..An。
2. id = `A0`：`tasks=[{id:"A0", instruction:"ls -la"}]`。
   - 预期：拒绝（不在 A1..An 范围内）。
3. id = `A6`（N=5）：`tasks=[{id:"A6", instruction:"ls -la"}]`。
   - 预期：拒绝（超出上限，提示当前最大可用数为 5）。
4. id 格式非法：分别用 `"a1"`、`"A"`、`"A1 "`（尾空格）、`"A-1"`、`"B1"`、`"AA1"`、超过 32 字符的 id。
   - 预期：全部被拒绝；提示合法格式为 `A1`..`A{n}`。
5. 先用 `A2` 启动一个长任务（如 `timeout_seconds` 很小、指令为长时间命令，使其转后台保持 running）。
   - 随后再次以 `id="A2"` 创建：预期**拒绝**（该槽位正在运行），错误提示应指出 `A2` 正在运行并给出当前可用槽位。
6. 一次调用中传多个任务：`tasks=[{id:"A1",...},{id:"A1",...}]`（重复 id）。
   - 预期：拒绝（同一批内 id 必须互不重复），并指出重复的 id。
7. 一次调用中传多个合法且互不重复的 id：`tasks=[{id:"A1",...},{id:"A3",...},{id:"A5",...}]`。
   - 预期：接受，三个子代理同时启动（数量未超过 N）。

## 预期结果

- 校验在**启动进程之前**完成：被拒绝的请求不产生 `sub-agents/<id>/` 目录、不出现清单行。
- 错误文案为 i18n 化文本（zh/en 均存在对应 key），且包含足够信息让主 agent 自我纠正：合法范围（A1..An）、当前上限 N、哪些槽位正在运行。
- 校验失败时整批任务不启动（不允许「部分成功」带来的 id 语义混乱）。

## 验证方式

- 观察工具返回文本（错误消息）与 `ls sub-agents/`。
- 单元测试（table-driven）：必填缺失、A0、A{n+1}、大小写与字符集、长度上限、运行中占用、批内重复、批内混合合法/非法。

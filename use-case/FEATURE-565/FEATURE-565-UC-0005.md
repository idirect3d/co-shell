# FEATURE-565 运行时用例 UC-0005：右侧清单只显示运行中的子代理（空态隐藏整栏）

## 目标

验证 Web UI 右侧「任务进展」栏下方的子代理清单**只显示正在运行**的子代理；
某一个子代理结束（完成/失败/被杀）后其行消失；当前会话没有任何运行中子代理时，**整栏隐藏（不占位）**。
同时验证刷新/重连后仍与后端一致（沿用 FEATURE-564 的快照回放机制）。

## 前置条件

- 工作区为 co-shell 仓库，`work/` 下已构建本分支可执行码（v0.79.0）。
- `--serve` 启动，浏览器打开 Web UI（先按 `Cmd/Ctrl+Shift+R` 强刷一次，排除静态资源缓存）。
- 上限 N = 5（默认），会话初始无任何子代理。

## 步骤

1. 页面初始状态（本会话从未启动子代理）观察右侧栏。
   - 预期：**没有**「子代理」标题与清单区域（整栏隐藏，不占位、不留空白条）。
2. 启动一个长任务子代理 `A1`（指令使其运行较久，如 sleep 或大范围搜索）。
   - 预期：清单区域**立刻出现**（事件驱动推送），显示 1 行：`A1 <指令截断30字符>(…)`。
3. 等待 `A1` 正常结束（completed）。
   - 预期：该行**消失**；回到无运行中子代理的状态 → 整栏隐藏。
4. 启动 `A1`、`A2` 两个子代理，其中让 `A2` 被 kill（`kill_sub_agent(ids=["A2"])`）。
   - 预期：`A2` 的行消失，`A1` 的行仍在；清单始终只有「运行中的」那一行。
5. 页面**刷新（F5）**，观察清单。
   - 预期：刷新后清单仍正确显示当前运行中的子代理（`sendState` 快照回放），不出现空白或旧数据。
6. 断开再重连（关标签页重开 / WebSocket 重连）。
   - 预期：同上，清单与后端实际运行中的子代理一致。
7. 切换到另一个会话，再切回本会话。
   - 预期：清单只显示**当前会话**运行中的子代理（切换会话会主动推送刷新）。

## 预期结果

- 清单口径 = 当前会话中**状态为 running**（且进程确实存活，stale 的不算）的子代理，最多 N 行。
- 没有运行中子代理时，标题与清单区域都不渲染（`display:none`），右侧栏只保留「任务进展」本身。
- 刷新/重连/切换会话后清单与后端一致（无缓存残留、无旧行残留）。

## 验证方式

- `browser_evaluate` 读取 `#subAgentHead` / `#subAgentBody` 的 computed style 与子项数量：
  - 运行中 N 个 → 行数 = N；
  - 全部结束 → 两者均 `display:none`。
- 用 `browser_screenshot` 目视比对。
- 单元测试：`Rows()` 过滤非 running；空结果时前端隐藏（快照回放 `sub_agents` 事件负载为 `[]`）。

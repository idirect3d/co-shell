# FIX-415 修复 Web UI TOOL 块输入参数子块 Raw 开关默认状态反了

## 背景

FEATURE-412 增加"Raw"小胶囊开关控制输入参数子块是否进行 md 渲染。当前实现默认 `rawMode=true`（显示原始内容），但 Raw 开关默认无 `.on` class（显示为关闭），导致开关视觉状态与逻辑状态不一致（显示原始内容但开关显示为关闭）。

修复方案：默认 Raw 模式关闭（`rawMode=false`，进行 md 渲染），Raw 开关默认关闭（无 `.on`），使开关视觉状态与逻辑状态一致。

## 验收标准

1. 输入参数子块默认进行 md 渲染（rawMode=false）。
2. Raw 开关默认显示为关闭状态（无 `.on`），与默认进行 md 渲染的逻辑状态一致。
3. 点击 Raw 开关后，开关切换为打开状态（高亮 `.on`），参数子块切换为原始内容显示。
4. 再次点击 Raw 开关后，开关切换为关闭状态，参数子块恢复为 md 渲染。
5. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 Raw 开关默认关闭
- 前置：Web UI 已加载，触发 TOOL 调用（有流式参数）

- 期望：Raw 开关默认显示为关闭状态（无 `.on`），且参数子块进行 md 渲染

### UC-002 默认进行 md 渲染
- 前置：Web UI 已加载，触发 TOOL 调用，参数含 md 语法
- 步骤：观察参数子块内容
- 期望：参数内容以 md 渲染显示（如 `**加粗**` 渲染为加粗），且 Raw 开关为关闭状态

### UC-003 点击开关切换为原始内容
- 前置：Web UI 已加载，触发 TOOL 调用，Raw 开关默认关闭
- 步骤：点击 Raw 开关（打开）
- 期望：Raw 开关切换为打开状态（高亮 `.on`），参数子块切换为原始内容显示

### UC-004 再次点击恢复 md 渲染
- 前置：Web UI 已加载，触发 TOOL 调用，Raw 开关已打开
- 步骤：再次点击 Raw 开关（关闭）
- 期望：Raw 开关切换为关闭状态（取消高亮），参数子块恢复为 md 渲染

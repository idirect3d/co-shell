# FIX-334: 修复 KeyCmdMig_* 中文资源双重转义换行

## 背景

`:model switch` 等中文界面输出 `(优先级: 20)\n  [2]`——模型列表项之间显示字面 `\n` 而非换行。

## 根因

i18n/zh.go 的 `KeyCmdMig_*` 资源值使用 `\\n`（源码双反斜杠+n），Go 双引号解码后得到**字面 `\n` 两字符**而非换行。143 行受影响。en.go 在 FIX-333 翻译时已用单转义 `\n`（正确），中文界面立即暴露 zh.go 缺陷。

## 修复

将 zh.go 中 `KeyCmdMig_*` 行的 `\\n` 全部还原为 `\n`（真实换行）。`KeySettingCmd_615` 教学示例中的 `\\n` 是展示给 LLM 的字面 JSON 参数格式，有意保留。

## 用例

- UC-0001: `:model switch` 列表项间显示真实换行
- UC-0002: `KeyCmdMig_*` 无 `\\n` 残留（KeySettingCmd_615 除外）
- UC-0003: `go build ./...`、`go test ./i18n/` 全绿

## 验收

1. zh.go `KeyCmdMig_*` 行的 `\\n` 数量为 0（仅 KeySettingCmd_615 教学示例保留）
2. build/test 全绿

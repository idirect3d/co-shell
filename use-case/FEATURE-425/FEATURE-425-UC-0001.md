# FEATURE-425 文本文件只读预览

## 背景

Web UI 工作区文件目前只能双击用系统程序打开，无法在界面内直接查看文本文件内容。需要支持在弹窗中只读预览文本文件，带语法高亮和 git diff 高亮。

## 方案

1. **打开交互**：工作区文件行**单击**预览文本文件（新功能），**双击**仍用系统程序打开（现有行为），两者区分明确。
2. **单文件显示**：前端维护当前打开文件状态，点击新文件立即丢弃当前文件快速切换，重复点选当前文件无反应。
3. **弹窗布局**：弹窗绝对定位覆盖主消息区（#stream-wrap）内部，不覆盖工作区/任务进展/录入框，窗口变化自动缩放。
4. **大文件按需加载**：后端新增按行范围读取 API，前端滚动时按需预读，>100K 文件不一次读入内存。
5. **Go 语法高亮**：前端 JS 正则实现（关键字/方法/字符串/变量），参考 vscode 配色。
6. **git diff 高亮**：后端返回当前文件未提交修改的行级数据，前端按行着色。

## 验收标准

1. 工作区单击文本文件（源代码/txt/md/csv/shell脚本/配置文件等）在弹窗中显示内容。
2. 工作区双击文本文件仍用系统程序打开（不触发预览弹窗）。
3. 单击新文件立即替换当前显示内容，重复点选当前文件无反应。
4. 弹窗覆盖主消息区 90% 以上，不覆盖工作区/任务进展/录入框，窗口变化自动缩放。
5. >100K 文件按需加载，滚动时预读，不一次读入内存。
6. Go 文件关键字/方法/字符串/变量高亮，参考 vscode 配色。
7. git 版本控制下，未提交修改按 diff 方式高亮（新增绿/删除红）。
8. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 单击文本文件预览
- 前置：Web UI 已加载，工作区有文本文件（如 main.go）
- 步骤：单击工作区中的 main.go 文件行
- 期望：弹窗显示 main.go 内容，覆盖主消息区，不覆盖工作区/任务进展/录入框

### UC-002 双击仍用系统打开
- 前置：Web UI 已加载，工作区有文本文件
- 步骤：双击工作区中的文本文件行
- 期望：调用系统程序打开（/api/open），不触发预览弹窗

### UC-003 单文件快速切换
- 前置：已预览文件 A
- 步骤：单击文件 B
- 期望：立即丢弃文件 A，显示文件 B 内容

### UC-004 重复点选当前文件无反应
- 前置：已预览文件 A
- 步骤：再次单击文件 A
- 期望：无反应，不重新加载，弹窗保持

### UC-005 弹窗自动缩放
- 前置：已预览文件
- 步骤：调整浏览器窗口大小
- 期望：弹窗自动缩放，仍覆盖主消息区 90% 以上，不覆盖工作区/任务进展/录入框

### UC-006 大文件按需加载
- 前置：工作区有 >100K 的文本文件
- 步骤：预览该文件并滚动到底部
- 期望：内容按需加载，滚动时预读，不一次读入内存

### UC-007 Go 语法高亮
- 前置：已预览 Go 源文件
- 步骤：观察代码渲染
- 期望：关键字/方法/字符串/变量有不同颜色高亮，参考 vscode 配色

### UC-008 git diff 高亮
- 前置：工作区是 git 仓库，当前文件有未提交修改
- 步骤：预览该文件
- 期望：未提交修改按 diff 方式高亮（新增绿/删除红）

### UC-009 编译验证
- 前置：无
- 步骤：运行 `go build ./... && go vet ./... && go build -o work/co-shell .`
- 期望：全部通过，无编译错误、无 vet 告警

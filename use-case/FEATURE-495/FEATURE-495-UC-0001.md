# FEATURE-495 提交指令后焦点自动移出 — 测试用例

> 任务：Web UI 优化——用户在主消息框（#input textarea）提交指令后，焦点自动移出（blur）。因 document 级 keydown 监听已能在用户敲击普通字符键时自动把焦点带回输入框，故不影响后续录入。
> 分支：FEATURE-495　版本：v0.43.0
> 测试方式：浏览器手动验证（serve 模式）+ node --check 语法检查

## 前置条件
- 以 `--serve` 启动 Web UI（不自动打开浏览器），用调试浏览器访问
- 主消息框元素 id 为 `input`（textarea）

## 用例

### UC-001 正常发送指令后焦点移出
- **操作**：在输入框输入一条指令，按 Enter 发送
- **预期**：指令发送后，输入框内容清空，且焦点自动移出输入框（`document.activeElement` 不再是 `#input`，输入框无光标闪烁）

### UC-002 发送后敲击普通字符键焦点自动回焦
- **操作**：接 UC-001，焦点已移出后，直接敲击一个普通字符键（如字母 a）
- **预期**：document 级 keydown 监听将焦点自动带回输入框，字符落入输入框（不影响后续录入）

### UC-003 任务运行中发送动态消息后焦点移出
- **操作**：任务运行中（按钮为 ⏸），在输入框输入文字并发送（触发 user_message 动态事件）
- **预期**：发送后输入框清空且焦点移出

### UC-004 回答交互补充信息后焦点移出
- **操作**：交互（confirm/select）挂起时，点击输入框进入补充模式，输入补充文字并发送
- **预期**：补充信息作为交互答案发送后，输入框清空且焦点移出

### UC-005 上传附件发送后焦点移出
- **操作**：粘贴/选择图片附件，输入文字后发送（走 uploadAndSend 路径）
- **预期**：附件上传并发送成功后，输入框清空且焦点移出

### UC-006 空输入不触发焦点移出
- **操作**：输入框为空（无文字无附件）时按 Enter
- **预期**：sendInput 直接 return，不发送、不改变焦点状态（无异常）

### UC-007 语法与回归
- **操作**：`node --check web/static/app.js`
- **预期**：无语法错误；既有交互（历史 ↑↓、IME 组合输入、Shift+Enter 换行）不受影响

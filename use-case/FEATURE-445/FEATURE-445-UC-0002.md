# FEATURE-445-UC-0002 超出 100px 不跟随 + 底部向下箭头按钮

## 前置条件
- Web UI 已启动，有足够长的输出内容使滚动条出现

## 操作步骤
1. 让 LLM 输出大量内容，使滚动条出现
2. 将滚动条向上滚动，使位置超出距内容末尾 100 像素
3. 观察底部是否出现向下箭头按钮
4. 继续让 LLM 输出新内容，观察是否跟随
5. 点击底部向下箭头按钮

## 预期结果
- 滚动位置超出 100px 后，底部悬浮显示向下箭头按钮（下三角矢量图标、扁平效果、胶囊边框、半透明）
- 鼠标滑过按钮时恢复高亮
- 滚动位置超出 100px 时，新内容输出不自动跟随（方便查看历史）
- 点击向下箭头按钮后，滚动到内容末尾并恢复自动跟随，按钮隐藏

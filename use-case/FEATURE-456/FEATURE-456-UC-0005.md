# FEATURE-456-UC-0005 判定输入组装（用户消息增量 + taskplan + 主LLM报告）

## 前置条件
- 已编译最新可执行码（`go build -o work/co-shell .`）
- 监督 LLM 已启用

## 操作步骤
1. 在一个会话中，用户先提出任务 A，中途补充需求 B（改变思路）
2. 主 LLM 完成工作后调用 `attempt_completion` 触发监督审查
3. 观察监督 LLM 收到的判定输入是否包含：
   - 用户**历次**消息（含任务 A 和补充需求 B，带时间）
   - 当前 taskplan 的 description
   - 主 LLM 最后一次任务完成报告
   - 场景入口信息（区分完整任务/子任务）
   - 当前任务执行进度清单
4. 再次触发一次监督审查（同一会话），观察是否只给**增量**用户消息（记录上次消息序号）

## 预期结果
- 监督 LLM 判定输入包含：用户历次消息（含中途改需求）+ taskplan description + 主 LLM 最后报告 + 场景入口信息 + 任务进度清单
- 多次判定时，用户消息只给增量（从上次消息序号之后的新增部分）
- 监督 LLM 能感知用户中途改变思路（补充需求 B）

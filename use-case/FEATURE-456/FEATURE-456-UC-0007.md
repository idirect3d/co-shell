## 前置条件
- 已编译最新可执行码（`go build -o work/co-shell .`）
- 监督 LLM 已启用

## 操作步骤
1. 让主 LLM 完成一个**不完整**的任务（故意遗漏某个子目标），调用 `attempt_completion`
2. 监督 LLM 判定**打回**（approved=false），给出理由和建议
3. 观察监督 LLM 的理由和建议是否作为 **user 消息**进入主 LLM 上下文
4. 观察主 LLM 是否基于该 user 消息继续重跑（补充遗漏的子目标）
5. 主 LLM 再次调用 `attempt_completion`，观察是否再次触发监督审查

## 预期结果
- 打回时，监督 LLM 的理由+建议作为 user 消息进入主 LLM 上下文
- 主 LLM 基于该 user 消息继续重跑，补充遗漏的子目标
- 重跑后再次触发监督审查，形成"监督→打回→重做→再监督"闭环

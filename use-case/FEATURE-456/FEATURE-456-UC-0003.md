# FEATURE-456-UC-0003 监督 LLM 上下文累积与清空开关

## 前置条件
- 已编译最新可执行码（`go build -o work/co-shell .`）
- 监督 LLM 已启用

## 操作步骤
1. 查看配置中监督 LLM 上下文清空开关（`supervisor.clearContext`，放[安全与确认]）
2. 确认默认值为 false（累积）
3. 在同一个会话中，让主 LLM 完成两个子任务，分别触发两次监督审查
4. 观察第二次审查时，监督 LLM 是否能看到第一次审查的上下文（累积）
5. 将 `supervisor.clearContext` 设为 true
6. 在同一个会话中，再次触发两次监督审查
7. 观察第二次审查时，监督 LLM 上下文是否被清空（全新审查）

## 预期结果
- `supervisor.clearContext` 默认 false（累积）
- 累积模式：第二次审查时监督 LLM 能看到第一次审查的上下文（避免重复审查）
- 清空模式：每次审查都是全新上下文

# FIX-311-UC-0001: show-loop-detection 默认值修正验证

## 目标

验证 `show_loop_detection` 配置项默认值修正为 `false`，且字段注释与实际默认值一致。

## 背景

- 问题：config/config.go 中 `ShowLoopDetection` 字段注释写 `Default: false`，但 `DefaultConfig()` 实际设置为 `true`，注释与实现矛盾。
- 意图：FEATURE-241 设计意图为默认不显示完整判定详情（完整判定 prompt + 完整判定 response，避免刷屏），用户手动开启后才显示。
- 修复：只改 config/config.go 中 `DefaultConfig()` 的 `ShowLoopDetection` 为 `false`，不动其他代码。

## 前置条件

- 已在 FIX-311 分支
- 代码可编译

## 运行时用例

### UC-0001: 默认配置文件 show_loop_detection 为 false

**步骤**

1. 在无 config.json 的干净目录（如 work/）运行 co-shell
2. 进入 REPL 后执行 `:set` 查看显示设置分组
3. 观察 `show-loop-detection` 行状态

**预期**

- `show-loop-detection` 状态显示为 `off`
- `:set show-loop-detection`（无参数）同样显示 `off`

**验证点**

- DefaultConfig() 中 ShowLoopDetection == false
- 字段注释 `Default: false` 与实现一致

### UC-0002: 手动开启后完整判定详情可显示

**步骤**

1. 在 REPL 中执行 `:set show-loop-detection on`
2. 再次执行 `:set` 确认状态为 `on`

**预期**

- 状态切换为 `on`
- 配置可持久化到 config.json

**验证点**

- 开关功能未受影响，仅默认值改变

### UC-0003: 编译与单元测试通过

2. 执行 `go vet ./agent/...`
3. 执行相关单元测试

**预期**

- go vet 无警告
- 现有测试全部通过（本改动不影响行为逻辑，仅默认值）

**验证点**

- 无回归

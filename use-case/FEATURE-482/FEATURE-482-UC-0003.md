# FEATURE-482-UC-0003 红点高度表示上下文占用

## 前置条件
- Web UI 已启动，主模型最大上下文已知（如 1M tokens）
- 已产生多轮 LLM 迭代，累计上下文占用逐步上升

## 操作步骤
1. 观察可视化控件中每条色线中间的红点
2. 记录最早消息与最新消息红点的纵向位置
3. 让 LLM 持续输出，使累计上下文占用明显上升后再次观察

## 预期结果
- 每条色线中间有一个纯红色点
- 红点纵向位置表示该消息产生时的累计上下文占用比例：占用越高红点越靠上，占满（=主模型最大上下文）时红点位于色线顶端
- 同一轮迭代内产生的多个消息块（LLM/THINK/TOOL）红点高度相同（共享同一上下文占用值）
- 随上下文占用上升，后续消息的红点整体高于早期消息的红点

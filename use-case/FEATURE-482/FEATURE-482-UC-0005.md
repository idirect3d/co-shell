# FEATURE-482-UC-0005 无限追加与拖拽滑动

## 前置条件
- Web UI 已启动，会话标题栏已显示消息可视化控件

## 操作步骤
1. 持续让 LLM 产生大量消息，使色线数量超过控件可视宽度
2. 观察控件是否出现可横向滑动的状态
3. 在控件上按住鼠标左键并左右拖动
4. 刷新浏览器页面

## 预期结果
- 色线数量不设上限，持续追加（浏览器刷新前不清空、不覆盖最早色线）
- 当色线总宽度超过控件可视宽度时，可通过按住拖动左右平移查看历史/最新色线
- 拖动时色线整体随鼠标移动，松手后停留在拖动位置
- 刷新浏览器后，可视化控件清空（色线数据不持久化），随新消息重新累积

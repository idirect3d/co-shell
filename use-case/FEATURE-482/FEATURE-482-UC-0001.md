# FEATURE-482-UC-0001 会话标题栏布局改造（标题框固定 200px + 可视化控件占满剩余）

## 前置条件
- Web UI 已启动（`--serve`），进入会话主界面

## 操作步骤
1. 观察会话标题栏（stream-head）布局
2. 测量会话标题输入框（#streamTitle）宽度
3. 观察标题输入框与显示模式三段开关（#streamMode）之间的区域

## 预期结果
- 会话标题输入框宽度固定为 200px（不再随窗口伸缩）
- 标题输入框与三段开关之间出现消息可视化图表控件，占满两者之间的全部剩余宽度，两侧适当留白
- 可视化控件高度与显示模式三段开关外框高度相同
- 三段开关仍靠右显示，标题输入框仍可正常编辑会话标题

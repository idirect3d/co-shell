# FEATURE-482-UC-0002 消息色线渲染（颜色=标题栏指示灯色，1px 宽）

## 前置条件
- Web UI 已启动，会话标题栏已显示消息可视化控件

## 操作步骤
1. 向 LLM 发送一条消息，使其产生一轮包含 LLM 输出、THINK 思考、TOOL 工具调用的迭代
2. 观察可视化控件中新增的色线
3. 对比各色线颜色与对应消息块标题栏指示灯（.ev-head::before）颜色

## 预期结果
- 每产生一个消息块（.ev），可视化控件右侧追加一条 1px 宽的纵向色线
- 色线颜色与该消息块标题栏指示灯颜色一致（如 LLM=青色、TOOL=黄色、THINK=灰、YOU=青色、错误=红色等）
- 色线高度等于控件高度
- 新色线从右侧追加，已有色线整体向左移动 1px

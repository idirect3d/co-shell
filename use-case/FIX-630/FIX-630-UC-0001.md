## 设计基线（本次实现基准）

| 项 | 设计 |
|----|------|
| App entitlements | `app-sandbox`、`network.client`、`network.server`、`files.user-selected.read-write`（必要时 `files.bookmarks.app-scope`） |
| 内嵌 helper（hub/agent） | `app-sandbox` + `com.apple.security.inherit`（继承父进程沙箱/容器），由 App 发起启动 |
| 数据落位 | hub-gateway.json / hub-agents.json / board db / 日志 / 会话库全部落到 App 容器 `~/Library/Containers/com.coshell.app.mas/Data/…` |
| 工作区 | 用户经 `NSOpenPanel` 选择目录 → 生成 security-scoped bookmark → 传给 hub/agent 作为工作区；只在该范围内读写 |
| 能力边界 | 沙箱内不再具备「在任意目录执行任意命令」的能力（用户已确认接受） |
| 分发 | Bundle ID `com.coshell.app.mas`；签名 Apple Distribution + Mac App Store 描述文件；`method=app-store-connect` 上传 |
| 合规 | `PrivacyInfo.xcprivacy`、`ITSAppUsesNonExemptEncryption=false`、ATS 收窄、CFBundleName/版本纪律 |

## 术语

- **(R)** 离线静态校验　**(M)** 运行时手动/DOM 断言
- **spike v2**：结构正确的沙箱化验证（helper 带 `inherit`，由沙箱父进程发起）
- **容器**：`~/Library/Containers/<bundle-id>/Data/`

## 用例清单

### UC-01 (R) entitlements 最小集正确

- 断言：存在 App 与 helper 两份 entitlements；App 含 `app-sandbox`、`network.client`、`network.server`、`files.user-selected.read-write`；helper 含 `app-sandbox` + `com.apple.security.inherit`。
- 断言：未声明与功能无关的宽泛权限（如 `files.all` / `temporary-exception`）。

### UC-02 (R/M) 沙箱子进程不再因容器身份缺失而崩溃（spike v2）

- 断言：`codesign -d --entitlements -` 显示 helper 的 `inherit` 已生效；
- 断言：由签名后的 App 发起启动时，hub 进程能起来（不再 SIGTRAP），`~/Library/Logs/…/hub.log` 有正常启动日志。

### UC-03 (M) 数据全部落在容器内

- 断言：hub/agent 运行时产生的配置文件、注册表、board db、日志、会话库路径均在容器内；
- 断言：无容器外写入尝试（系统日志无相应 deny 记录）。

### UC-04 (M) 授权目录内可正常读写

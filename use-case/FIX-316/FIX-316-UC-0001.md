# FIX-316: 工具执行后必显输出（动作结果概要 + attempt/track 详情）

## 需求

工具执行后应向用户显示「必显」信息（受 `showTool` 控制，走统一 `StreamRenderer` `EventToolCall` 通道，带工具图标 `[🔧]` 引导）：
- `attempt_completion`：显示 `✅ 任务完成` + result 全量
- `track_task_progress`：显示完整任务计划详情
- `read_file`：`读取 xxx（第 n-m 行）`
- `write_to_file`：`写入 xxx（共 N 行）`
- `replace_in_file`：`修改 xxx（N 处替换）`
- `search_files`：`搜索 xxx（找到 N 处）`
- `execute_command`：成功/失败状态
- 其他工具：`{tool} 执行成功/失败`（兜底）

区别于 `showToolOutput`（详情）：本功能是精简的「动作收条」，不受详情开关影响（只受 showTool 总开关）。

## 现状

| 项 | 现状 |
|---|---|
| `read_file` 等结果 | 仅 `showToolOutput`（默认 false）显示 `Result:` 全文 → 用户看不到动作概要 |
| `attempt_completion` | result 进上下文；仅 showToolOutput 显示 → 用户看不到 `✅ 任务完成` |
| `track_task_progress` | 裸 `defaultIO().Println(formatted)` 绕过事件通道 |
| 成功/失败状态 | 无统一成功状态行 |

## 修复内容

### `agent/tool_summary.go`
新增 `buildToolOutcome(toolName string, args map[string]interface{}, resultText string) string`：
- `read_file` → `读取 {path}（第 {start}-{end} 行）`
- `write_to_file` → `写入 {path}（共 N 行）`（N 从 resultText 解析实际行数）
- `replace_in_file` → `修改 {path}（{N} 处替换）`
- `search_files` → `搜索 {path}（找到 N 处）`
- `execute_command` → 成功/失败状态
- 兜底 → `{tool} 执行成功/失败`

### `agent/run_stream.go`（Step 4 工具循环）
`executeToolCall` 成功后、`if a.showTool` 内：
- `attempt_completion` → `cb(EventToolCall, "✅ 任务完成\n\n"+result)`（a.completed 分支）
- `track_task_progress`/`view_task_plan` → `cb(EventToolCall, result)`（完整详情）
- 其他 → `cb(EventToolCall, buildToolOutcome(...))`

### `agent/taskplan_tools.go`
`trackTaskProgressTool`/`viewTaskPlanTool` 去掉裸 `defaultIO().Println`，改为返回 result 走统一通道（受 showTool 控制）。

### `i18n`
新增中英 key：`tool_outcome_read/write/replace/search/exec/ok/fail` 等。

## 用例（循环模式）

| # | 场景 | 步骤 | 预期结果 |
|---|---|---|---|
| 1 | read_file 概要 | `buildToolOutcome("read_file", {path,start_line,end_line}, result)` | `读取 {path}（第 {s}-{e} 行）` |
| 2 | write_to_file 概要(行数) | result 含实际行数 | `写入 {path}（共 N 行）` |
| 3 | replace_in_file 概要 | args.replacements=3 | `修改 {path}（3 处替换）` |
| 4 | search_files 概要 | result 含匹配数 | `搜索 {path}（找到 N 处）` |
| 5 | execute_command 成功/失败 | err nil / err non-nil | 成功/失败状态行 |
| 6 | 兜底概要 | 未知工具名 | `{tool} 执行成功/失败` |
| 7 | attempt_completion 全量 | `a.completed` 分支 | `✅ 任务完成\n\n{result}` 经 EventToolCall |
| 8 | track_task_progress 详情 | `trackTaskProgressTool` | 完整计划详情经 EventToolCall（受 showTool） |
| 9 | showTool=false 不显示 | showTool 关闭 | 无 EventToolCall 输出 |

# FEATURE-612 UC-0003：动态信息面板显示优化（左右对齐 / 卡片化 / 标题栏计数）

> 分支：**FEATURE-612**　版本：**v0.100.1**　BUILD：**1245**
> 需求（用户提出 4 项）：① 环境块属性名左对齐（去掉冒号）、值右对齐；② 公告板 agent 名称左对齐、online/offline 右对齐；③ 动态感知信息做成卡片（首行＝消息类型＋状态＋时间右对齐，次行＝消息内容，超长省略号截断）；④ 面板标题栏随视图显示计数——任务进展显示任务执行进展分数，动态信息显示动态感知信息数量（保持现状语义）。
> 判定口径：见下列各用例；实现限于前端展示层（`app.js` + `style.css`）。

## 变更点（实际）

| 位置 | 变更 |
|---|---|
| `web/static/app.js` `dynEnvLines` | 行数据从字符串改为对象：键值行 `{name, value}`、公告板行 `{name, badge}`、单值行 `{value}`（含占据位/工具路径） |
| `web/static/app.js` `dynBlockEl` | 按对象行渲染：名称 span（`.dyn-env-name`）+ 值 span（`.dyn-env-val`）/ 状态徽章（`.dyn-env-badge`）；无名称无徽章的单值行仍占满整行左对齐 |
| `web/static/app.js` `dynRow` | 时间线行拆为卡片：首行 `.dyn-row-head`（类型标签 + 状态标记 + 时间），次行 `.dyn-text`（消息内容，单行省略号） |
| `web/static/app.js` `applyPanels` / 新增 `updatePlanSwitchBadge` | 头部计数统一在此刷新：动态信息视图＝待确认+未确认（0 隐藏，>99 显示 99+）；任务进展视图＝(已完成+进行中)/总数，无计划时隐藏 |
| `web/static/style.css` | `.dyn-env-line` 改 flex 左右分布、新增 `.dyn-env-name`/`.dyn-env-val`、`.dyn-env-badge` 改 `margin-left:auto`；`.dyn-row` 改卡片、新增 `.dyn-row-head`、`.dyn-text` 单行省略号；新增 `.ps-badge.plan` 中性配色 |

## 用例与结果

`(M)` = 需人工在 Web UI 验收；本次已在独立实例中以样例数据实测几何/结构与截图核对。

### A. 环境块左右布局

- **UC-01（M）** 键值行改为「名称贴左、值贴右」，中间不再有冒号（如「进程号 … 91229」）。
- **UC-02（M）** 名称与值在同一条水平行上，值抵住块右边界。
- **UC-03（M）** 无名称的单值行（如可用工具路径、占位符）仍占满整行、左对齐，不被推到右侧。
- **UC-04（M）** 所有环境块（运行环境、上下文占用、用户在线状态等）行布局一致。

### B. 公告板

- **UC-05（M）** 每行 agent 名称左对齐。
- **UC-06（M）** online/offline 徽章贴行右端，颜色区分（online 绿 / offline 灰）。
- **UC-07（M）** 行内不出现 id、职责、rev 等多余信息。

### C. 时间线卡片化

- **UC-08（M）** 每条感知事件是一张卡片（边框 + 圆角），卡片之间有间距。
- **UC-09（M）** 卡片首行左侧为消息类型标签，状态标记（待确认/未确认）紧随其后，时间位于首行右端。
- **UC-10（M）** 卡片次行为消息内容，左对齐；超长时以省略号截断（不换行、不撑破面板）。
- **UC-11（M）** 待确认/未确认卡片保留醒目底色（橙色系），与普通卡片可区分。

### D. 标题栏计数

- **UC-12（M）** 切到「任务进展」时徽章显示分数 `(已完成+进行中)/总数`（如 `2/3`），使用中性配色。
- **UC-13（M）** 任务进展视图下无任务计划时徽章隐藏（不显示 `0/0`）。
- **UC-14（M）** 切到「动态信息」时徽章显示待确认+未确认数量，为 0 时隐藏，超过 99 显示 `99+`。

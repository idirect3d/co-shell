# FEATURE-612 UC-0004：已打开资源改为「分类标题 + 资源卡片」

> 分支：**FEATURE-612**　版本：**v0.100.1**　BUILD：**待定（编码后回填）**
> 需求（用户提出）：已打开资源中的各类信息，都需要在**对应分类标题下**，以**卡片方式**显示各个资源的信息，以便更直观地显示信息、带来更好的体验。
> 用户确认的决策：① 卡片显示**完整字段**（名称/状态/形态/是否活动/标题/内容摘要等）；② **空分类保留分类标题，内容显示「无」**；③ 增强四项全做——活动窗口高亮、点击窗口卡片切换到该窗口、分类图标（**复用现有 SVG symbol**）、长文本截断且悬停显示完整值；④ 任务并入 **FEATURE-612**，沿用当前分支，不新建。
> 判定口径：`<opened_resources>` 在动态信息面板中的渲染由「一个块 + 平铺文本行」改为**五类分类标题各自成组，组内每个资源一张卡片**；分类标题带图标；空分类显示「无」。改动限于前端展示层（`web/static/app.js` + `web/static/style.css`），后端数据格式不变。

## 现状与变更点（计划）

| 位置 | 现状 | 变更 |
|---|---|---|
| `app.js` `dynEnvLines("opened_resources")` | 通用分支：子元素解析为 `{name, value}` 行（`ui_windows` 的 5 字段行被整行当成值文本） | 新增 `opened_resources` 专用分支：按 `<browser>/<excel>/<word>/<shell>/<ui_windows>` 五类切分，输出「分类 + 资源卡片」结构 |
| `app.js` `dynBlockEl` | 逐行渲染 `.dyn-env-line` | 对结构化结果渲染 `.dyn-res-group`（标题+图标）/ `.dyn-res-card`（字段行） |
| `app.js` 新增 | — | `dynResGroups()`（解析五类）、`dynResCard()`（卡片元素）、窗口卡片点击 → `UIWin.activate(name)` |
| `style.css` | `.dyn-env-*` | 新增 `.dyn-res-group` / `.dyn-res-title` / `.dyn-res-card` / `.dyn-res-card.active` / `.dyn-res-k` / `.dyn-res-v` 等（颜色一律用 CSS 变量） |

## 用例与结果

`(R)` = 可自动复现（`node --check` + 抽取真实函数在 node 中执行断言）；`(M)` = 需人工在 Web UI 验收。

### A. 分类标题 + 卡片结构

- **UC-01（M）** 五类资源各有分类标题：**浏览器 / Excel / Word / 终端 / 界面窗口**（英文界面为 Browser / Excel / Word / Shell / UI windows），顺序与后端输出一致。
- **UC-02（M）** 每个分类标题左侧带分类图标（复用 sprite：`i-display`、`i-file`、`i-memory`、`i-devtools`、`i-expand`），图标随文字颜色。
- **UC-03（M）** 每个资源渲染为**一张独立卡片**（边框 + 圆角 + 卡片间距），不再是平铺的文本行。
- **UC-04（M）** 空分类（如 `<browser>none</browser>`）**保留分类标题**，其下显示「无」，不隐藏、不留空白。
- **UC-05（R）** 面板中不出现任何 XML 标签（`<opened_resources>`、`<window>`、`|` 分隔的原始行均被消化）。
- **UC-06（R）** 「已打开资源」之外的其它环境块（运行环境、公告板、可用工具等）渲染保持现状不变。

### B. 卡片字段（完整字段）

- **UC-07（M）** 界面窗口卡片首行为**窗口名**（主标识），并显示：形态（浮窗/面板）、是否当前活动、标题、内容摘要。
- **UC-08（M）** Excel / Word 分类下**每个 session 一张卡片**，显示其会话标识（路径或 id）。
- **UC-09（M）** 浏览器卡片显示运行状态（运行中 / 无）；终端卡片显示运行状态（运行中 / 无）。
- **UC-10（M）** 字段名随界面语言本地化（zh/en），且与后端值一一对应、不丢字段。
- **UC-11（R）** `<window>名 | float | active | 标题 | 摘要</window>` 解析为 5 个字段，**摘要中若含 ` | ` 不串位**（按前 4 个分隔符切分，其余全部归摘要）。

### C. 交互增强（用户确认全做）

- **UC-12（M）** 当前活动窗口的卡片有高亮（统一方案：`--accent-dim` 底 + `--accent` 边框 + `--accent` 文字），非活动卡片为普通样式。
- **UC-13（M）** 在**界面窗口卡片上点击**，该窗口被切换为当前活动窗口（复用 `UIWin.activate(name)`），随后卡片高亮与 `<ui_windows>` 的 `active` 标记同步更新。
- **UC-14（M）** 非界面窗口卡片（浏览器/Excel/Word/终端）不可点击、无手型光标、点击无副作用。
- **UC-15（M）** 长文本（内容摘要、标题、路径）单行省略号截断，**悬停显示完整值**（`title` 属性），不撑破面板。
- **UC-16（M）** 深浅主题下配色全部走 CSS 变量，无硬编码颜色（规范要求）。

### D. 边界与健壮

- **UC-17（M）** 五类全空时，五个分类标题 + 各自「无」正常显示，面板不塌陷。
- **UC-18（M）** 多窗口（≥3）时卡片按后端顺序排列，仅活动窗口高亮；点击任一卡片高亮正确转移。
- **UC-19（R）** 出现未知分类（未来新增的顶层子元素）时**降级为通用行渲染**，不崩溃、不裸显 XML。
- **UC-20（M）** 窄屏（面板宽度 ~260px）下卡片不横向溢出，字段值换行/截断正确。
- **UC-21（M）** 切换会话、重连（刷新页面）后展示与后端快照一致，不残留上一会话的卡片。

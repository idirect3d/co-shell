# FIX-558 验收测试用例（UC-0001）：hub Agent 管理界面调整（创建去描述录入 + 注册描述只读展示）

> 需求（用户提出）：
> 1. **创建 agent 时去掉「Agent描述」项**；agent 的 **ID 写入新建 agent 的 `{workspace}/IDENTITY.md`**。
> 2. **编辑 agent 时仅显示该 agent 最后一次注册时上报的「Agent描述」**，显示在**所有项目的最后**，**仅显示内容**（不使用任何输入控件）。
>
> 交互决策（经 ask_user 确认）：
> - ① 版本归属 **v0.76.1**、任务编号 **FIX-558**（按修复处理，patch+1）；
> - ② ID 写入方式 = 写入 IDENTITY.md 现有 **`## agent-name` 段**（ID 作为名字）；
> - ③ 编辑只读描述口径 = **仅取该 agent 在 hub 公告板最后一次注册上报的描述**，从未注册过显示「未上报」；
> - ④ 描述写回通道一并删除：移除 `PUT /api/agents/{id}/identity` 端点，描述只由 agent 自身在「身份与个性」中修改。
>
> 改动范围（预期实现）：
> `hub/gateway/webui_static.go`（创建表单去掉描述项；编辑表单描述项移到末尾并改为只读展示）、
> `hub/gateway/webui.go`（创建后写 `## agent-name` = ID；`identityFor` 改取 roster 上报值；删除 PUT identity 路由与 handler）、
> `hub/gateway/identity.go`（新增写 `## agent-name` 段的接口）。

## A 组：单元测试（Go，`hub/gateway`）

- **A-001**：断言 `webui_static.go` 中不存在 `id="m-name"`，且创建视图（`viewConfig` 本地字段区）不含「Agent描述」输入项。
- **A-002**：断言 `webui_static.go` 创建提交的 `api('POST', '/api/agents', {...})` 请求体中不含 `agent_description`。
- **A-003**：调用 `handleCreateAgent`（temp workspace）→ 读取 `{ws}/IDENTITY.md`，断言含 `## agent-name` 段且值为请求 ID。
- **A-004**：预置 `## user-name\n匿名` + 自由文本的 IDENTITY.md → 创建同名 agent → 断言 `agent-name` = ID，且 `user-name` 与自由文本原样保留。
- **A-005**：断言编辑视图 HTML 中「Agent描述」项出现在 `d-extra`/`d-state` 之后，且描述容器不是 `<input>`/`<textarea>`（为只读展示元素）。
- **A-006**：断言 `webui_static.go` 中不存在 `PUT` + `/identity` 的调用（仅保留读接口或均不调用）。
- **A-007**：对 `PUT /api/agents/{id}/identity` 发请求 → 断言返回 404/405（路由已移除）；`GET` 端点按实现保留/移除时同步断言。
- **A-008**：board 无该 agent 条目 → `identityFor` 描述为空、`readonly=true`。
- **A-009**：`board.Register(id, name, "描述A")` → `identityFor` 返回「描述A」、`readonly=true`。
- **A-010**：`board.SetDutyResolver` 提供回退值并用空 duty 注册（`duty_source=hub`）→ `identityFor` 返回空（视为未上报）。
- **A-011**：external agent + 注册上报描述 → 返回上报值、`readonly=true`。
- **A-012**：断言 `createAgentRequest` 结构体不再声明 `AgentDescription` 字段。

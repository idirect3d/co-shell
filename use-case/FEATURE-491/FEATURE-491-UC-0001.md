# FEATURE-491-UC-0001 工具结果上下文长度限制 - 配置项默认值

## 前置条件
- 使用默认配置（config.DefaultConfig()）

## 操作步骤
1. 检查 LLMConfig 中新增的 `tool_result_max_size` 字段
2. 检查默认值

## 预期结果
- `tool_result_max_size` 字段存在，JSON tag 为 `tool_result_max_size`
- 默认值为 65536（64KB）
- 值为 0 表示不限制（不截断、不保存文件）

# FEATURE-491-UC-0003 工具结果上下文长度限制 - 截断函数（超限）

## 前置条件
- 构造一个 Agent，`tool_result_max_size` 设为 1024
- 工具结果内容长度 > 1024（例如 5000 字节，含多行）

## 操作步骤
1. 调用通用截断函数处理工具结果

## 预期结果
- 返回内容只包含头部（约 1024 字节以内）
- 追加了截断说明，说明中包含：
  - 完整内容保存的文件路径（tmp/tool-result/ 下）
  - 完整内容总大小（字节数）
  - 完整内容总行数
  - 截断的字节数
- 完整内容已保存为文本文件，文件内容与原始内容一致

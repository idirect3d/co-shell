# FEATURE-467-UC-0003 模板原始 JSON 内容展示（可收起/展开）

## 前置条件
- 启动 Web UI（`--serve`）
- 打开模型管理界面，点击「＋ 新增模型」进入向导

## 操作步骤
1. 进入向导第一步「选择模板」
2. 观察模板下拉框下方是否有「查看模板原始 JSON」的收起/展开控件
3. 默认状态下，模板 JSON 内容是否隐藏
4. 点击展开控件，观察是否显示当前选中模板的完整原始 JSON（含 provider、endpoint、capabilities、default_params 等）
5. 切换模板，观察 JSON 内容是否随模板变化实时刷新
6. 再次点击收起控件，观察 JSON 内容是否隐藏

## 预期结果
- 第一步显示「查看模板原始 JSON」的收起/展开控件
- 默认收起（隐藏 JSON 内容）
- 展开后显示当前选中模板的完整原始 JSON，内容与后端模板定义一致
- 切换模板时 JSON 内容实时刷新
- 可再次收起

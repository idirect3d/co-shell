# FIX-545 测试用例（UC-0001 ~ UC-0012）

> 主题：修复 token 输出性能统计——纯工具调用轮次速率缺失（`↓xxxx (-, -)`）+ 消息行 token 统计与状态栏对齐
> 版本：v0.68.7　分支：FIX-545
> 验收口径：状态栏与消息行均显示 `↑N（tps, 用时）↓N（tps, 用时）`，**数据项一致、不重复、不缺值**

---

## 一、根因回顾（用例设计依据）

| 现象 | 根因位置 | 说明 |
|---|---|---|
| 状态栏 `↓1,266 (-, -)` | `agent/stream_response.go:259` | 首字时刻只在收到 `StreamEventContent`/`StreamEventReasoning` 时记录。纯 tool_calls 轮次（content 空、无思考）永不触发 → `firstLat=0`、`genDuration=0` → `ft`/`in_tps`/`out_tps` 全为 `"-"` |
| 状态栏用时也是 `-` | `web/static/app.js:2689` | 用时由 `tokens / tps` 反推，tps 为 `-` 时用时连带失效 |
| 消息行有重复用时 | `web/static/app.js:1676-1677` | `in_tps = prompt / ft`，故 `p / inTPS ≡ ft`，输入侧打印了两份相同耗时 |
| 消息行输出侧无用时 | `web/static/app.js:1681` | 只打印 `outTPS + "t/s"`，没有用时项 |

## 二、修复后约定

- 后端 `LLMTiming` 新增 `OutputDuration`，经 `token_iter` 事件 meta 键 `out_dur` 下发（= 流结束时刻 − 首字时刻）。
- 输入侧用时沿用既有 `ft` 键（= 首字时刻 − 调用发起时刻，即 prefill 有效用时）。
- 两个用时均取自**流时间戳**，天然不含工具执行耗时（工具在流结束后才执行）。
- 前端不再用 `tokens / tps` 反推用时，一律直读 `ft` / `out_dur`。
- `TokenIterEvent` 保持 7 参数签名不变（4 处既有测试调用点不受影响），`out_dur` 由 `emitTokenIter` 附加。

## 三、用例清单

### UC-0001 纯 tool_calls 轮次能测出首字时刻（核心回归）
- **前置**：LLM 本轮返回 OpenAI JSON tool_calls，`content` 为空、无 reasoning（连续多工具场景）。
- **步骤**：`go test ./agent/ -run TestGetLLMTiming -v`
- **预期**：`GetLLMTiming()` 的 `FirstTokenLatency`、`InputTPS`、`OutputTPS`、`OutputDuration` **均非 `"-"` 且非空**。
- **失败判据**：任一字段为 `"-"` 即视为未修复。

### UC-0002 文本轮次不回归
- **预期**：仅 content 事件时四项齐备；`OutputDuration` ≈ 流结束 − 首字。

### UC-0003 思考（reasoning）轮次不回归
- **预期**：仅 reasoning 事件时首字时刻被记录，四项齐备。

### UC-0004 无新增 token 时不产生虚假速率
- **预期**：`totalDelta == 0` 时返回空 `LLMTiming{}`（四字段皆空串），不出现 `0`、`Inf`、`NaN`。

### UC-0005 读取后计时状态复位（防跨轮污染）
- **预期**：第二次调用 `GetLLMTiming()` 返回空值；三个时间戳归零。

### UC-0006 `out_dur` 随 token_iter 事件下发
- **预期**：事件 `Meta["out_dur"]` 等于传入的 `timing.OutputDuration`；`ft`/`in_tps`/`out_tps` 同步存在。

### UC-0007 事件构造器签名兼容既有测试
- **步骤**：`go build ./... && go vet ./...`
- **预期**：`TokenIterEvent` 保持 7 参数签名，`agent/stream_renderer_test.go`、`agent/line_renderer_test.go`、`repl/render_test.go`、`render_test.go` 四处调用点无需改动即可编译。

### UC-0008 REPL/单命令渲染不回归
- **步骤**：`go test ./agent/ ./repl/ . -run 'Token|Render'`
- **预期**：`KeyTokenUsageDisplay` 渲染仍为 `首字=%s | 输入=%d(%s t/s) | 输出=%d(%s t/s) | 总计=%d (%.1f%%)`，无 `%!s(...)` 类格式化错乱。

### UC-0009 消息行格式与状态栏同构（Web 运行时）
- **前置**：`--serve` 启动 Web UI，发起一轮含工具调用的任务。
- **预期**：形如 `12. 2026-09-20 02:30:58  ↑12,345（8,123t/s, 1.5s）  ↓678（45t/s, 15.1s）`；
  ① 输入侧**只有一个**用时项（不再重复）；② 输出侧**有**用时项；③ 数据项集合与状态栏一致。

### UC-0010 状态栏不再出现 `(-, -)`（Web 运行时）
- **预期**：`↑N（tps, 用时）↓N（tps, 用时）` 四项齐备；仅在真正无数据时显示 `-`。

### UC-0011 用时直读后端值（Web 运行时）
- **预期**：状态栏用时与消息行用时数值一致（同源 `ft` / `out_dur`），不再因 `tokens/tps` 反推产生舍入偏差。

### UC-0012 全量回归
- **步骤**：`go build ./... && go vet ./... && go test ./... -short`
- **预期**：全部通过，无新增失败。

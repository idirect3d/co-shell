# FIX-519 测试用例：工作区文件列表文件行误显示展开/收起三角箭头

## 背景

Web UI 工作区文件树中，文件（非目录）行左侧也渲染了「展开/收起」三角箭头（▸），该箭头只应出现在目录行。

根因：`web/static/app.js` 的 `treeNode()` 为每个节点（含文件）无条件执行 `setIcon(tw, "i-tri")`。目录分支随后会按 open 状态重新设置图标，因此该初始赋值对目录冗余、对文件则是错误箭头来源。

修复：删除 `treeNode()` 中初始的 `setIcon(tw, "i-tri")`。`.tw` span 仍为每行创建（CSS `width:12px` 占位不变，左右对齐不受影响），文件行为空 → 无箭头；目录行由 dir 分支正常设置 `i-tri` / `i-tri-down`。

## 验收前置

- 分支：`FIX-519`；版本 `0.56.2`；BUILD `1019`
- 启动方式：`go run . --serve --port <port>`（不带 `--serve` 会自动开系统浏览器并占用 WebSocket 单客户端连接）

## UC-0001 静态校验：文件节点不再设置三角图标（运行时）

**类型**：运行时（静态源码 + node 语法）
**步骤**：
1. `node --check web/static/app.js`
2. 在 `treeNode()` 函数体内检索 `setIcon(tw` 的全部出现位置

**预期**：
- `node --check` 通过（无语法错误）
- `treeNode()` 中 `setIcon(tw` 仅出现在 `if (node.dir)` 分支内（初始展开态设置 + 点击切换），函数顶部创建 `tw` 处不再有 `setIcon(tw, "i-tri")`

## UC-0002 运行时：文件行 `.tw` 为空、目录行 `.tw` 有箭头（DOM 实测）

**类型**：运行时（浏览器 DOM）
**步骤**：
1. 启动 `--serve`，打开工作区文件树
2. 展开根目录，使同一层同时出现目录与文件
3. 在控制台执行：
   ```js
   const rows = [...document.querySelectorAll('.tree-row')];
   const file = rows.find(r => !r.classList.contains('dir'));
   const dir  = rows.find(r =>  r.classList.contains('dir'));
   ({
     fileTwHTML: file.querySelector('.tw').innerHTML,
     fileTwChildren: file.querySelector('.tw').childElementCount,
     dirTwHasIcon: !!dir.querySelector('.tw svg, .tw .ico'),
   })
   ```

**预期**：
- `fileTwChildren === 0` 且 `fileTwHTML === ""`（文件行无箭头）
- `dirTwHasIcon === true`（目录行有三角箭头）

## UC-0003 运行时：文件与目录名称左对齐未偏移（DOM 实测）

**类型**：运行时（浏览器 DOM 几何）
**步骤**：
1. 在同一层同时存在目录与文件时，在控制台执行：
   ```js

   const file = rows.find(r => !r.classList.contains('dir'));
   const dir  = rows.find(r =>  r.classList.contains('dir'));
   ({
     fileTwW: getComputedStyle(file.querySelector('.tw')).width,
     dirTwW:  getComputedStyle(dir.querySelector('.tw')).width,

   })
   ```

**预期**：
- `fileTwW === dirTwW`（均为 `12px`）
- `fileLeft === dirLeft`（同层文件与目录名称左边缘一致，无偏移）

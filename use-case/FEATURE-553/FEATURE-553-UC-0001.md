# FEATURE-553 验收测试用例：工作区文件树隐藏文件夹可配置

> 需求：Web UI 工作区文件树中「隐藏不显示」的文件夹改为可在系统设置中配置。
> 设置面板新增「工作区」标签：显示当前工作空间绝对路径（只读）+ 隐藏文件夹列表（可增/可删）。
> 默认隐藏名单：`db`、`.git`。删除 `web/server.go` 中原有的硬编码名单 `treeExcludedNames`。
>
> 匹配规则（用户确认）：
> - 不含 `/` 的条目 → 按**文件夹名**精确匹配，任意层级生效（如 `db` 隐藏任意位置的 `db/`）；
> - 含 `/` 的条目 → 按**从工作区根起的完整相对路径**精确匹配（如 `docs/private` 只隐藏该目录）；
> - **只对文件夹生效**，同名文件不受影响。
>
> 生效范围：仅 Web UI 工作区树（`GET /api/tree`）；`list_files` 工具与 environment_details 列表不受影响。
> 存储：当前工作区 `config.json` 的 `tree_excludes` 字段。

### UC-0001 默认隐藏名单为 db 与 .git

- 前置：工作区 `config.json` 中不存在 `tree_excludes` 字段（或为 `null`）。
- 步骤：启动 `co-shell --serve`，打开 Web UI 工作区文件树。
- 预期：
  1. 工作区根目录下**看不到** `db/` 与 `.git/`；
  2. `log/`、`tmp/`、`node_modules/`（若存在）**可见**；
  3. 系统设置 →「工作区」中列表显示 `db`、`.git` 两项。

### UC-0002 按文件夹名匹配、任意层级生效

- 前置：工作区存在 `node_modules/`（根）与 `web/node_modules/`（子层）。
- 步骤：设置 →「工作区」→ 添加 `node_modules`。
- 预期：
  1. 根与子层的 `node_modules/` 均从树中消失；
  2. 保存后无需重新加载配置即生效。

### UC-0003 按完整相对路径精确匹配

- 前置：工作区存在 `docs/private/` 与 `other/private/`。
- 步骤：添加 `docs/private`。
- 预期：
  1. `docs/private/` 被隐藏；
  2. `other/private/` 仍然可见（路径不匹配）；
  3. 列表项按用户输入原样展示。

### UC-0004 同名文件不被隐藏

- 前置：工作区根目录存在文件 `db`（无扩展名）与目录 `db/`。
- 步骤：默认配置（隐藏 `db`），查看工作区树。
- 预期：目录 `db/` 隐藏，文件 `db` 仍然可见。

### UC-0005 移除条目后目录恢复显示

- 步骤：设置 →「工作区」→ 点击 `db` 行的删除按钮。
- 预期：
  1. 列表不再包含 `db`；
  2. 工作区树中 `db/` 立即重新出现；
  3. `config.json` 的 `tree_excludes` 中不再含 `db`。

### UC-0006 清空列表后全部显示且持久化

- 步骤：逐项删除所有条目（列表为空）。
- 预期：
  1. 工作区树显示全部目录（含 `db/`、`.git/`）；
  2. `config.json` 中写入空数组 `"tree_excludes": []`；
  3. 重启 co-shell 后仍然全部显示（空列表**不会**被默认值覆盖）。

### UC-0007 设置面板以纯文本句子显示工作区绝对路径

- 步骤：打开系统设置，切换到「工作区」标签。
- 预期：
  1. 「工作区」标签位于「开发者」分组**之上**，左侧图标为**文件夹**；
  2. 面板顶部以**纯文本句子**显示「当前工作空间为 <绝对路径>」（如 `/Users/xxx/project`），**不**渲染为输入框/只读框；
  3. 该句之后直接接隐藏文件夹列表及其说明文案；
  4. 切换工作区启动后，路径随工作区变化。

### UC-0008 非法输入被拒绝

- 步骤：在添加输入框中分别输入 ``（空）、`/abs/path`、`../escape`、`a/../b`、已存在的条目。
- 预期：
  1. 空值、以 `/` 开头、含 `..` 的路径被拒绝并给出提示；
  2. 重复条目被忽略或提示已存在；
  3. 被拒绝时列表与配置文件均不变化。

### UC-0009 保存后文件树即时刷新

- 步骤：添加 `research` → 观察工作区树。
- 预期：无需刷新页面、无需重启服务，工作区树自动刷新并隐藏 `research/`。
- 备注：符合「状态变化后前端必须刷新」的项目约定（工具/设置改动后刷新树）。

### UC-0010 旧配置（缺字段）升级兼容

- 前置：使用 v0.72.2 生成的 `config.json`（无 `tree_excludes`）。
- 步骤：升级到本版本后启动 `--serve`。
- 预期：
  1. 树按默认名单隐藏 `db/`、`.git/`；
  2. `log/`、`tmp/`、`node_modules/` 变为可见（相对旧版本的行为变化，符合本次需求）；
  3. 首次保存后 `config.json` 中出现 `tree_excludes` 字段。

### UC-0011 非工作区树通道不受影响

- 步骤：让 Agent 执行 `list_files`（path 为工作区根），并查看 `<environment_details>` 的 `current_dir`。
- 预期：`db/` 仍出现在 `list_files` 输出与 `current_dir` 列表中（本次改动只作用于 Web UI 工作区树）。

### UC-0012 配置持久化到工作区 config.json

- 步骤：添加 `docs/private`，查看工作区 `config.json`，重启服务。
- 预期：
  1. `config.json` 含 `"tree_excludes": ["db", ".git", "docs/private"]`；
  2. 重启后设置与树过滤行为保持一致。

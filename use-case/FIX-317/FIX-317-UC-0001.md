# FIX-317: OpenAI 模式 replace_in_file 失败死循环

## 现象
LLM 反复重发相同 replace_in_file，错误被静默丢弃不修正。4 类：path 不存在 / SEARCH 不匹配 / SEARCH 重试 / JSON 语法。

## 根因
FIX-314 retry 对所有错误「静默丢弃重发」。但 path/SEARCH 错误 LLM 必须看到才能修正；仅 JSON 解析错误可静默自纠。formatToolError 已实现结构化反馈却被绕过。

## 修复（agent/run_stream.go Step4）
retry+!isXMLMode 按错误分流：`cannot parse tool arguments`→保留静默重发；其他→append formatToolError user 消息回灌 LLM 修正。

## 用例
1. JSON 解析错→静默重发（保留 FIX-314）
2. path 不存在→回灌 formatToolError，LLM 修正
3. SEARCH 不匹配→回灌，LLM 修正
4. 缺参→formatToolError missing 分支
5. exit 策略不变
6. XML 模式行为不变

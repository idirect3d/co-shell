# FIX-543 验收用例：IDENTITY.md 纳入版本控制

> 版本 v0.68.5 ｜ 分支 FIX-543 ｜ 类型：仓库治理（无代码逻辑改动）
> 用户确认：直接提交 IDENTITY.md 本体；归入 v0.68.5；不动 agent/tmp/。

## 背景

仓库根 `IDENTITY.md`（FEATURE-531 的 agent 个性化文件：`agent-name` / `agent-description`）长期未被 git 跟踪。`.gitignore` 并未排除它，只是从未 `git add`。本次纳入版本控制，使身份定义随代码可追溯。

已知代价（用户已接受）：该文件运行时可被改写——Web「身份与个性」保存、`--agent-name`/`--description`、hub 写 Agent描述、`--init` 导出都会修改它，身份一旦变更即产生工作区脏改动。

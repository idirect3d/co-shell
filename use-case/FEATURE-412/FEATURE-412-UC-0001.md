# FEATURE-412 Web UI TOOL 块输入参数子块增加"原始内容"小胶囊开关

## 背景

TOOL 块输入参数子块（FEATURE-400）当前始终进行 md 内容解析和渲染（FEATURE-409），但部分参数内容（如 JSON、XML 等结构化数据）经 md 渲染后可能丢失原始格式。希望在输入参数子块标题栏、收起展开图标的左边，增加一个名为"原始内容"的小胶囊开关，控制是否进行 md 内容解析和渲染，默认关闭（即默认显示原始内容，不做 md 渲染）。

## 验收标准

1. 输入参数子块标题栏、收起展开图标的左边，有一个名为"原始内容"的小胶囊开关。
2. 开关默认关闭：参数子块以原始文本（textContent）显示，不做 md 解析渲染。
3. 开关打开时：参数子块以 md 渲染（mdRender）显示。
4. 开关关闭时：参数子块恢复为原始文本显示。
5. 开关状态切换不影响参数原始内容（`params.raw`）的累积。
6. 编译通过：`go build ./... && go vet ./... && go build -o work/co-shell .`

## 测试用例

### UC-001 小胶囊开关存在且默认关闭
- 前置：Web UI 已加载，触发 TOOL 调用（有流式参数）
- 步骤：观察输入参数子块标题栏
- 期望：收起展开图标左边有一个"原始内容"小胶囊开关，且默认处于关闭状态（未高亮）

### UC-002 默认显示原始内容（不做 md 渲染）
- 前置：Web UI 已加载，触发 TOOL 调用，参数含 md 语法（如 `**加粗**`、`- 列表项`、代码块）
- 步骤：观察参数子块内容
- 期望：参数内容以原始文本显示，md 语法不被解析（如 `**加粗**` 原样显示，不渲染为加粗）

### UC-003 打开开关后 md 渲染
- 前置：Web UI 已加载，触发 TOOL 调用，参数含 md 语法
- 步骤：点击"原始内容"小胶囊开关（打开）
- 期望：参数子块内容切换为 md 渲染（如 `**加粗**` 渲染为加粗、列表渲染为列表）

### UC-004 关闭开关恢复原始内容
- 前置：Web UI 已加载，触发 TOOL 调用，开关已打开
- 步骤：再次点击"原始内容"小胶囊开关（关闭）
- 期望：参数子块内容恢复为原始文本显示

### UC-005 开关切换不影响参数累积
- 前置：Web UI 已加载，触发 TOOL 调用（流式参数仍在累积）
- 步骤：在流式参数累积过程中反复切换开关
- 期望：参数原始内容（`params.raw`）完整累积，切换开关后显示内容正确

### UC-006 编译验证
- 前置：无
- 步骤：运行 `go build ./... && go vet ./... && go build -o work/co-shell .`
- 期望：全部通过，无编译错误、无 vet 告警

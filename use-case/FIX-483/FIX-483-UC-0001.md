# FIX-483-UC-0001: msgviz 红点背景色改为控件底色

## 前置条件
- Web UI 已启动（serve 模式），浏览器已打开会话
- 会话中已产生至少一条消息（msgviz 图表有线段和红点）

## 操作步骤
1. 打开浏览器开发者工具（F12）
2. 检查 `.msgviz-dot` 元素的计算样式
3. 查看其 `background` 属性值

## 预期结果
- `.msgviz-dot` 的 `background` 为 `var(--bg-panel)` 解析后的颜色值（深色主题下为 `rgb(16, 20, 29)`）
- 不再是纯红色 `#ff0000`
- 红点位置看起来像线段在该处"断开"（被控件底色挖空）

## 验收标准
- [ ] `.msgviz-dot` 背景色等于控件（stream-head）背景色 `--bg-panel`
- [ ] 视觉上红点处线段呈断开效果

# FIX-581 UC-0013：设置入口、静态检查与回归保护

> 分支：**FIX-581**　版本：**v0.89.1**　对应方案：**参数入口接入（`.set` / 设置页 / LLM set 工具）+ 回归保护**
> 依据：ROADMAP v0.89.1 需求 ①（通过系统参数设置）＋ 验收标准 ⑤（单测与 `go build ./... && go vet ./...` 通过）⑥（提交分支、用户确认后合并）
> 判定口径：三个设置入口都能看到并设置新参数；静态检查与既有测试零回归；不带 `command` 的交付行为保持不变。

## 目的

确保新参数在用户可见的三个入口（REPL `.set`、Web 设置页、LLM 可调用的 set 工具）都能读能写，并确认本次改动没有引入回归。

## 前置条件

- 分支 `FIX-581`，设置入口改动落地：`cmd/config.go`、`cmd/settings.go`、`cmd/settings_web.go`、`agent/settings_tools.go`。
- 运行：`go build ./... && go vet ./...`、`go test ./... -short`。

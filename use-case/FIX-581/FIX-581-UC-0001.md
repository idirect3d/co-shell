# FIX-581 UC-0001：参数默认值与配置读写（demo-cmd-timeout）

> 分支：**FIX-581**　版本：**v0.89.1**　对应方案：**新增系统参数 `demo_command_timeout`（默认 3s，0 = 不限制）**
> 依据：ROADMAP v0.89.1「FIX-581 attempt_completion demo 命令执行超时上限」需求 ①（可通过系统参数设置，默认 3s）③（支持 0 = 不限制）
> 判定口径：默认 3s；可在 `.set` / 设置页 / LLM set 工具设置与回读；`0` 表示不限制；非法值被拒绝且不改动现值。

## 目的

确认新参数「demo 命令执行返回超时上限」有稳定的默认值 3s、能被读写与持久化、且 `0` 的语义（不限制）与既有 `cmd-timeout` / `tool-timeout` 一致。

## 前置条件

- 分支 `FIX-581`，本次改动落地：`config/config.go` 新增 `LLMConfig.DemoCommandTimeout int`（`json:"demo_command_timeout"`，默认 3）。
- 运行单测：`go test ./config/ -run FIX581 -v`。

## 用例 UC-0001：未设置时默认 3s

```go
// config 包单测（名称以实际实现为准）
cfg := config.Default()                    // 或 config.DefaultConfig()
if got := cfg.LLM.DemoCommandTimeout; got != 3 {
    t.Fatalf("DemoCommandTimeout default = %d, want 3", got)
}
```

**期望**：默认结构体取值为 `3`（秒）。

## 用例 UC-0002：旧配置文件缺少该字段时回落到默认 3s

```bash
# 造一个不含 demo_command_timeout 的旧配置
python3 - <<'EOF'
import json,pathlib
p = pathlib.Path("work/tmp/fix581-old.json")
p.parent.mkdir(parents=True, exist_ok=True)
p.write_text(json.dumps({"llm": {"command_timeout": 0}}, ensure_ascii=False))
EOF
go test ./config/ -run FIX581 -v   # 断言：加载后 DemoCommandTimeout == 3（而不是 0）
```

**期望**：加载旧配置后取值为 `3`，**不得**因为字段缺失而变成 `0`（那会等于“不限制”，失去保护）。

## 用例 UC-0003：设置、持久化与重启回读

```bash
cd /Users/direct3d/github/co-shell
# 交互式设置（或用 config handle 的单测等价调用）
./work/co-shell-0.89.1.darwin.arm64        # 在 REPL 中执行： .set demo-cmd-timeout 5
grep -n "demo_command_timeout" config.json # 期望出现 "demo_command_timeout": 5
./work/co-shell-0.89.1.darwin.arm64        # 重启后执行： .set demo-cmd-timeout  → 期望显示 5s
```

**期望**：`.set` 回显更新成功；`config.json` 写入 `"demo_command_timeout": 5`；重启后仍为 5s。

## 用例 UC-0004：非法值与 `0`（不限制）的语义

```bash
# 在 REPL 中依次执行，观察回显
.set demo-cmd-timeout abc     # 期望：报“无效值”类错误，当前值不变
.set demo-cmd-timeout -1      # 期望：报错（必须 >= 0），当前值不变
.set demo-cmd-timeout 0       # 期望：设置为 0，回显“不限制 / unlimited”
.set demo-cmd-timeout         # 期望：展示当前值（0 → “不限制”）
```

**期望**：非法输入不修改配置；`0` 被接受并显示为「不限制」；Agent 侧取值为 `0` 时不做超时限制（见 UC-0010）。

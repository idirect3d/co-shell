## 二、容器 / 布局控件

### 2.1 事件块 `.ev`

**用途**：消息流（stream）中的事件块，承载 LLM 输出、TOOL 调用、命令、系统消息等。

**HTML 结构**：
```html
<div class="ev tool">
  <div class="ev-head">
    <span class="ev-head-label">TOOL</span>
    <span class="ev-streaming">...</span>
    <span class="ev-actions">
      <button class="ev-act">⧉</button>
      <button class="ev-act">▾</button>
      <button class="ev-act">↻</button>
    </span>
  </div>
  <div class="ev-body">内容</div>
</div>
```

**CSS 类名**：`.ev`（容器，类型类 `.llm`/`.tool`/`.command`/`.system`/`.repl`/`.user-msg`/`.thinking`，状态类 `.collapsed`/`.level-*`）、`.ev-head`（标题栏）、`.ev-head-label`（标题文字）、`.ev-streaming`（动态省略号）、`.ev-actions`（操作组）、`.ev-act`（操作图标）、`.ev-body`（内容区）。

**JS 用法**：用 `makeBlock(cls, label, msgIndex)` 创建；`addBlockActions` 添加复制/收起/重试图标；`scheduleMd` 做 md 渲染。

**样式要点**：`.ev` 为 `border: 1px solid var(--border)`、`border-radius: 8px`、`background: var(--bg-panel)`；`.ev-head` 为 flex 标题栏（`--bg-elev` 背景、`text-transform: uppercase`）；`.ev-head::before` 是类型指示圆点（颜色随类型变化）；`.ev-body` 等宽字体、`white-space: pre-wrap`；`.collapsed` 隐藏 body。

**注意事项**：
- 类型圆点颜色：LLM=accent、TOOL=warn、command=ok、system=fg-faint、repl=debug。
- 内容区加 `.md` 类后切换为 markdown 渲染（`white-space: normal`）。
- 正在输出的块不收起（`markStreaming` 移除 `.collapsed`）。

### 2.2 输入参数子块 `.tool-params`

**用途**：TOOL 块内的输入参数子块，有标题栏、Raw 开关、展开/收起切换、可滚动内容区。

**HTML 结构**：

```html
    </span>

```

**CSS 类名**：`.tool-params`（容器，状态类 `.expanded`）、`.tool-params-head`（标题栏）、`.tool-params-title`（标题）、`.tool-params-right`（右侧操作组）、`.tool-params-raw`（Raw 开关）、`.tool-params-toggle`（展开/收起）、`.tool-params-body`（内容区）。

**JS 用法**：`ensureToolParams(curTool)` 创建；`renderParams(params)` 按 Raw 开关状态渲染（rawMode 时 textContent，否则 mdRender）。

**样式要点**：`.tool-params` 上下边框 + `--bg-elev` 背景；`.tool-params-head` 为 flex 标题栏（`justify-content: space-between`）；`.tool-params-body` 固定 `max-height: 200px` 可滚动，`.expanded` 时 `max-height: none`。

**注意事项**：Raw 开关（`.tool-params-raw`）控制 md 渲染，默认关闭显示原始内容；展开/收起切换按钮（`.tool-params-toggle`）在 Raw 开关右边。

### 2.3 模态框 `.modal`

**用途**：系统设置、身份与个性、删除会话确认等弹窗。

## 四、使用准则（新增控件时必读）

1. **优先复用现有控件**：新增界面元素前，先检查本手册是否已有对应控件，复用其类名与样式，禁止另起炉灶。
2. **遵循命名约定**：类名用 kebab-case，子元素共享组件前缀，状态用 `.on`/`.active`/`.hidden` 等统一类。
3. **使用 CSS 变量**：颜色一律用 `var(--xxx)`，禁止硬编码颜色（特殊语义色除外）。
4. **可点击元素用 `<button>`**：保证键盘可达与语义正确，图标按钮必须有 `title`。
5. **支持多语言**：静态文案用 `data-i18n`，动态文案用 `T.xxx` 字典。
6. **统一隐藏方式**：用 `.hidden` 类控制显示/隐藏，JS 用 `classList.add/remove("hidden")`。
7. **hover/focus 反馈**：可交互元素 hover 变 `--accent`，输入控件 focus 边框变 `--accent`。
8. **新增控件需登记**：新增控件后，在本手册补充对应条目，并同步更新 `style.css` 与 `app.js`。
9. **样式集中管理**：所有控件样式写在 `web/static/style.css`，按功能分区（用 `/* ---------- 分区名 ---------- */` 注释分隔）。

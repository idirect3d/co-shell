## 一、基础按钮控件

### 1.1 普通按钮 `.btn`

**用途**：表单提交、确认/取消、常规操作按钮。

**HTML 结构**：
```html
<button class="btn">回复</button>
<button class="btn primary">▶</button>
<button class="btn danger">确认</button>
<button class="btn ghost">取消</button>
<button class="btn sm">小按钮</button>
```

**CSS 类名**：`.btn`，变体 `.btn.primary`（主操作）、`.btn.danger`（危险操作）、`.btn.ghost`（透明背景）、`.btn.sm`（小尺寸）。

**JS 用法**：
```js
const b = document.createElement("button");
b.className = "btn";
b.textContent = "回复";
b.onclick = () => { /* 处理 */ };
```

**样式要点**：`border: 1px solid var(--border)`、`border-radius: 8px`、`background: var(--bg-elev)`、`padding: 8px 16px`。`.primary` 用 accent 色边框 + `--accent-dim` 背景；`.danger` 用 `--err` 色；`.sm` 缩小 padding 与圆角。

**注意事项**：
- 主操作（发送、确认）用 `.primary`；危险操作（删除）用 `.danger`。
- 发送/中断合并按钮（`#sendBtn`）在运行态用 `.run` 类切换为中断样式（`--err` 色）。

### 1.2 图标按钮 `.icon-btn`

**用途**：工具栏、标题栏的纯图标操作按钮（主题切换、菜单、关闭、刷新等）。

**HTML 结构**：
```html
<button class="icon-btn" id="themeToggle" title="theme">☾</button>
<button class="icon-btn sm" id="treeRefresh" title="刷新">⟳</button>
```

**CSS 类名**：`.icon-btn`，变体 `.icon-btn.sm`（小尺寸）。

**JS 用法**：
```js
const btn = document.createElement("button");
btn.className = "icon-btn";
btn.textContent = "✕";
btn.title = "关闭";
btn.onclick = () => { /* 处理 */ };
```

**样式要点**：`width/height: 28px`（`.sm` 为 22px）、`border: 1px solid var(--border)`、`border-radius: 6px`、`background: none`。hover 时 `color` 与 `border-color` 变 `--accent`。

**注意事项**：
- 图标按钮必须有 `title` 提示。
- 纯图标、无边框的轻量按钮（如 `#treeRefresh`）可覆盖样式去掉边框。

### 1.3 键盘风格按钮 `.key-btn`

**用途**：提问确认栏（ask）的快捷键按钮（Enter/c/a/g/d/n）。

**HTML 结构**：
```html
<button class="key-btn">Enter</button>
```

**CSS 类名**：`.key-btn`。

**JS 用法**：
```js
const b = document.createElement("button");
b.className = "key-btn";
b.textContent = label;
b.onclick = () => answerAsk(value);
```

**样式要点**：`min-width: 44px`、`padding: 4px 10px`、`background: var(--bg-elev)`、`border: 1px solid var(--border)`、`border-radius: 6px`、等宽字体。hover 时边框与文字变 `--accent`。

**注意事项**：用于模拟物理键盘按键的视觉风格，适合快捷键提示场景。

### 1.4 虚拟键盘选项键 `.opt-key-btn`

**用途**：结构化交互（ask_followup_question）的选项按钮，虚拟键盘风格方形键 + 旁边文字标签。

**HTML 结构**：
```html
<div class="opt-item">
  <button class="opt-key-btn">1</button>
  <span class="opt-label">选项文字</span>
</div>
```

**CSS 类名**：`.opt-key-btn`（键）、`.opt-label`（标签）、`.opt-item`（容器）、`.option-buttons`（组容器）。

**JS 用法**：
```js
const item = document.createElement("div");
item.className = "opt-item";
const b = document.createElement("button");
b.className = "opt-key-btn";
b.textContent = keyText;
b.onclick = onClick;
const label = document.createElement("span");
label.className = "opt-label";
for (const n of mdInline(labelText)) label.appendChild(n); // 支持内联 md
item.appendChild(b);
item.appendChild(label);
```

**样式要点**：`.opt-key-btn` 为 `min-width/height: 34px` 方形键，`border: 1px solid var(--accent)`，hover 时背景变 `--accent`、文字变白。`.opt-space` 变体用虚线边框表示空格键。

**注意事项**：选项文字支持内联 markdown（用 `mdInline` 渲染）；空格补充说明键用 `.opt-space` 虚线边框。

### 1.5 小胶囊开关 `.tool-params-raw`

**用途**：TOOL 块输入参数子块标题栏的"Raw"开关，控制是否进行 md 解析渲染（默认关闭显示原始内容）。

**HTML 结构**：
```html
<button class="tool-params-raw">Raw</button>
```

**CSS 类名**：`.tool-params-raw`，状态类 `.on`（打开时高亮）。

**JS 用法**：
```js
const rawPill = document.createElement("button");
rawPill.className = "tool-params-raw";
rawPill.textContent = "Raw";
rawPill.title = "Raw / md 渲染";
rawPill.onclick = () => {
  rawPill.classList.toggle("on");
  curTool.params.rawMode = !curTool.params.rawMode;
  renderParams(curTool.params);
};
```

**样式要点**：`border: 1px solid var(--border)`、`border-radius: 999px`（胶囊）、`padding: 2px 8px`、`font-size: 10px`。`.on` 状态 `color`/`border-color` 变 `--accent`、背景 `--accent-dim`。

**注意事项**：这是"小胶囊开关"的通用样式模板——需要胶囊形态的开关时复用此样式（圆角 999px + 边框 + `.on` 高亮）。

### 1.6 分段控件 `.mode-seg`

**用途**：工作模式切换的分段胶囊控件，高亮段滑动到选中项。

**HTML 结构**：
```html
<div class="mode-seg" id="modeSeg">
  <div class="mode-seg-slider" id="modeSegSlider"></div>
  <button class="mode-seg-item active">模式A</button>
  <button class="mode-seg-item">模式B</button>
</div>
```

**CSS 类名**：`.mode-seg`（容器）、`.mode-seg-slider`（滑动高亮条）、`.mode-seg-item`（分段项，状态类 `.active`）。

**JS 用法**：
```js
const seg = document.createElement("button");
seg.className = "mode-seg-item" + (m.current ? " active" : "");
seg.textContent = m.name;
seg.onclick = () => { if (m.current) return; wsSend({ type: "mode_switch", value: m.name }); };
```

**样式要点**：`.mode-seg` 为 `display: inline-flex` 胶囊容器（`border-radius: 999px`、`padding: 2px`）；`.mode-seg-slider` 绝对定位，`transition: transform/width 0.25s` 实现滑动动画；`.mode-seg-item` 为透明背景按钮，`.active` 高亮 accent 色。

**注意事项**：分段控件适合互斥选项（一次只能选一个）；滑动高亮条需 JS 计算位置与宽度。

### 1.7 表单控件 `.set-toggle` / `.set-input` / `.set-select`

**用途**：系统设置面板的表单控件——开关（bool）、输入框（text/number）、下拉选择（enum）。

**HTML 结构**：
```html
<label class="set-row">
  <span class="set-label">主题</span>
  <select class="set-select" id="setThemeMode">
    <option value="auto">跟随系统</option>
  </select>
</label>
```

**CSS 类名**：`.set-row`（行容器）、`.set-label`（标签）、`.set-toggle`（checkbox 开关）、`.set-input`（text/number 输入）、`.set-select`（下拉）。

**JS 用法**（动态创建，见 `renderSettingItem`）：
```js
if (it.type === "bool") {
  ctl = document.createElement("input");
  ctl.type = "checkbox";
  ctl.className = "set-toggle";
  ctl.checked = it.value === "on";
  ctl.onchange = () => wsSend({ type: "settings_set", key: it.key, value: ctl.checked ? "on" : "off" });
} else if (it.type === "enum") {
  ctl = document.createElement("select");
  ctl.className = "set-select";
  // ... 填充 option
}
```

**样式要点**：`.set-row` 为 flex 行，`.set-label` 固定 50% 宽右对齐；`.set-toggle` 用 `accent-color: var(--accent)`；`.set-input`/`.set-select` 用 `--mono-bg` 背景、`--border` 边框、focus 时 `--accent`。

**注意事项**：设置项按类型（bool/number/enum/text）选择对应控件；设置变更通过 `settings_set` WebSocket 消息发送。

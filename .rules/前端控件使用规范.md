# 前端控件使用规范

> 本文件是 co-shell Web UI 前端控件的统一使用手册，作为未来界面控件的使用准则。
> 目标：确保所有界面控件以统一的方式和样式被使用，避免样式漂移与重复造轮子。
>
> 适用范围：`web/static/index.html`（静态结构）、`web/static/app.js`（动态创建）、`web/static/style.css`（样式）。
> 相关规范：`.rules/PROJECT STANDARDS.md`（开发流程）、`.rules/go使用规范.md`（Go 后端）。

## 通用约定

### 命名约定
- **CSS 类名**：小写字母 + 连字符（kebab-case），如 `.icon-btn`、`.tool-params-raw`、`.mode-seg-item`。
- **语义前缀**：同一组件的子元素共享前缀，如 `.tool-params` 下的 `.tool-params-head` / `.tool-params-body` / `.tool-params-toggle`。
- **状态类**：用 `.on` / `.active` / `.expanded` / `.collapsed` / `.hidden` 等表示状态，通过 JS 切换。
- **ID 命名**：仅用于唯一元素（如 `#input`、`#sendBtn`、`#stream`），动态创建的控件一律用 class。

### 样式约定
- **颜色一律使用 CSS 变量**：`var(--accent)`、`var(--border)`、`var(--fg)`、`var(--fg-dim)`、`var(--fg-faint)`、`var(--bg)`、`var(--bg-panel)`、`var(--bg-elev)`、`var(--mono-bg)`、`var(--ok)`、`var(--warn)`、`var(--err)`、`var(--debug)`、`var(--accent-dim)`、`var(--placeholder)`、`var(--glow)`。禁止硬编码颜色值（git 状态色等特殊语义色除外）。
- **字体**：正文用 `inherit`；代码/等宽内容用 `ui-monospace, "SF Mono", Menlo, Consolas, monospace`。
- **圆角**：按钮/输入框 `4-8px`，胶囊/分段控件 `999px`，模态框/菜单 `8-10px`。
- **hover 反馈**：可交互元素 hover 时颜色变为 `var(--accent)`，边框变为 `var(--accent)`。
- **focus 反馈**：输入类控件 focus 时 `border-color: var(--accent)`。

### 交互约定
- **可点击元素**：一律用 `<button>`（非 `<div>`/`<span>`），保证键盘可达与语义正确。
- **提示**：图标按钮用 `title` 属性提供悬停提示；有 i18n 需求的用 `data-i18n-title`。
- **多语言**：静态文案用 `data-i18n` 属性；动态文案用 `T.xxx` 字典（见 app.js 顶部 `T` 对象）。
- **隐藏/显示**：统一用 `.hidden` 类（`display: none`），JS 通过 `classList.add/remove("hidden")` 切换。
- **事件**：动态创建的控件用 `onclick` / `addEventListener` 绑定；阻止冒泡用 `e.stopPropagation()`。

## 一、基础按钮控件

### 1.1 普通按钮 `.btn`

**用途**：表单提交、确认/取消、常规操作按钮。

**HTML 结构**：
```html
<button class="btn">回复</button>
<button class="btn primary">▶</button>
<button class="btn danger">确认</button>
<button class="btn ghost">取消</button>
<button class="btn sm">小按钮</button>
```

**CSS 类名**：`.btn`，变体 `.btn.primary`（主操作）、`.btn.danger`（危险操作）、`.btn.ghost`（透明背景）、`.btn.sm`（小尺寸）。

**JS 用法**：
```js
const b = document.createElement("button");
b.className = "btn";
b.textContent = "回复";
b.onclick = () => { /* 处理 */ };
```

**样式要点**：`border: 1px solid var(--border)`、`border-radius: 8px`、`background: var(--bg-elev)`、`padding: 8px 16px`。`.primary` 用 accent 色边框 + `--accent-dim` 背景；`.danger` 用 `--err` 色；`.sm` 缩小 padding 与圆角。

**注意事项**：
- 主操作（发送、确认）用 `.primary`；危险操作（删除）用 `.danger`。
- 发送/中断合并按钮（`#sendBtn`）在运行态用 `.run` 类切换为中断样式（`--err` 色）。

### 1.2 图标按钮 `.icon-btn`

**用途**：工具栏、标题栏的纯图标操作按钮（主题切换、菜单、关闭、刷新等）。

**HTML 结构**：
```html
<button class="icon-btn" id="themeToggle" title="theme">☾</button>
<button class="icon-btn sm" id="treeRefresh" title="刷新">⟳</button>
```

**CSS 类名**：`.icon-btn`，变体 `.icon-btn.sm`（小尺寸）。

**JS 用法**：
```js
const btn = document.createElement("button");
btn.className = "icon-btn";
btn.textContent = "✕";
btn.title = "关闭";
btn.onclick = () => { /* 处理 */ };
```

**样式要点**：`width/height: 28px`（`.sm` 为 22px）、`border: 1px solid var(--border)`、`border-radius: 6px`、`background: none`。hover 时 `color` 与 `border-color` 变 `--accent`。

**注意事项**：
- 图标按钮必须有 `title` 提示。
- 纯图标、无边框的轻量按钮（如 `#treeRefresh`）可覆盖样式去掉边框。

### 1.3 键盘风格按钮 `.key-btn`

**用途**：提问确认栏（ask）的快捷键按钮（Enter/c/a/g/d/n）。

**HTML 结构**：
```html
<button class="key-btn">Enter</button>
```

**CSS 类名**：`.key-btn`。

**JS 用法**：
```js
const b = document.createElement("button");
b.className = "key-btn";
b.textContent = label;
b.onclick = () => answerAsk(value);
```

**样式要点**：`min-width: 44px`、`padding: 4px 10px`、`background: var(--bg-elev)`、`border: 1px solid var(--border)`、`border-radius: 6px`、等宽字体。hover 时边框与文字变 `--accent`。

**注意事项**：用于模拟物理键盘按键的视觉风格，适合快捷键提示场景。

### 1.4 虚拟键盘选项键 `.opt-key-btn`

**用途**：结构化交互（ask_followup_question）的选项按钮，虚拟键盘风格方形键 + 旁边文字标签。

**HTML 结构**：
```html
<div class="opt-item">
  <button class="opt-key-btn">1</button>
  <span class="opt-label">选项文字</span>
</div>
```

**CSS 类名**：`.opt-key-btn`（键）、`.opt-label`（标签）、`.opt-item`（容器）、`.option-buttons`（组容器）。

**JS 用法**：
```js
const item = document.createElement("div");
item.className = "opt-item";
const b = document.createElement("button");
b.className = "opt-key-btn";
b.textContent = keyText;
b.onclick = onClick;
const label = document.createElement("span");
label.className = "opt-label";
for (const n of mdInline(labelText)) label.appendChild(n); // 支持内联 md
item.appendChild(b);
item.appendChild(label);
```

**样式要点**：`.opt-key-btn` 为 `min-width/height: 34px` 方形键，`border: 1px solid var(--accent)`，hover 时背景变 `--accent`、文字变白。`.opt-space` 变体用虚线边框表示空格键。

**注意事项**：选项文字支持内联 markdown（用 `mdInline` 渲染）；空格补充说明键用 `.opt-space` 虚线边框。

### 1.5 小胶囊开关 `.tool-params-raw`

**用途**：TOOL 块输入参数子块标题栏的"Raw"开关，控制是否进行 md 解析渲染（默认关闭显示原始内容）。

**HTML 结构**：
```html
<button class="tool-params-raw">Raw</button>
```

**CSS 类名**：`.tool-params-raw`，状态类 `.on`（打开时高亮）。

**JS 用法**：
```js
const rawPill = document.createElement("button");
rawPill.className = "tool-params-raw";
rawPill.textContent = "Raw";
rawPill.title = "Raw / md 渲染";
rawPill.onclick = () => {
  rawPill.classList.toggle("on");
  curTool.params.rawMode = !curTool.params.rawMode;
  renderParams(curTool.params);
};
```

**样式要点**：`border: 1px solid var(--border)`、`border-radius: 999px`（胶囊）、`padding: 2px 8px`、`font-size: 10px`。`.on` 状态 `color`/`border-color` 变 `--accent`、背景 `--accent-dim`。

**注意事项**：这是"小胶囊开关"的通用样式模板——需要胶囊形态的开关时复用此样式（圆角 999px + 边框 + `.on` 高亮）。

### 1.6 分段控件 `.mode-seg`

**用途**：工作模式切换的分段胶囊控件，高亮段滑动到选中项。

**HTML 结构**：
```html
<div class="mode-seg" id="modeSeg">
  <div class="mode-seg-slider" id="modeSegSlider"></div>
  <button class="mode-seg-item active">模式A</button>
  <button class="mode-seg-item">模式B</button>
</div>
```

**CSS 类名**：`.mode-seg`（容器）、`.mode-seg-slider`（滑动高亮条）、`.mode-seg-item`（分段项，状态类 `.active`）。

**JS 用法**：
```js
const seg = document.createElement("button");
seg.className = "mode-seg-item" + (m.current ? " active" : "");
seg.textContent = m.name;
seg.onclick = () => { if (m.current) return; wsSend({ type: "mode_switch", value: m.name }); };
```

**样式要点**：`.mode-seg` 为 `display: inline-flex` 胶囊容器（`border-radius: 999px`、`padding: 2px`）；`.mode-seg-slider` 绝对定位，`transition: transform/width 0.25s` 实现滑动动画；`.mode-seg-item` 为透明背景按钮，`.active` 高亮 accent 色。

**注意事项**：分段控件适合互斥选项（一次只能选一个）；滑动高亮条需 JS 计算位置与宽度。

### 1.7 表单控件 `.set-toggle` / `.set-input` / `.set-select`

**用途**：系统设置面板的表单控件——开关（bool）、输入框（text/number）、下拉选择（enum）。

**HTML 结构**：
```html
<label class="set-row">
  <span class="set-label">主题</span>
  <select class="set-select" id="setThemeMode">
    <option value="auto">跟随系统</option>
  </select>
</label>
```

**CSS 类名**：`.set-row`（行容器）、`.set-label`（标签）、`.set-toggle`（checkbox 开关）、`.set-input`（text/number 输入）、`.set-select`（下拉）。

**JS 用法**（动态创建，见 `renderSettingItem`）：
```js
if (it.type === "bool") {
  ctl = document.createElement("input");
  ctl.type = "checkbox";
  ctl.className = "set-toggle";
  ctl.checked = it.value === "on";
  ctl.onchange = () => wsSend({ type: "settings_set", key: it.key, value: ctl.checked ? "on" : "off" });
} else if (it.type === "enum") {
  ctl = document.createElement("select");
  ctl.className = "set-select";
  // ... 填充 option
}
```

**样式要点**：`.set-row` 为 flex 行，`.set-label` 固定 50% 宽右对齐；`.set-toggle` 用 `accent-color: var(--accent)`；`.set-input`/`.set-select` 用 `--mono-bg` 背景、`--border` 边框、focus 时 `--accent`。

**注意事项**：设置项按类型（bool/number/enum/text）选择对应控件；设置变更通过 `settings_set` WebSocket 消息发送。

## 二、容器 / 布局控件

### 2.1 事件块 `.ev`

**用途**：消息流（stream）中的事件块，承载 LLM 输出、TOOL 调用、命令、系统消息等。

**HTML 结构**：
```html
<div class="ev tool">
  <div class="ev-head">
    <span class="ev-head-label">TOOL</span>
    <span class="ev-streaming">...</span>
    <span class="ev-actions">
      <button class="ev-act">⧉</button>
      <button class="ev-act">▾</button>
      <button class="ev-act">↻</button>
    </span>
  </div>
  <div class="ev-body">内容</div>
</div>
```

**CSS 类名**：`.ev`（容器，类型类 `.llm`/`.tool`/`.command`/`.system`/`.repl`/`.user-msg`/`.thinking`，状态类 `.collapsed`/`.level-*`）、`.ev-head`（标题栏）、`.ev-head-label`（标题文字）、`.ev-streaming`（动态省略号）、`.ev-actions`（操作组）、`.ev-act`（操作图标）、`.ev-body`（内容区）。

**JS 用法**：用 `makeBlock(cls, label, msgIndex)` 创建；`addBlockActions` 添加复制/收起/重试图标；`scheduleMd` 做 md 渲染。

**样式要点**：`.ev` 为 `border: 1px solid var(--border)`、`border-radius: 8px`、`background: var(--bg-panel)`；`.ev-head` 为 flex 标题栏（`--bg-elev` 背景、`text-transform: uppercase`）；`.ev-head::before` 是类型指示圆点（颜色随类型变化）；`.ev-body` 等宽字体、`white-space: pre-wrap`；`.collapsed` 隐藏 body。

**注意事项**：
- 类型圆点颜色：LLM=accent、TOOL=warn、command=ok、system=fg-faint、repl=debug。
- 内容区加 `.md` 类后切换为 markdown 渲染（`white-space: normal`）。
- 正在输出的块不收起（`markStreaming` 移除 `.collapsed`）。

### 2.2 输入参数子块 `.tool-params`

**用途**：TOOL 块内的输入参数子块，有标题栏、Raw 开关、展开/收起切换、可滚动内容区。

**HTML 结构**：
```html
<div class="tool-params">
  <div class="tool-params-head">
    <span class="tool-params-title">输入参数</span>
    <span class="tool-params-right">
      <button class="tool-params-raw">Raw</button>
      <button class="tool-params-toggle">⤢</button>
    </span>
  </div>
  <div class="tool-params-body">参数内容</div>
</div>
```

**CSS 类名**：`.tool-params`（容器，状态类 `.expanded`）、`.tool-params-head`（标题栏）、`.tool-params-title`（标题）、`.tool-params-right`（右侧操作组）、`.tool-params-raw`（Raw 开关）、`.tool-params-toggle`（展开/收起）、`.tool-params-body`（内容区）。

**JS 用法**：`ensureToolParams(curTool)` 创建；`renderParams(params)` 按 Raw 开关状态渲染（rawMode 时 textContent，否则 mdRender）。

**样式要点**：`.tool-params` 上下边框 + `--bg-elev` 背景；`.tool-params-head` 为 flex 标题栏（`justify-content: space-between`）；`.tool-params-body` 固定 `max-height: 200px` 可滚动，`.expanded` 时 `max-height: none`。

**注意事项**：Raw 开关（`.tool-params-raw`）控制 md 渲染，默认关闭显示原始内容；展开/收起切换按钮（`.tool-params-toggle`）在 Raw 开关右边。

### 2.3 模态框 `.modal`

**用途**：系统设置、身份与个性、删除会话确认等弹窗。

**HTML 结构**：
```html
<div id="settings" class="modal hidden">
  <div class="modal-box">
    <div class="modal-head">
      <span>系统设置</span>
      <button class="icon-btn sm" id="settingsClose">✕</button>
    </div>
    <div class="modal-body">内容</div>
  </div>
</div>
```

**CSS 类名**：`.modal`（遮罩容器，状态类 `.hidden`）、`.modal-box`（弹窗主体）、`.modal-head`（标题栏）、`.modal-body`（内容区）。

**JS 用法**：
```js
settingsClose.onclick = () => settingsModal.classList.add("hidden");
settingsModal.onclick = (e) => { if (e.target === settingsModal) settingsModal.classList.add("hidden"); };
```

**样式要点**：`.modal` 为 `position: fixed; inset: 0` 全屏遮罩（`rgba(0,0,0,0.6)`），flex 居中；`.modal-box` 为 `min-width: 320px`、`--bg-panel` 背景、`border-radius: 10px`；`.modal-head` 为 flex 标题栏（`justify-content: space-between`）。

**注意事项**：点击遮罩（`e.target === modal`）关闭；关闭按钮用 `.icon-btn.sm`；`.hidden` 控制显示/隐藏。

### 2.4 下拉菜单 `.menu`

**用途**：右上角菜单（工作区/任务进展/状态条/系统设置/重启后台）。

**HTML 结构**：
```html
<div class="menu-wrap" id="menuWrap">
  <button class="icon-btn" id="menuBtn">☰</button>
  <div class="menu" id="menu">
    <button class="menu-item">

    </button>
    <div class="menu-sep"></div>
  </div>
</div>
```

**CSS 类名**：`.menu-wrap`（包裹容器）、`.menu`（下拉面板）、`.menu-item`（菜单项）、`.mi-ico`（图标）、`.mi-label`（文字）、`.mi-check`（勾选标记）、`.menu-sep`（分隔线）。

**JS 用法**：hover 显示（`.menu-wrap:hover .menu`）；菜单项点击处理。

**样式要点**：`.menu` 为 `position: absolute; top: 100%; right: 0` 下拉面板（`--bg` 背景、`border-radius: 8px`、阴影）；`.menu-item` 为 flex 行（hover 时 `--bg-elev` 背景 + accent 文字）；`.mi-check` 默认隐藏，`.on` 时显示勾选。

**注意事项**：`.menu-wrap` 的垂直 padding 桥接按钮与菜单的悬停间隙；菜单项文字对齐（无图标项留出图标空位）。

### 2.8 提问区域 `.ask-area`

## 三、通用状态类

| 状态类 | 用途 | 示例 |
|--------|------|------|
| `.hidden` | 隐藏元素（`display: none`） | 模态框、菜单、面板 |
| `.on` | 激活/打开状态 | `.tool-params-raw.on`、`.conn.on` |
| `.active` | 选中/当前项 | `.mode-seg-item.active`、`.session-item.current` |
| `.expanded` | 展开状态 | `.tool-params.expanded` |
| `.collapsed` | 收起状态 | `.ev.collapsed` |
| `.md` | markdown 渲染模式 | `.ev-body.md`、`.interaction-title.md` |
| `.level-*` | 事件级别（success/warning/error/debug） | `.ev.level-error` |

## 四、使用准则（新增控件时必读）

1. **优先复用现有控件**：新增界面元素前，先检查本手册是否已有对应控件，复用其类名与样式，禁止另起炉灶。
2. **遵循命名约定**：类名用 kebab-case，子元素共享组件前缀，状态用 `.on`/`.active`/`.hidden` 等统一类。
3. **使用 CSS 变量**：颜色一律用 `var(--xxx)`，禁止硬编码颜色（特殊语义色除外）。
4. **可点击元素用 `<button>`**：保证键盘可达与语义正确，图标按钮必须有 `title`。
5. **支持多语言**：静态文案用 `data-i18n`，动态文案用 `T.xxx` 字典。
6. **统一隐藏方式**：用 `.hidden` 类控制显示/隐藏，JS 用 `classList.add/remove("hidden")`。
7. **hover/focus 反馈**：可交互元素 hover 变 `--accent`，输入控件 focus 边框变 `--accent`。
8. **新增控件需登记**：新增控件后，在本手册补充对应条目，并同步更新 `style.css` 与 `app.js`。
9. **样式集中管理**：所有控件样式写在 `web/static/style.css`，按功能分区（用 `/* ---------- 分区名 ---------- */` 注释分隔）。

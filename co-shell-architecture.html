1本地多实例编排

  • hub 作为父进程创建 / 启动 / 停止多个本地 co-shell
  • 自动分配端口，独立 workspace 与 config
  • 崩溃监控与一键启停管理

2远程实例接入

  • 添加不受控远程 co-shell（仅提供 WS 地址）
  • hub 只连接访问，不干预其生命周期
  • 本地 + 远程实例统一编排、统一切换

3桌面多标签操作

  • 浏览器打开 hub 外壳，iframe 多页并列各实例
  • 反向代理透传完整 co-shell Web UI
  • 标签切换 agent，会话状态各自保留

4移动端远程操控

  • co-shell-mobile-app 经 TCP + API Key 连 hub
  • WKWebView 渲染 hub 外壳，窄屏自适应
  • 随时随地操控本地 / 远程所有 agent

co-shell · 功能架构图

co-shell 是一个 AI 驱动的智能命令行 Shell —— 用自然语言描述你想做的事，AI Agent 自动理解意图、编排命令、执行并分析结果。 通过 Web UI 在浏览器中操作：对话、浏览文件、管理任务、上传附件，一站式完成。单文件约 10MB、零外部依赖、跨平台（macOS / Linux / Windows）。
启动 Web UI：co-shell serve → 浏览器打开 http://127.0.0.1:端口

🛠️ 系统管理

磁盘清理、进程管理、日志分析、环境配置 —— 一句话搞定，不用记命令参数。

例："清理超过 1GB 的临时文件" · "查看哪个进程占用 80 端口"

💻 开发辅助

创建项目、代码统计、Git 操作、依赖管理、自动化测试，AI 帮你编排工具链。

例："统计本项目 Go 代码行数" · "帮我初始化一个 Git 仓库并提交"

📁 文件处理

批量重命名、格式转换、内容搜索、Word / Excel / PDF 文档生成与处理。

例："把 100 张图片批量重命名" · "把这份 Markdown 转成 Word"

🔍 调研报告

联网搜索、数据收集、自动生成结构化 Markdown / Word 深度调研报告。

例："调研北冰洋品牌历史并出报告" · "分析再保险市场趋势"

🌐 网页自动化

浏览器自动化：打开网页、点击、填表、截图、抓取数据，SREA 闭环操作。

例："打开某网站并截图首页" · "自动填写表单并提交"

⏰ 自动化任务

定时执行、任务计划拆解、子 Agent 并行，把重复工作交给 AI。

例："每天 9 点生成日报" · "并行调研 3 个主题"

📊 数据分析

读取 Excel / 数据库，统计、透视、生成图表与结论，表达式精确计算。

例："分析销售表并汇总各区域业绩" · "计算复利收益"

🌐 远程操控

配合 co-shell-hub 统一编排本地 / 远程实例，手机随时远程操作。

例："手机远程查看服务器状态" · "统一管理多台机器"
